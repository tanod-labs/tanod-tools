How a QR code holds your text

A QR code is a square grid of dark and light squares called modules. Your text is turned into bytes (this tool uses UTF-8, so accents and emoji survive), split into blocks, and padded with extra error-correction data computed with Reed-Solomon codes. The extra data is what lets a scanner read a code that is smudged, scratched or partly covered.

The grid size is chosen automatically: more text, or a higher error-correction level, means a larger grid with smaller squares. Printing small? Keep the text short and leave the quiet zone in place, because scanners use that blank border to find the code.

Wi-Fi codes use a standard text layout that phones recognise and offer to join. Email and phone codes use mailto: and tel: links. Everything is generated on this page and nothing is sent anywhere.
