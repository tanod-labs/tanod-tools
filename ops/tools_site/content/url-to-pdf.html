How a web page becomes a PDF here

Our server starts a fresh, sandboxed copy of the Chromium browser, opens the address you gave, waits for the page to finish loading and prints it to PDF with your paper size and orientation, the same way your browser's Print dialog would. The browser can reach only that one site, never private networks, and is thrown away after each job.

Tips

  • Reader-friendly pages, such as articles with a print view, give the cleanest PDFs.
  • Want several pages in one file? Convert each one, then join them with Merge PDF (in your browser).
  • Need the text rather than a PDF? HTML to Markdown converts pasted HTML on your device.
