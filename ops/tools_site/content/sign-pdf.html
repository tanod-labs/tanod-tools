How a signature gets onto a PDF page

A PDF page is a fixed layout, so signing it means adding something to the page, not typing into it. This tool turns your signature into a small picture with a transparent background, together with the date line if you ticked that box, and draws that picture on the page you chose. Your browser shows you the page using pdf.js and writes the new copy with pdf-lib, so the page you see is the page that gets signed.

The position and the size are stored as fractions of the page, not as fixed measurements. That is why one set of sliders suits pages of different sizes when you sign every page, and why a page that is stored turned sideways still receives a signature that stands upright. Your original file is never modified; you download a separate signed copy.

What you get is an image of a signature, which is how most people sign forms, letters and agreements by hand and then scan them. It is not a cryptographic digital signature. Those use a certificate issued to you, protect the file from changes after signing and need a service built for the purpose. Which kind a document needs depends on the document and on who asked for the signature.

Tips

  • Draw slowly and fill the pad: the signature is trimmed to the ink, so a bigger drawing gives a sharper result at the same size on the page.
  • Lock the signed copy with a password using Protect PDF, or stamp every page with Watermark PDF.
  • Need to add a signed page to another document first? Merge PDF joins files in the order you choose.
