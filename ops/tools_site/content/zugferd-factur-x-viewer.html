    A PDF that is also an invoice
    

    A ZUGFeRD or Factur-X file looks like any PDF invoice, but it carries a second copy of the invoice as XML, attached to the PDF the way an email attachment is attached to a message. People read the pages; programs read the XML. Since 1 January 2025 every business in Germany has to be able to receive structured e-invoices, and France requires the same from 1 September 2026, so these hybrid PDFs are now common.
    

    This page opens the PDF in your browser, reads the list of attached files, and tries the XML ones in this order: factur-x.xml, zugferd-invoice.xml, xrechnung.xml, then any other XML file. The first one that is a supported invoice is shown. It does not draw the PDF pages.
    

    Profiles
    

    The profile tells how much data the XML holds. MINIMUM and BASIC WL have header data and totals only. BASIC adds line items. EN 16931 (called COMFORT in older ZUGFeRD) is the full European standard. EXTENDED goes beyond it, and XRECHNUNG is the German public-sector profile. The page shows what each file contains and does not check it against the profile rules.
