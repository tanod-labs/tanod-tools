What PDF metadata is, and why you might change it

Every PDF can carry a few descriptive fields: a title, an author, a subject, keywords, the program that created it and the dates it was made and last changed. They live in the document information dictionary, and many programs also write a second copy as an XMP packet, an XML block attached to the file.

These fields show up in file properties, search results and browser tabs, so a wrong title or a forgotten author name can be awkward when a document leaves your hands. This tool reads them in your browser, lets you correct them, or clears them. Page content is never altered.
