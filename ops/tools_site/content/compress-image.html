    How image compression works here

    Most of an image file's size is pixel data. JPEG and WebP shrink it by discarding detail the eye is least likely to miss; the quality setting decides how much is discarded. PNG is lossless, so its size depends on how predictable the pixels are. Reducing a PNG to a palette of at most 256 colours makes the data far simpler to compress, at the cost of exact colour.

    This tool decodes each image with your browser, draws it to a canvas and saves it again, using your browser's own JPEG and WebP encoders. For palette PNGs it picks the colours with the open-source UPNG.js quantiser and writes the PNG file itself. If the result is not smaller than the file you gave it, you get your original back.

    Tips
