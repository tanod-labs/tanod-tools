Replacing text in bulk

Find and replace changes every occurrence of a word or pattern in one pass. The match count updates while you type, so you can see how far a change reaches before you apply it, and the result appears in a separate box so your original text is never overwritten until you choose "Use result as text".

Regular expressions let you describe a shape rather than a fixed string: a run of digits, a date, a word followed by a comma. Groups in brackets can be rearranged in the replacement with $1, $2 and so on. Because a badly written pattern can run for a very long time, patterns are executed in a background worker that is stopped after two seconds.

Tips

  • Build and debug a pattern first in the Regex tester, which lists every match and its groups.
  • Change capitalisation with the Case converter.
  • Check the edit with Compare text.
  • Remove repeated lines with Remove duplicate lines.
