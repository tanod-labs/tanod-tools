Aspect ratio

Cropping without losing resolution

Cropping keeps a rectangle of the original pixels and throws the rest away. The picture you see on screen is a reduced preview so it fits the page; the crop itself is taken from the full-resolution image, using the X, Y, width and height shown in the fields. Those numbers are in the image's own pixels, not screen pixels.

Use an aspect ratio when the result has to fit a frame: 1:1 for a square avatar, 16:9 for a video thumbnail, 4:3 or 3:2 for common photo shapes, 9:16 for a vertical story. The box keeps that shape as you resize it, and typing a width or height updates the other.

Tips

  • Crop first, then reduce the size with Resize image and Compress image.
  • Photo turned the wrong way? Rotate image fixes it.
  • Making an icon from part of a picture? Crop to 1:1, then use the Favicon generator.
