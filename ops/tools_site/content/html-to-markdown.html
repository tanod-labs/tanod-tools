Turning web pages into Markdown

Moving content out of a web page, an old CMS or a rich-text editor and into a README, a static site or a notes app usually means converting HTML to Markdown. The converter walks the HTML structure and writes each element in its Markdown form: headings become # lines, lists become dashes, links become [text](url), and <pre><code> becomes a code block.

Markdown only describes structure, so styling is left behind. Inline styles, classes, colours and layout containers disappear, while the words, emphasis, links, images and lists stay. Tables are written as GitHub Flavored Markdown tables when they are simple enough to fit that format.

Different projects prefer different Markdown habits, which is why the heading, list marker, code block and italic styles can be changed. Most renderers accept any of them.

Tips

  • Check how the Markdown renders with Markdown to HTML, which has a preview.
  • Tidy leftover spacing or wording with Find and replace.
  • Count the words in the result with the Word counter.
