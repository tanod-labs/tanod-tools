Reversing text without breaking characters

Backwards text is used for puzzles, games, secret notes, checking palindromes and testing how software copes with unusual input. Reversing looks trivial, but computers store many characters as more than one piece: most emoji, flags, and letters whose accent is stored separately. Flipping the pieces one by one produces broken symbols. This tool uses your browser's text segmentation to find where each visible character starts and ends, and reverses whole characters.

The Word order and Each word options work line by line, so a list keeps its line structure. Spaces between words are kept as they were.

Right-to-left scripts such as Arabic and Hebrew are stored in reading order and displayed right to left by your browser, so reversing them gives text that reads backwards, the same as for English.

Tips

  • Make a secret note harder to read with the Morse code translator or Text to binary.
  • Reverse a sorted list with Sort lines alphabetically, which can sort Z to A directly.
  • Swap capitals and lower case with the Case converter.
