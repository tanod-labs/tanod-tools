What a UUID is, and v4 against v7


A UUID is a 128-bit identifier written as 32 hex digits in five groups. Because the space is so large, systems can create IDs independently, with no central counter, and still expect them to be unique.


In a version 4 UUID, 122 of the 128 bits are random; the rest hold the version (4) and the variant. A version 7 UUID starts with the creation time in Unix milliseconds, followed by a counter and random bits. Because the time comes first, newer IDs sort after older ones, which is friendlier to database indexes than fully random keys. The cost is that the creation time can be read from the ID.


This tool uses the browser's secure random generator. Within one millisecond, version 7 values increase through a 12-bit counter, so a batch is strictly ordered.
