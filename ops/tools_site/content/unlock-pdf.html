What unlocking does

A protected PDF is encrypted. With the right password, our server opens it with the open-source qpdf library and writes a copy without the encryption and without the owner's restrictions on printing, copying and editing. The pages themselves don't change.

Tips

  • Keep the protected original if you'll need to send it securely again, or protect the copy later with Protect PDF.
  • Once unlocked, the file works with every PDF tool here, such as Merge PDF and Split PDF, which run in your browser.
