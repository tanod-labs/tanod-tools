Removing duplicates and sorting lines

Lists collect repeats: email addresses pasted from several sources, keywords, log lines, file names. This tool reads the text one line at a time, remembers each line it has seen and drops the later copies (or the earlier ones, if you choose to keep the last occurrence). The lines that survive stay in their original order unless you pick a sort.

The report above the buttons shows how many lines went in, how many came out and how many were removed as duplicates, so you can check the result against what you expected. Empty lines removed by the option are reported separately.

Tips

  • To clean up the lines first, use Find and replace, then come back here.
  • Check what changed between two versions of a list with Compare text.
  • Only need the list in order, with more sorting choices? Use Sort lines alphabetically.
  • Count what is left with the Word counter.
