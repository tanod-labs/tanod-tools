Background

Turning vector graphics into pixels

An SVG describes shapes with coordinates, so it can be drawn at any size without losing sharpness. Many places still want a bitmap, though: app stores, social profiles, slide decks, email signatures and older design tools. Converting to PNG fixes the drawing at one pixel size, so choose the largest size you will need; you can always shrink a PNG later, but enlarging it blurs.

Your browser's own SVG renderer does the drawing on a canvas, at the output size, and the canvas is saved as PNG with full transparency. The SVG is treated strictly as an image: scripts inside it never run and nothing it links to is downloaded.

Tips

  • For screens with high pixel density, export at 2x or 3x the size the image is shown at.
