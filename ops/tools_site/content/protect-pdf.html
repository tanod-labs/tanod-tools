What password protection does

A protected PDF is encrypted: its pages are scrambled with a key derived from your password, so a reader shows nothing until the password is typed in. Our server encrypts the file with AES-256 using the open-source qpdf library and sends the locked copy back to you.

Tips

  • Send the password separately from the file, for example by text message instead of in the same email.
  • Want a visible "Confidential" mark too? Add one with Watermark PDF first; it runs in your browser.
