From CSV rows to JSON

CSV is the lowest common denominator of data: every spreadsheet and database can export it. JSON is what most web APIs, scripts and configuration files expect. This tool reads the CSV with a parser that follows the CSV standard, so a comma inside a quoted address or a line break inside a quoted comment stays inside its cell instead of splitting the row.

With a header row, each line becomes an object whose keys are the column names, in column order. Without one, each line becomes an array. Values are kept as text unless you ask for numbers and true/false to be converted, because a CSV file carries no types and an automatic guess can quietly change a postcode like 02134 into the number 2134.

The line under the options tells you how many rows and columns were read and which delimiter was used. If some rows have more or fewer fields than the header, a note says which lines, which usually points at a stray delimiter or an unclosed quote in the source.

Tips

  • Going the other way? Use JSON to CSV.
  • To check or reformat the result, paste it into the JSON formatter.
  • Clean repeated rows first with Remove duplicate lines.
