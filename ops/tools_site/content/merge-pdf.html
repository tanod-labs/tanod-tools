    Merging PDFs without uploading them

    A PDF merge doesn't need a server. Each page in a PDF is a self-contained description of text, images and drawing commands, so combining files means copying those page objects into a new document and writing a fresh index. Your browser can do that directly with the files on your device.

    The pages are copied, not re-rendered, so the merged file has the same quality as the originals: text stays selectable and searchable, and images are not recompressed. The new document gets one page list in the order you set here.

    Tips

    • Need only some pages from a file? Run it through Extract pages first, or remove pages after merging with Remove pages.
    • Merging photos or scans? Turn them into a PDF with JPG to PDF, then merge.
