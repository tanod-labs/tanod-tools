What Base64 is for


Base64 represents any sequence of bytes using 64 safe text characters: A-Z, a-z, 0-9, plus and slash. Every 3 bytes become 4 characters, with = padding to fill the last group. That makes binary data safe to place in email, JSON, HTML, URLs and other places that only handle text. It is an encoding, not encryption: anyone can reverse it.


Text is first turned into bytes, and the character encoding matters. This tool uses UTF-8, the standard on the web, so non-English text and symbols survive a round trip. Decoding checks the result is valid UTF-8 and tells you if it is not, which usually means the data was a file rather than text.


File mode reads the file in your browser and encodes it in small slices so the page stays responsive. Going the other way, the tool decodes pasted Base64 into bytes and gives them to you as a download. It looks at the first bytes to suggest a file extension for common formats such as PNG, JPEG, GIF, PDF and ZIP.
