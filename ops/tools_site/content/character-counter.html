Counting characters the way the receiving system does

"Character" means different things to different software. A person sees one character in "é" or in a flag emoji, but a computer may store either as two or more pieces. This counter shows the count you see (Characters), the lower-level count of Unicode code points, and the number of bytes the text takes up in UTF-8, the encoding most websites and databases use. When a form says "maximum 255 characters", it is usually counting one of these, and the difference matters only for emoji, accents stored as separate marks and non-Latin scripts.

The length limits table compares your text with places where length is often capped. Each row shows what is used and what is left; a row over its limit shows how many characters to cut. Text messages are counted with the GSM rules phones use, so one emoji can switch the whole message to the shorter Unicode limit.

Everything is counted in your browser as you type. The text is not uploaded or stored.
