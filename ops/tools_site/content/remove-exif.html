    What a photo can give away

    Most cameras and phones write extra information into every photo: the make and model, the time it was taken, the software that edited it and, if location is on, the GPS coordinates of where you stood. That block is called EXIF. Editing programs add XMP and IPTC blocks with captions, author names and keywords. Many sites strip this when you upload, but not all of them do, and a file sent by email or chat usually keeps everything.

    This tool first shows what each photo contains, then removes it by rewriting the file's container. A JPEG is a sequence of labelled blocks followed by the compressed picture; the metadata blocks are left out and the picture data is copied unchanged. That is why the result is not re-compressed and looks identical.

    Tips

    • Check the list before sharing: a flagged location means the photo carries coordinates.
    • Screenshots and edited exports can still contain text metadata. Run them through here too.
    • To also shrink the file, use Compress image afterwards; that re-encodes and drops metadata as well.
