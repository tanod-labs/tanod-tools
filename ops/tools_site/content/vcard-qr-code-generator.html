What is inside a contact QR code


A vCard QR code is a vCard written out as text and drawn as a QR code. The card starts with BEGIN:VCARD and ends with END:VCARD, and each line is a property: N holds the structured name, FN the name as it should be displayed, TEL a phone number with a type such as CELL, and so on. Scanning the code hands the phone the same text a .vcf file would contain, and the phone offers to save the contact.


The standard asks for lines to end in a carriage return and a line feed, so the file and the code use that. Values are escaped: a backslash, comma or semicolon gets a backslash in front, and a line break in the note becomes \n. The name and address are lists of parts separated by semicolons, so a semicolon typed into one part cannot spill into the next.


QR codes grow in steps called versions, from 1 (21 by 21 modules) to 40 (177 by 177). Every extra character may push a code to the next version. A card with only a name, phone and email is a modest version and scans easily on a small print. Adding a street address and a long note can double the width. If the code is dense, drop fields you can live without or choose a lower error correction level.
