    Borders, padding and rounded corners

    A border is drawn outside the picture, so it adds to the image size rather than covering any of it. Padding is an optional second band between the picture and the border, in its own colour. A thin dark border plus a wide white padding gives the classic photo-print look; a wide border with no padding gives a plain frame.

    Giving pixel values means every image gets the same border even when the images differ in size, which is handy for a set that will sit side by side. Percent values scale with each picture instead, so a small thumbnail and a large photo keep the same proportions. The preview shows the first image reduced, with the border scaled to match.

    Rounded corners need pixels that are not part of the picture. PNG and WebP can leave them transparent, so the picture sits cleanly on any background. JPEG has no transparency, which is why this tool asks for a colour to fill those corners with.

    Tips

    • Make a set of pictures the same size before framing them with Resize image.
    • To place framed pictures next to each other, use Merge images.
    • For a round profile picture, crop to a square first, then set the radius to 50%.
