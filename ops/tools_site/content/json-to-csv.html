Turning JSON into a spreadsheet

APIs and exports often hand you JSON, while the people who need the data want a spreadsheet. CSV bridges the two: each object in the array becomes a row and each key becomes a column. Because objects in real data rarely all have the same keys, the tool collects every key it sees, in the order it first sees them, and leaves a cell empty where an object has no value for that column.

Spreadsheets are flat, so nested data has to be squeezed into columns somehow. Flattening turns user.name and user.email into separate columns, which suits most reports. Keeping nested objects as JSON text keeps the column count down and lets you rebuild the original structure later.

The CSV follows the usual rules (RFC 4180): values are quoted only when needed and quotes inside a value are doubled. Numbers keep the exact digits from your JSON rather than being rounded the way JavaScript numbers would be.

Tips

  • Going the other way? Use CSV to JSON.
  • If the JSON won't convert, find the problem with the JSON formatter.
  • Compare two exports line by line with Compare text.
