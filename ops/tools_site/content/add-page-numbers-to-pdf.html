Adding page numbers without uploading the PDF

Page numbers are just small pieces of text drawn on top of each page. Your browser can do that directly: it opens the PDF with pdf-lib, adds a line of Helvetica text to every page you chose, and writes a new file. The original page content is left alone.

Each page can have its own size, crop box and rotation, so the position is worked out per page. Margins are measured from the edge of the visible area, and on a page stored sideways the number is turned with it so it still reads upright where you expect it.

Tips

  • Putting several files together first? Use Merge PDF, then number the result so the numbers run straight through.
  • Need a mark across the page rather than a number? Try Watermark PDF.
  • Pages in the wrong order? Fix that with Reorder pages before numbering.
