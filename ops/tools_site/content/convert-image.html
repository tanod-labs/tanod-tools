    Converting image formats in your browser

    An image file is a container plus a compression method. Converting means decoding the pixels from the old format and encoding them again in the new one. Your browser already has decoders and encoders for the common formats, so the conversion can run entirely on your device.

    PNG stores every pixel exactly and supports transparency, which makes it larger for photos. JPEG and WebP are lossy: they trade a little exactness for much smaller files, controlled by the quality setting. Converting a JPEG to PNG does not restore detail the JPEG already lost; it only stores the current pixels without further loss.

    Tips

    • After converting, shrink the file with Compress image.
    • Changing the pixel dimensions instead? Use Resize image.
    • Starting from a vector drawing? SVG to PNG renders it at any size.
