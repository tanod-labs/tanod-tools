What a favicon set contains

A favicon is the small icon in a browser tab, bookmark list or search result. Browsers look for a few different files: favicon.ico for older and general use, PNG icons at 16 and 32 pixels for tabs, a 180 pixel Apple touch icon for iPhone and iPad home screens, and 192 and 512 pixel icons for Android and installable web apps. A small site.webmanifest file lists the Android icons.

This tool draws each size separately from your original, so small sizes are scaled down from the full image rather than blown up from a tiny one. The .ico file is written as a container of three PNG images at 16, 32 and 48 pixels. Letter icons are drawn directly at each size, so edges stay sharp.

Tips

  • Use bold, simple shapes and strong contrast. Fine detail disappears at 16 pixels.
  • Want a square picture from part of a photo? Use Crop image with 1:1 first.
  • Need other sizes? Resize image gives you any width and height.
