How the comparison works

A diff finds the shortest list of edits that turns the original into the changed text. Matching stretches are left alone; what is left over is shown as removed from the original and added in the new version. This tool uses the open-source jsdiff library, which runs in your browser.

When a block of lines is replaced, the old and new versions are shown on the same rows in side-by-side view so you can read them across. On a phone the two sides stack. "Open a .txt file" fills whichever box you used last.

Tips

  • Compare lists after cleaning them with Remove duplicate lines.
  • Make the same edit everywhere first with Find and replace.
  • Comparing two data exports? Convert them first with JSON to CSV so each record sits on one line.
  • Press Swap to see the comparison the other way round.
