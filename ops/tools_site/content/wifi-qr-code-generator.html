What a Wi-Fi QR code contains


A Wi-Fi QR code is ordinary text in a fixed layout: WIFI:T:WPA;S:name;P:password;;. The letters before each colon are the field: T for the security type, S for the network name, P for the password and H for a hidden network. Phone cameras recognise the WIFI: prefix and offer to join, so the person scanning never types the password.


Because fields are split on semicolons and colons, those characters, plus the backslash, comma and double quote, must be escaped with a backslash when they appear in a name or password. Getting this wrong is the usual reason a code works for a simple password and fails for a complicated one. The readout above shows the final text so you can see what was escaped. For an open network the password field is left out entirely.


The printable card puts the code on a plain white background with the network name beneath it, using the same Archivo typeface as the rest of this site. It is a fixed 900 by 1100 pixel PNG, which prints sharply at about 8 by 10 cm at 280 dots per inch, and larger if you accept a softer edge on the text.
