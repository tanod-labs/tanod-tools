How text becomes ones and zeros

Computers store text as numbers. An encoding decides which number each character gets; this tool uses UTF-8, which is what nearly every web page, email and modern file uses. UTF-8 stores the first 128 characters (the English alphabet, digits and common punctuation) in one byte each, with the same values as the older ASCII code. Other characters take two to four bytes: é is 11000011 10101001 and the emoji 😀 is four bytes.

A byte is eight bits, so each byte is shown as eight binary digits, with leading zeros kept so every group is the same width. That makes the output easy to read back: each group of eight is one byte.

To decode, the tool reads each group as a byte, then reads the bytes as UTF-8 text. If the bytes don't form valid UTF-8, it says where the problem starts instead of showing garbled characters.
