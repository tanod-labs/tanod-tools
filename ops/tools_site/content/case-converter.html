Changing text case without retyping

Pick a style and the text in the box is rewritten in place, so you can chain conversions: lower-case a shouted paragraph, then turn it into Sentence case. Undo keeps the last twenty versions in memory while the page is open.

The programming styles (camelCase, PascalCase, snake_case, kebab-case, CONSTANT_CASE) treat each line as its own name, so a list of phrases becomes a list of identifiers. Capital letters inside words are treated as word boundaries, which lets you move a name from one style to another.

Tips

  • Count what you have with the Word counter.
  • Replace many words at once with Find and replace.
  • See what the conversion changed with Compare text.
