How Markdown becomes HTML

Markdown is a way of writing formatted text with plain characters: a # starts a heading, **two asterisks** make bold, a line starting with a dash is a list item. It is what README files, many note apps and most developer forums use. Browsers, email templates and content systems want HTML, so at some point the Markdown has to be translated.

This converter follows CommonMark with the GitHub Flavored Markdown additions, so tables, task lists and strikethrough work the way they do on GitHub. The HTML it produces is then passed through a sanitiser, which removes anything that could run code when the HTML is shown, while leaving ordinary formatting alone.

The preview tab shows the same HTML rendered in the page. Links open in a new tab, and images hosted elsewhere are shown as placeholders rather than fetched, so nothing you write is sent to another site while you work.
