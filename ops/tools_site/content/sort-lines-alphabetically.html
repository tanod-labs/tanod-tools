Putting a list in alphabetical order

Each line of the input is one item. The tool sorts the lines and shows the result next to the input as you type, so you can try a different order or option and see the effect straight away. Lines are compared whole, from the first character, so a list of names sorts by first name unless the surname comes first on each line.

Alphabetical sorting uses your browser's language rules, which handle accents and mixed case sensibly. Natural order is best for anything with numbers in it, such as file names, chapter titles or version numbers. Character code order matches what many programming tools and spreadsheets do with a plain sort: every capital letter comes before every lower-case one.

When two lines compare as equal, for example "Apple" and "apple" with Ignore case on, they stay in the order they were in, so sorting twice gives the same result.

Tips

  • Strip numbering or bullet characters before sorting with Find and replace, so they don't decide the order.
  • Check what changed between two versions of a list with Compare text.
  • Need the list on one line again? Use Remove line breaks with a comma as the separator.
