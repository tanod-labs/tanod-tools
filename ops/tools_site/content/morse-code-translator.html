Morse code in brief

Morse code writes each letter as a short pattern of short and long signals, dots and dashes. Common letters get short codes: E is a single dot and T a single dash, while rarer letters such as Q (--.-) take four signals. The version used here is the international Morse code standardised by the ITU, which is the one radio amateurs, pilots and sailors learn.

Timing is part of the code. A dash lasts three times as long as a dot, the gap inside a letter is one dot long, the gap between letters three dots and the gap between words seven. In writing, a space stands for the gap between letters and a slash for the gap between words.

Morse code has no capital letters, so decoded text comes out in capitals, the way operators traditionally write it down.
