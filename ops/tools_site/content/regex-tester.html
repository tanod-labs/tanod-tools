Testing patterns safely


The tester builds a JavaScript RegExp from your pattern and flags and runs it in a background worker, the same engine your code will use in this browser. Matches come back with their start position and every capture group, and the page draws them over your text with alternating highlights so neighbouring matches stay distinguishable. An empty match, such as the one \b or a* can produce, shows as a thin bar.


Running the pattern in a worker matters because a regular expression can take exponential time. If a pattern is still running after 2 seconds, the worker is stopped and you get a message instead of a frozen tab. The same safeguard protects Find and replace.


Positions are counted in UTF-16 code units, which is how JavaScript strings count: an emoji or other character outside the basic plane takes two. The list shows the first 1,000 matches; the total count above it includes every match.
