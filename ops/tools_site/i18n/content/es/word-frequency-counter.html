Cómo se cuenta la frecuencia de palabras

El texto se divide en palabras, cada palabra se pasa a minúsculas y la herramienta cuenta cuántas veces aparece cada una. La lista ordenada pone primero las más frecuentes y desempata por orden alfabético. Contar cuánto se repiten las palabras es una forma rápida de ver de qué trata realmente un texto, de comprobar si una palabra clave se usa en exceso, de encontrar los términos de una entrevista o de un conjunto de respuestas de encuesta, o de detectar una manía como apoyarse siempre en la misma palabra en un ensayo.

Sin ningún filtro, la parte superior de la lista suele estar llena de palabras funcionales como the, of y and. Al elegir un idioma de palabras vacías se quitan, y las palabras con contenido suben a los primeros puestos. Las listas abarcan los artículos, pronombres, preposiciones, conjunciones y verbos auxiliares más comunes del idioma y sirven para echar un vistazo rápido, no para trabajo lingüístico.

Las frases se cuentan como grupos de dos o tres palabras seguidas, dentro de una misma oración. Las frases repetidas suelen decir más que las palabras sueltas: revelan nombres de productos, eslóganes y expresiones fijas de un texto. Con las palabras vacías activadas, se descartan las frases que empiezan o terminan con una palabra vacía, así que lo que queda es más significativo.

El porcentaje de un elemento es su cantidad dividida entre el total contado. Ese total cambia con las opciones, porque las palabras vacías y los números que se dejan fuera no se cuentan. Descarga el CSV para conservar la lista completa o para hacer un gráfico en una hoja de cálculo.

Consejos

  • Para los totales de palabras, caracteres, oraciones y tiempo de lectura, usa el contador de palabras.
  • Para distinguir mayúsculas de minúsculas a tu manera, cambia antes el uso de mayúsculas con el conversor de mayúsculas y minúsculas.
  • Limpia una lista de elementos repetidos con Eliminar líneas duplicadas.
