Cómo se convierte aquí una página web en PDF

Para pasar una página web a PDF, nuestro servidor inicia una copia nueva y aislada del navegador Chromium, abre la dirección que indicaste, espera a que la página termine de cargar y la imprime en PDF con tu tamaño de papel y orientación, igual que lo haría el cuadro de diálogo Imprimir de tu navegador. Ese navegador solo puede acceder a ese sitio, nunca a redes privadas, y se descarta después de cada tarea.

Consejos

  • Las páginas fáciles de leer, como los artículos con vista de impresión, dan los PDF más limpios.
  • ¿Quieres varias páginas en un solo archivo? Convierte cada una y luego únelas con Unir PDF (en tu navegador).
  • ¿Necesitas el texto en lugar de un PDF? HTML a Markdown convierte el HTML que pegues en tu dispositivo.
