Eliminar duplicados y ordenar líneas

Las listas acumulan repeticiones: correos electrónicos pegados de varias fuentes, palabras clave, líneas de registro, nombres de archivo. Esta herramienta para eliminar líneas duplicadas lee el texto línea por línea, recuerda cada línea que ya vio y descarta las copias posteriores (o las anteriores, si eliges conservar la última aparición). Las líneas que quedan mantienen su orden original, a menos que elijas un orden.

El informe que aparece sobre los botones muestra cuántas líneas entraron, cuántas salieron y cuántas se eliminaron por estar duplicadas, para que compares el resultado con lo que esperabas. Las líneas vacías que elimina la opción se informan por separado.

Consejos

  • Para limpiar las líneas antes, usa Buscar y reemplazar y luego vuelve aquí.
  • Revisa qué cambió entre dos versiones de una lista con Comparar textos.
  • ¿Solo necesitas la lista ordenada, con más opciones de orden? Usa Ordenar líneas alfabéticamente.
  • Cuenta lo que queda con el Contador de palabras.
