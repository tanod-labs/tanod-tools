Convertir páginas web en Markdown

Llevar contenido de una página web, un CMS antiguo o un editor de texto enriquecido a un README, un sitio estático o una app de notas normalmente implica convertir HTML a Markdown. El conversor recorre la estructura del HTML y escribe cada elemento en su forma Markdown: los encabezados se convierten en líneas con #, las listas en guiones, los enlaces en [texto](url) y <pre><code> en un bloque de código.

Markdown solo describe la estructura, así que el estilo se queda atrás. Los estilos en línea, las clases, los colores y los contenedores de diseño desaparecen, mientras que las palabras, el énfasis, los enlaces, las imágenes y las listas se conservan. Las tablas se escriben como tablas de GitHub Flavored Markdown cuando son lo bastante simples para ese formato.

Cada proyecto prefiere sus propias costumbres de Markdown, por eso se pueden cambiar los estilos de encabezado, viñeta de lista, bloque de código y cursiva. La mayoría de los visores aceptan cualquiera de ellos.

Consejos

  • Revisa cómo se ve el Markdown con Markdown a HTML, que tiene vista previa.
  • Arregla espacios o palabras sobrantes con Buscar y reemplazar.
  • Cuenta las palabras del resultado con el Contador de palabras.
