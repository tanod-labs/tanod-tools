Cómo funciona la comparación

Para comparar textos, un diff busca la lista más corta de ediciones que convierte el original en el texto modificado. Los tramos que coinciden se dejan tal cual; lo que sobra se muestra como eliminado del original y agregado en la versión nueva. Esta herramienta usa la biblioteca de código abierto jsdiff, que funciona en tu navegador.

Cuando se reemplaza un bloque de líneas, la versión anterior y la nueva aparecen en las mismas filas en la vista lado a lado, para que puedas leerlas de un lado a otro. En un celular, los dos lados se apilan. "Abrir un archivo .txt" llena el último cuadro que usaste.

Consejos

  • Compara listas después de limpiarlas con Eliminar líneas duplicadas.
  • Haz primero el mismo cambio en todas partes con Buscar y reemplazar.
  • ¿Comparas dos exportaciones de datos? Conviértelas primero con JSON a CSV para que cada registro quede en una sola línea.
  • Presiona Intercambiar para ver la comparación al revés.
