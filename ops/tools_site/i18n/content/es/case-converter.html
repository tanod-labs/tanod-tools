Convertir mayúsculas y minúsculas sin volver a escribir

Elige un estilo y el texto del cuadro se reescribe ahí mismo, así que puedes encadenar conversiones: pasar a minúsculas un párrafo escrito todo en mayúsculas y luego convertirlo a tipo oración. Deshacer guarda en memoria las últimas veinte versiones mientras la página está abierta.

Los estilos de programación (camelCase, PascalCase, snake_case, kebab-case, CONSTANT_CASE) tratan cada línea como un nombre independiente, así que una lista de frases se convierte en una lista de identificadores. Las mayúsculas dentro de las palabras se tratan como límites entre palabras, lo que te permite pasar un nombre de un estilo a otro.

Consejos

  • Cuenta lo que tienes con el Contador de palabras.
  • Reemplaza muchas palabras a la vez con Buscar y reemplazar.
  • Mira qué cambió la conversión con Comparar textos.
  • ¿Vas a crear una dirección web a partir de un título? El Generador de slugs también convierte las tildes y elimina los signos de puntuación.
