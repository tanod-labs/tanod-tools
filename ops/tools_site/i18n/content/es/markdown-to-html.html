Cómo el Markdown se convierte en HTML

Markdown es una forma de escribir texto con formato usando caracteres simples: un # inicia un encabezado, **dos asteriscos** ponen el texto en negrita y una línea que empieza con un guion es un elemento de lista. Es lo que usan los archivos README, muchas apps de notas y la mayoría de los foros de desarrolladores. Los navegadores, las plantillas de correo y los gestores de contenido necesitan HTML, así que en algún momento hay que convertir el Markdown a HTML.

Este conversor sigue CommonMark con las extensiones de GitHub Flavored Markdown, así que las tablas, las listas de tareas y el tachado funcionan igual que en GitHub. El HTML que genera pasa luego por un limpiador, que elimina todo lo que podría ejecutar código cuando se muestra el HTML y deja intacto el formato común.

La pestaña de vista previa muestra ese mismo HTML renderizado en la página. Los enlaces se abren en una pestaña nueva, y las imágenes alojadas en otros sitios se muestran como marcadores en lugar de descargarse, así que nada de lo que escribes se envía a otro sitio mientras trabajas.
