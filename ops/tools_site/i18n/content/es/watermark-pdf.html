Poner una marca de agua a un PDF en tu navegador

Una marca de agua es un texto dibujado en cada página. Tu navegador abre el PDF con pdf-lib, calcula el área visible de cada página y dibuja ahí el texto con el color, la opacidad y el ángulo que elegiste. El resultado es un archivo nuevo; tu original queda como estaba.

El texto usa Helvetica, una de las fuentes que ya tiene cualquier visor de PDF, lo que mantiene pequeño el archivo resultante pero limita los caracteres al conjunto latino de Europa occidental. La ubicación en mosaico repite el texto en un patrón escalonado para que no se pueda eliminar recortando una esquina.

Consejos

  • Mantén la opacidad baja, entre un 20 y un 35 por ciento, para que la página se siga leyendo bien.
  • ¿También quieres números de página? Agrégalos con Numerar páginas de un PDF.
  • ¿Necesitas compartir una copia aplanada? Convierte las páginas en imágenes con PDF a JPG.
