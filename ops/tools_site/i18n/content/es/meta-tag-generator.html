Para qué sirve cada etiqueta

Un generador de meta tags te ahorra escribir a mano las etiquetas del head. El <title> y la meta description son la base con la que normalmente se arma un resultado de búsqueda. El enlace canonical les dice a los buscadores cuál es la dirección principal cuando se puede llegar a la misma página de varias formas, por ejemplo con parámetros de seguimiento. La etiqueta robots solo hace falta cuando quieres cambiar el comportamiento predeterminado de indexar la página y seguir sus enlaces.

Las etiquetas Open Graph se crearon para las vistas previas de enlaces y hoy las leen la mayoría de las apps de mensajería y redes sociales. El título, la descripción, la imagen y la URL son las cuatro que más importan; og:image:alt le da a la imagen una descripción en texto, y og:type suele ser website o article. La etiqueta de tarjeta de X elige entre una miniatura cuadrada pequeña (summary) y una imagen ancha (summary_large_image).

El texto se escapa a medida que se escribe, así que un ampersand se convierte en &amp; y una comilla doble en &quot;. Así la página sigue siendo válida y unas comillas sueltas no pueden cerrar un atributo antes de tiempo. Revisa la página terminada con una vista previa real al compartir antes de darla por buena, porque cada sitio guarda en caché la vista previa que obtuvo la primera vez.
