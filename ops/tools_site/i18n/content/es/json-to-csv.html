Convertir JSON en una hoja de cálculo

Las API y las exportaciones suelen entregarte JSON, mientras que quienes necesitan los datos quieren una hoja de cálculo. Convertir JSON a CSV une ambos mundos: cada objeto del array se convierte en una fila y cada clave en una columna. Como en los datos reales los objetos rara vez tienen todos las mismas claves, la herramienta reúne todas las claves que encuentra, en el orden en que las ve por primera vez, y deja la celda vacía cuando un objeto no tiene valor para esa columna.

Las hojas de cálculo son planas, así que los datos anidados tienen que acomodarse en columnas de alguna manera. Aplanar convierte user.name y user.email en columnas separadas, lo que sirve para la mayoría de los informes. Conservar los objetos anidados como texto JSON mantiene bajo el número de columnas y te permite reconstruir la estructura original más adelante.

El CSV sigue las reglas habituales (RFC 4180): los valores se ponen entre comillas solo cuando hace falta y las comillas dentro de un valor se duplican. Los números conservan los dígitos exactos de tu JSON en lugar de redondearse como pasaría con los números de JavaScript.
