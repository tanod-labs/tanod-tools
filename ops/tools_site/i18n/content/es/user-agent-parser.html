Client Hints de tu navegador

Lo que un user agent te dice y lo que oculta

El user agent (agente de usuario) nació como una forma de que el servidor viera qué navegador hacía la solicitud, para enviarle una página que funcionara en él. Luego los navegadores copiaron los nombres de los otros para recibir las buenas páginas, y por eso una cadena de Chrome hoy dice también Mozilla, AppleWebKit, KHTML, Gecko y Safari. Un analizador de user agent resuelve esto probando patrones en un orden cuidadoso y eligiendo la coincidencia más específica.

Además, la cadena se está recortando a propósito. La reducción del User-Agent de Chrome fija la versión de Windows en NT 10.0, la de macOS en 10_15_7, el modelo de Android en K y el número de compilación en 0.0.0, para que la cadena deje de ser una buena huella digital. Los datos no han desaparecido: una página que los pide mediante Client Hints obtiene la versión de la plataforma, la arquitectura, el modelo y la versión completa del navegador, y el navegador del visitante decide si responde.

Usa la cadena para decisiones generales y para logs, no para dar confianza. Los rastreadores y las herramientas de línea de comandos como curl envían sus propias cadenas cortas, y cualquier cosa se puede falsificar. Si persigues un error de diseño, detectar funciones en la página es más fiable que leer el nombre del navegador.

Consejos

  • ¿Un log del servidor lleno de respuestas 403 o 429 para un mismo cliente? Busca los códigos en Códigos de estado HTTP.
  • Los user agents en URL o cadenas de consulta suelen estar codificados por porcentaje; decodifícalos con Codificar y decodificar URL.
  • Los encabezados copiados de una solicitud a veces llevan valores en Base64; léelos con Codificar y decodificar Base64.
