Formatear y validar JSON


JSON es un formato de texto pequeño y estricto para datos: objetos entre llaves, arrays entre corchetes y valores que son cadenas, números, true, false o null. A las máquinas no les importan los espacios en blanco, pero a las personas sí, así que un formateador de JSON agrega sangría y saltos de línea para que los datos anidados se puedan leer, y un minificador los quita para ahorrar espacio.


Esta herramienta lee tu texto con su propio analizador, así que puede señalar el carácter exacto donde algo falla. Los errores más comunes son una coma sobrante después del último elemento, comillas simples en lugar de dobles, una clave sin comillas, un comentario o un corchete que falta al final. El error muestra la línea y la columna, una copia de esa línea y un signo ^ bajo la posición.


Formatear solo cambia los espacios en blanco. Los números y los escapes de las cadenas se conservan tal como están escritos, así que un identificador largo como 12345678901234567890 no se redondea como pasaría si los datos se leyeran como números de JavaScript.
