El código morse en pocas palabras

El código morse escribe cada letra como un patrón breve de señales cortas y largas: puntos y rayas. Las letras frecuentes tienen códigos cortos: la E es un solo punto y la T una sola raya, mientras que letras menos comunes como la Q (--.-) llevan cuatro señales. Este traductor de código morse usa el código morse internacional estandarizado por la UIT, que es el que aprenden los radioaficionados, los pilotos y los marinos.

Los tiempos forman parte del código. Una raya dura tres veces más que un punto, la pausa dentro de una letra dura un punto, la pausa entre letras tres puntos y la pausa entre palabras siete. Por escrito, un espacio representa la pausa entre letras y una barra la pausa entre palabras.

El código morse no tiene mayúsculas ni minúsculas, así que el texto decodificado sale en mayúsculas, como lo anotan tradicionalmente los operadores.
