De filas CSV a JSON

CSV es el mínimo común denominador de los datos: cualquier hoja de cálculo o base de datos puede exportarlo. JSON es lo que esperan la mayoría de las API web, los scripts y los archivos de configuración. Para convertir CSV a JSON, esta herramienta lee el archivo con un analizador que sigue el estándar CSV, así que una coma dentro de una dirección entre comillas o un salto de línea dentro de un comentario entre comillas se queda en su celda en lugar de partir la fila.

Con una fila de encabezado, cada línea se convierte en un objeto cuyas claves son los nombres de las columnas, en el orden de las columnas. Sin encabezado, cada línea se convierte en un array. Los valores se conservan como texto a menos que pidas convertir números y true/false, porque un archivo CSV no lleva tipos y una suposición automática puede convertir sin avisar un código postal como 02134 en el número 2134.

La línea debajo de las opciones te dice cuántas filas y columnas se leyeron y qué delimitador se usó. Si algunas filas tienen más o menos campos que el encabezado, una nota indica qué líneas, lo que suele apuntar a un delimitador suelto o a unas comillas sin cerrar en el origen.
