Cómo se escribe una tabla Markdown

Una tabla Markdown de GitHub es texto plano: una fila de encabezado, una fila de guiones que define la alineación y una línea por cada fila de datos, con las celdas separadas por barras verticales. Es el formato que GitHub muestra en READMEs, issues y pull requests, y muchas otras herramientas, como sitios de documentación y apps de notas, también lo entienden.

La cuadrícula contiene las celdas; la primera fila es el encabezado. Cada columna tiene una alineación. La izquierda se escribe :---, el centro :---:, la derecha ---: y la ausencia de alineación son guiones simples. El texto de las celdas se escapa cuando hace falta: una barra vertical pasa a ser \| y un salto de línea pasa a ser la etiqueta HTML <br>. Después la herramienta alinea las columnas con espacios para que el código se lea como una tabla, usando el ancho de cada carácter y no su tamaño en bytes, de modo que las letras con tilde también cuadren.

Pegar desde una hoja de cálculo es la forma más rápida de empezar. Las hojas de cálculo copian las celdas al portapapeles como texto separado por tabulaciones, con una línea por fila, y la cuadrícula lo lee directamente. Los archivos CSV y TSV funcionan igual a través del cuadro de pegado, con campos entre comillas y saltos de línea entre comillas incluidos. Si pegas una tabla Markdown existente, las celdas y las alineaciones se leen de vuelta en la cuadrícula para que puedas modificarlas.
