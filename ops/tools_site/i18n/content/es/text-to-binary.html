Cómo el texto se convierte en unos y ceros

Las computadoras guardan el texto como números. Una codificación decide qué número recibe cada carácter; para convertir texto a binario, esta herramienta usa UTF-8, que es la que usan casi todas las páginas web, los correos y los archivos modernos. UTF-8 guarda los primeros 128 caracteres (el alfabeto inglés, los dígitos y la puntuación común) en un byte cada uno, con los mismos valores que el antiguo código ASCII. Los demás caracteres ocupan de dos a cuatro bytes: é es 11000011 10101001 y el emoji 😀 ocupa cuatro bytes.

Un byte tiene ocho bits, así que cada byte se muestra como ocho dígitos binarios, conservando los ceros a la izquierda para que todos los grupos tengan el mismo ancho. Eso hace que el resultado sea fácil de volver a leer: cada grupo de ocho es un byte.

Para decodificar, la herramienta lee cada grupo como un byte y luego lee los bytes como texto UTF-8. Si los bytes no forman UTF-8 válido, indica dónde empieza el problema en lugar de mostrar caracteres ilegibles.
