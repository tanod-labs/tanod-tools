Probar patrones de forma segura


Este probador de regex construye un RegExp de JavaScript con tu patrón y tus flags y lo ejecuta en un worker en segundo plano, el mismo motor que usará tu código en este navegador. Las coincidencias vuelven con su posición inicial y cada grupo de captura, y la página las dibuja sobre tu texto con resaltados alternos para que las coincidencias vecinas se distingan. Una coincidencia vacía, como la que pueden producir \b o a*, se muestra como una barra delgada.


Ejecutar el patrón en un worker es importante porque una expresión regular puede tardar un tiempo exponencial. Si un patrón sigue ejecutándose después de 2 segundos, el worker se detiene y recibes un mensaje en lugar de una pestaña congelada. La misma protección se aplica en Buscar y reemplazar.


Las posiciones se cuentan en unidades de código UTF-16, que es como cuentan las cadenas de JavaScript: un emoji u otro carácter fuera del plano básico ocupa dos. La lista muestra las primeras 1.000 coincidencias; el total que aparece arriba incluye todas.
