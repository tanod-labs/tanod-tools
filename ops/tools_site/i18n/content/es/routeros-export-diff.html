Cómo leer el diff de una configuración de RouterOS

Un export es la configuración del router escrita como los comandos que la recrearían: una línea de menú como /ip firewall filter seguida de los comandos add y set de ese menú. Solo aparecen los ajustes que difieren de los valores por defecto, lo que mantiene los exports cortos pero hace que un ajuste que volvió a su valor por defecto simplemente desaparezca del export más reciente. El diff trata cada menú como una sección, compara sus comandos en orden y resalta las secciones que cambiaron.

Algunas diferencias son ruido y no cambios: el encabezado con la fecha del export, el ID de software y el número de serie se descarta, las líneas cortadas se unen, y las líneas de comentario se pueden ignorar. Lo que queda es lo que el router haría de forma distinta. El orden se conserva a propósito: las reglas de firewall, NAT, mangle y queue se procesan de arriba hacia abajo, así que mover una regla es un cambio real.

Consejos

  • Guarda un export con fecha después de cada ventana de cambios y compáralo con el anterior para ver exactamente qué se hizo.
  • ¿Verificando una actualización de v6 a v7? Compara el script convertido del asistente de migración con un export tomado después de la actualización.
  • Para texto simple que no es un export, el comparador de texto general también compara palabra por palabra.
