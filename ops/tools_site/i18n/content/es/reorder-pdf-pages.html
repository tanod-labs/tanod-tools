Poner las páginas de un PDF en orden

Las páginas quedan desordenadas todo el tiempo: escaneos a doble cara, documentos armados a partir de varias fuentes, una página de firmas que va al final. Aquí ves cada página como una miniatura y la mueves a donde corresponde.

El PDF nuevo se crea copiando las páginas en tu orden. No se cambia nada en las páginas, y los enlaces, el texto y las imágenes se mantienen intactos.

Consejos

  • ¿Vas a combinar varios archivos en un orden concreto? Unir PDF te deja ordenar primero los archivos.
  • Después de reordenar, usa Numerar páginas de un PDF para que el orden se vea en papel.
