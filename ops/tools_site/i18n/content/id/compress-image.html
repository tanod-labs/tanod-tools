Letakkan gambar di sini

PNG, JPEG, WebP, GIF, BMP, atau AVIF. Atau seret ke mana saja di halaman ini.

    Format output

    Pertahankan menyimpan JPEG, WebP, dan PNG dalam formatnya sendiri; format lain menjadi PNG.

    Berlaku untuk output JPEG dan WebP. JPEG tidak mendukung transparansi, jadi area transparan menjadi putih.

    Lossy. Paling cocok untuk logo, screenshot, dan grafik datar.

    Cara kerja kompresi gambar di sini

    Saat Anda mengompres foto, yang dikecilkan adalah data pikselnya, karena sebagian besar ukuran file gambar berasal dari situ. JPEG dan WebP memperkecilnya dengan membuang detail yang paling kecil kemungkinannya disadari mata; pengaturan kualitas menentukan seberapa banyak yang dibuang. PNG bersifat lossless, jadi ukurannya bergantung pada seberapa mudah piksel-pikselnya diprediksi. Mengurangi PNG menjadi palet maksimal 256 warna membuat datanya jauh lebih mudah dikompres, dengan konsekuensi warnanya tidak lagi persis sama.

    Alat ini mendekode setiap gambar dengan browser Anda, menggambarnya ke kanvas, dan menyimpannya kembali, memakai encoder JPEG dan WebP bawaan browser Anda. Untuk PNG berpalet, alat ini memilih warna dengan quantiser open source UPNG.js dan menulis file PNG-nya sendiri. Jika hasilnya tidak lebih kecil dari file yang Anda berikan, Anda mendapatkan kembali file asli Anda.

    Tips

    • Foto berukuran besar paling banyak menyusut jika dimensinya juga dikurangi: coba Ubah ukuran gambar dulu, lalu kompres.
    • Perlu format lain? Konversi gambar mendukung PNG, JPEG, dan WebP.
    • Untuk menghapus lokasi dan detail kamera tanpa mengompres ulang, gunakan Hapus data EXIF.
