Untuk apa Base64


Encode dan decode Base64 dipakai untuk menuliskan urutan byte apa pun dengan 64 karakter teks yang aman: A-Z, a-z, 0-9, plus dan garis miring. Setiap 3 byte menjadi 4 karakter, dengan padding = untuk mengisi kelompok terakhir. Hasilnya, data biner aman ditaruh di email, JSON, HTML, URL dan tempat lain yang hanya menangani teks. Base64 adalah encoding, bukan enkripsi: siapa pun bisa membaliknya.


Teks diubah dulu menjadi byte, dan encoding karakternya berpengaruh. Alat ini memakai UTF-8, standar di web, sehingga teks non-Inggris dan simbol tetap utuh bolak-balik. Saat decode, alat ini memeriksa apakah hasilnya UTF-8 yang valid dan memberi tahu Anda jika tidak, yang biasanya berarti datanya berupa file, bukan teks.


Mode File membaca file di browser Anda dan meng-encode-nya dalam potongan kecil agar halaman tetap responsif. Untuk arah sebaliknya, alat ini men-decode Base64 yang ditempel menjadi byte dan memberikannya kepada Anda sebagai unduhan. Alat ini melihat byte pertama untuk menyarankan ekstensi file bagi format umum seperti PNG, JPEG, GIF, PDF dan ZIP.
