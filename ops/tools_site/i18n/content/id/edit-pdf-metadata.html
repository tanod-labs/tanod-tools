Apa itu metadata PDF, dan mengapa Anda mungkin perlu mengubahnya

Setiap PDF bisa membawa beberapa kolom deskriptif: judul, penulis, subjek, kata kunci, program yang membuatnya, serta tanggal dibuat dan terakhir diubah. Kolom-kolom ini tersimpan di kamus informasi dokumen, dan banyak program juga menulis salinan kedua sebagai paket XMP, yaitu blok XML yang dilampirkan ke file.

Kolom-kolom ini muncul di properti file, hasil pencarian, dan tab browser, jadi judul yang salah atau nama penulis yang terlupa bisa memalukan saat dokumen sampai ke tangan orang lain. Alat untuk mengedit metadata PDF ini membacanya di browser Anda, memungkinkan Anda memperbaikinya, atau mengosongkannya. Isi halaman tidak pernah diubah.

Tips

  • Ingin membersihkan metadata dari foto? Gunakan Hapus data EXIF.
  • Menggabungkan file? Gabungkan PDF membuat dokumen baru, jadi atur judulnya setelah itu di sini.
