Letakkan faktur elektronik di sini

XML, PDF yang berisi faktur (ZUGFeRD, Factur-X), atau .p7m bertanda tangan. Atau seret ke mana saja di halaman ini.

    
    
    Hanya bagian awal file yang panjang ditampilkan di sini. Unduh XMLnya untuk mendapatkan seluruh isinya.
    
  
    

    

    


    PDF yang sekaligus faktur
    

    File ZUGFeRD atau Factur-X tampak seperti PDF faktur biasa, tetapi membawa salinan kedua faktur dalam bentuk XML, yang dilampirkan pada PDF seperti lampiran email pada sebuah pesan. Manusia membaca halamannya; program membaca XML-nya. Sejak 1 Januari 2025 setiap usaha di Jerman wajib mampu menerima faktur elektronik terstruktur, dan Prancis mewajibkan hal yang sama mulai 1 September 2026, sehingga PDF hibrida seperti ini kini makin sering ditemui.
    

    Halaman ini membuka PDF di browser Anda, membaca daftar file terlampir, lalu mencoba file XML dengan urutan berikut: factur-x.xml, zugferd-invoice.xml, xrechnung.xml, lalu file XML lainnya. File pertama yang berupa faktur dalam format yang didukung akan ditampilkan. Halaman PDF-nya sendiri tidak digambar.
    

    Profil
    

    Profil menunjukkan seberapa banyak data yang dimuat XML. MINIMUM dan BASIC WL hanya berisi data kepala dan total. BASIC menambahkan baris item. EN 16931 (pada ZUGFeRD lama disebut COMFORT) adalah standar Eropa lengkap. EXTENDED melampauinya, dan XRECHNUNG adalah profil sektor publik Jerman. Halaman ini menampilkan isi setiap file dan tidak memeriksanya terhadap aturan profil.
    

    Tips
    

      
  
    • Jika PDF faktur tidak memiliki lampiran, minta XML-nya atau versi ZUGFeRD / Factur-X kepada pengirim.
      • 
  
    • File XML polos dari standar yang sama juga bisa dibuka di sini; XML XRechnung juga dibaca oleh Penampil XRechnung.
      • 
  
    • Gunakan Unduh XML untuk menyimpan data terstruktur yang ada di dalam PDF.
