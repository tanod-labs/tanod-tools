Cara halaman web diubah menjadi PDF di sini

Untuk mengubah halaman web ke PDF, server kami menjalankan salinan baru browser Chromium dalam sandbox, membuka alamat yang Anda berikan, menunggu halaman selesai dimuat, lalu mencetaknya ke PDF dengan ukuran kertas dan orientasi pilihan Anda, sama seperti dialog Cetak di browser Anda. Browser itu hanya bisa menjangkau satu situs tersebut, tidak pernah jaringan pribadi, dan dibuang setelah setiap tugas.

Tips

  • Halaman yang ramah pembaca, seperti artikel dengan tampilan cetak, menghasilkan PDF yang paling rapi.
  • Ingin beberapa halaman dalam satu file? Konversi masing-masing, lalu satukan dengan Gabungkan PDF (di browser Anda).
  • Perlu teksnya, bukan PDF? HTML ke Markdown mengonversi HTML yang ditempel di perangkat Anda.
