Letakkan file WebP di sini

Gambar .webp, satu atau banyak. Atau seret ke mana saja di halaman ini.

    Konversi ke

    JPG tidak bisa transparan, jadi area tersebut diisi dengan warna ini.

    Mengapa gambar WebP perlu dikonversi

    Mengubah WebP ke PNG membuat gambar bisa dibuka di mana saja. WebP adalah format web: punya mode lossy untuk foto dan mode lossless untuk grafik, keduanya dengan transparansi, dan membuat halaman dimuat lebih cepat. Di luar browser, dukungannya belum merata. WebP yang disimpan dari situs belanja atau artikel berita bisa saja gagal dibuka di editor lama, ditolak saat dilampirkan ke formulir, atau tidak bisa dicetak dari aplikasi desktop.

    Halaman ini membaca WebP dengan decoder bawaan browser Anda, yang sudah memahami kedua mode dan transparansi, lalu menulis pikselnya sebagai PNG. Tidak ada yang diunggah, jadi alat ini juga cocok untuk gambar yang tidak ingin Anda kirim ke server konversi.

    Tips

    • Mengonversi foto? JPG menghasilkan file yang jauh lebih kecil daripada PNG; ganti format output di atas, atau gunakan PNG ke JPG nanti.
    • Perlu gambar sebagai teks untuk HTML atau CSS? Gunakan Gambar ke Base64.
    • Format lain, termasuk AVIF dan BMP, ditangani oleh Konversi gambar.
