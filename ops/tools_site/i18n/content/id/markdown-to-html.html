Bagaimana Markdown menjadi HTML

Markdown adalah cara menulis teks berformat dengan karakter biasa: # memulai heading, **dua tanda bintang** membuat teks tebal, baris yang diawali tanda pisah adalah item daftar. Format ini dipakai file README, banyak aplikasi catatan, dan sebagian besar forum developer. Browser, template email, dan sistem konten membutuhkan HTML, jadi pada suatu saat Markdown harus dikonversi ke HTML.

Konverter ini mengikuti CommonMark dengan tambahan GitHub Flavored Markdown, sehingga tabel, daftar tugas, dan teks coret bekerja seperti di GitHub. HTML yang dihasilkan lalu dilewatkan ke sanitizer, yang menghapus apa pun yang bisa menjalankan kode saat HTML ditampilkan, sementara format biasa dibiarkan.

Tab pratinjau menampilkan HTML yang sama dalam bentuk render di halaman. Tautan terbuka di tab baru, dan gambar yang di-hosting di tempat lain ditampilkan sebagai placeholder alih-alih diambil, sehingga tidak ada yang Anda tulis dikirim ke situs lain selama Anda bekerja.

Tips

  • Punya HTML dan ingin Markdown? Gunakan HTML ke Markdown.
  • Periksa panjang tulisan dengan Penghitung kata.
  • Bandingkan dua draf dengan Bandingkan teks.
