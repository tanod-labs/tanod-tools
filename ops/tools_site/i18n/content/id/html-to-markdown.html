Mengubah halaman web menjadi Markdown

Memindahkan konten dari halaman web, CMS lama, atau editor rich text ke README, situs statis, atau aplikasi catatan biasanya berarti mengonversi HTML ke Markdown. Konverter ini menelusuri struktur HTML dan menulis setiap elemen dalam bentuk Markdown-nya: heading menjadi baris #, daftar menjadi tanda pisah, tautan menjadi [text](url), dan <pre><code> menjadi blok kode.

Markdown hanya menggambarkan struktur, jadi gaya tampilan ditinggalkan. Gaya inline, kelas, warna, dan kontainer tata letak hilang, sedangkan kata-kata, penekanan, tautan, gambar, dan daftar tetap ada. Tabel ditulis sebagai tabel GitHub Flavored Markdown jika cukup sederhana untuk format tersebut.

Setiap proyek punya kebiasaan Markdown yang berbeda, karena itu gaya heading, penanda daftar, blok kode, dan huruf miring bisa diubah. Sebagian besar renderer menerima semuanya.

Tips

  • Periksa tampilan Markdown dengan Markdown ke HTML, yang memiliki pratinjau.
  • Rapikan sisa spasi atau kata dengan Cari dan ganti.
  • Hitung jumlah kata di hasilnya dengan Penghitung kata.
