Memformat dan memeriksa JSON


JSON adalah format teks yang ringkas dan ketat untuk data: objek dalam kurung kurawal, array dalam kurung siku, dan nilai berupa string, angka, true, false atau null. Mesin tidak peduli pada spasi, tetapi manusia peduli, jadi JSON formatter menambahkan indentasi dan jeda baris agar data bersarang mudah dibaca, sedangkan minifier menghapusnya untuk menghemat ruang.


Alat format dan validasi JSON ini membaca teks Anda dengan parser-nya sendiri, sehingga bisa menunjuk karakter persis tempat kesalahan terjadi. Kesalahan yang paling umum adalah koma berlebih setelah item terakhir, tanda kutip tunggal alih-alih tanda kutip ganda, kunci tanpa tanda kutip, komentar, atau kurung yang hilang di akhir. Pesan error menampilkan baris dan kolom, salinan baris tersebut, dan tanda ^ di bawah posisinya.


Pemformatan hanya mengubah spasi kosong. Angka dan escape string dipertahankan seperti tertulis, jadi ID panjang seperti 12345678901234567890 tidak dibulatkan seperti yang akan terjadi jika data dibaca sebagai angka JavaScript.


Tips


    
  
  • Membandingkan dua versi konfigurasi? Format keduanya dengan opsi yang sama, lalu gunakan Bandingkan teks.

  • Ada nilai Base64 di dalam JSON Anda? Dekode dengan Encode dan decode Base64.

  • Butuh datanya di spreadsheet? Gunakan JSON ke CSV, atau CSV ke JSON untuk arah sebaliknya.
