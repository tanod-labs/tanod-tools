Membuat SQL mudah dibaca


Database membaca query dengan cara yang sama baik ditulis dalam satu baris maupun empat puluh baris, karena itu query yang ditempel dari log, ORM, dan alat monitoring sering datang sebagai satu string panjang tanpa jeda. Alat format SQL ini menaruh setiap klausa utama (SELECT, FROM, WHERE, GROUP BY, ORDER BY) di barisnya sendiri dan mengindentasi kolom, kondisi, dan subquery di bawahnya, sehingga Anda bisa melihat bentuk query sekilas dan menemukan kondisi join yang terlewat.


Tata letaknya mengikuti dialek yang Anda pilih, karena kata dan simbol berbeda di setiap database. Cast PostgreSQL seperti price::numeric, parameter bernomor seperti $1, nama dengan backtick di MySQL, klausa CONNECT BY di Oracle, dan TOP 10 di SQL Server semuanya valid di satu dialek dan menjadi error sintaks di dialek lain. Placeholder untuk parameter terikat (?, $1, :name, @name) dikenali dan dibiarkan apa adanya.


Huruf besar/kecil keyword tidak berpengaruh pada cara query berjalan, jadi ini murni soal gaya penulisan. Pemformat yang memahami tata bahasanya bisa mengubahnya dengan aman, karena tahu kata mana yang merupakan keyword dan mana yang nama kolom atau teks di dalam tanda kutip.
