Mengubah JSON menjadi YAML yang mudah dibaca


Konversi JSON ke YAML pada dasarnya menulis ulang data yang sama dalam bentuk yang lebih ramah dibaca manusia. Kurung kurawal dan tanda kutip diganti indentasi dan kata-kata biasa, itulah sebabnya konfigurasi Kubernetes, Compose dan sistem CI umumnya ditulis dalam YAML. Jika Anda memulai dari JSON, misalnya respons API atau manifest yang dihasilkan, konversinya bersifat mekanis, tetapi ada satu hal yang perlu diperhatikan: YAML menentukan tipe sebuah nilai dari tampilannya.


Di YAML, true tanpa kutip adalah boolean, null adalah null, dan 1.0 adalah angka. String JSON yang kebetulan terlihat seperti itu, misalnya "null", "1.0" atau "0x1F", harus diberi tanda kutip di YAML, kalau tidak tipenya akan berubah saat dibaca. Konverter memberi tanda kutip tepat pada string seperti itu, ditambah string kosong dan teks yang diawali simbol yang punya arti khusus di YAML, lalu memeriksa hasilnya dengan membacanya kembali.


Teks multibaris menjadi literal block, yang jauh lebih mudah dibaca daripada string panjang penuh escape \n. Objek dan array kosong ditulis sebagai {} dan []. Karena JSON tidak punya komentar, YAML-nya dimulai tanpa komentar; Anda bisa menambahkannya sendiri setelahnya.


Tips


    
  
  • Untuk mengubah YAML kembali ke JSON, gunakan Konversi YAML ke JSON.

  • Validasi dan rapikan JSON terlebih dahulu dengan Format dan validasi JSON jika Anda ragu formatnya benar.
