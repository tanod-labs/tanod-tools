Cara menulis tabel Markdown

Tabel Markdown ala GitHub adalah teks biasa: satu baris header, satu baris tanda hubung yang menentukan perataan, dan satu baris untuk setiap baris data, dengan sel dipisahkan karakter pipa. Format ini ditampilkan GitHub di README, issue, dan pull request, dan banyak alat lain, termasuk situs dokumentasi dan aplikasi catatan, juga memahaminya.

Kisi menyimpan sel-selnya; baris pertama adalah header. Setiap kolom punya perataan. Kiri ditulis :---, tengah :---:, kanan ---:, dan tanpa perataan cukup tanda hubung biasa. Teks sel di-escape bila perlu: karakter pipa menjadi \| dan pemisah baris menjadi tag HTML <br>. Setelah itu alat ini meluruskan kolom dengan spasi agar sumbernya terbaca seperti tabel, dengan menghitung lebar tiap karakter, bukan jumlah byte-nya, sehingga huruf beraksen pun tetap lurus.

Menempel dari spreadsheet adalah cara tercepat untuk memulai. Spreadsheet menaruh sel yang disalin di clipboard sebagai teks yang dipisahkan tab, satu baris per baris tabel, dan kisi membacanya langsung. File CSV dan TSV bekerja dengan cara yang sama lewat kotak tempel, termasuk kolom bertanda kutip dan pemisah baris di dalam tanda kutip. Jika Anda menempel tabel Markdown yang sudah ada, sel dan perataannya dibaca kembali ke kisi sehingga bisa Anda ubah.

Tips

  • Punya JSON, bukan spreadsheet? Ubah dulu dengan JSON ke CSV, lalu tempel hasilnya di sini.
  • Lihat tampilan tabelnya dengan Markdown ke HTML.
  • Untuk arah sebaliknya, dari halaman web kembali ke Markdown, gunakan HTML ke Markdown.
