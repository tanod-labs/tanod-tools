Menyematkan gambar sebagai teks

Mengubah gambar ke Base64 berguna karena HTML, CSS, JSON, Markdown, dan isi email berupa teks, sedangkan gambar berupa data biner. Base64 menjembatani keduanya dengan menuliskan byte gambar memakai 64 karakter yang aman, sehingga seluruh gambar bisa ditempatkan di dalam aturan stylesheet, tag img, atau file konfigurasi tanpa unduhan terpisah.

Alat ini membaca file di browser Anda, memeriksa jenis aslinya dari byte pertama, lalu membuat potongan kode pilihan Anda di sekitar teks yang sudah dikodekan. Gambarnya sendiri tidak diubah: mendekode Base64 tersebut akan menghasilkan kembali file asli yang persis sama.

Tips

  • Perkecil gambar terlebih dahulu dengan Kompres gambar atau Ubah ukuran gambar; setiap byte yang dihemat berarti sepertiga lebih banyak penghematan dalam Base64.
  • Untuk ikon sederhana, SVG sering kali lebih kecil daripada PNG mana pun, bahkan sebagai Base64.
  • Untuk mendekode Base64 kembali menjadi file, atau mengodekan file lain, gunakan Encode dan decode Base64.
