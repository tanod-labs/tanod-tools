Cara kerja kompresi PDF

Untuk mengompres PDF, yang paling penting adalah gambarnya, karena sebagian besar ukuran PDF yang besar berasal dari gambar: halaman hasil scan, foto, tangkapan layar. Server kami membuka file, menemukan setiap gambar yang mirip foto, dan memeriksa seberapa tajam gambar itu pada ukuran cetaknya di halaman. Gambar yang lebih tajam dari batas level yang dipilih akan diperkecil, lalu disimpan ulang sebagai JPEG. Sebuah gambar hanya diganti jika itu menghemat setidaknya 10 persen, dan struktur file ditulis ulang dengan setiap stream dikompres serapat mungkin.

Hasilnya tidak pernah lebih besar dari file asli Anda. Jika tidak ada yang bisa dihemat, Anda akan diberi tahu, dan Anda tetap memakai file yang sudah ada.

Tips

  • Untuk email, coba Disarankan dulu; beralih ke Kuat hanya jika file masih terlalu besar.
  • Hanya perlu beberapa halaman? Ambil dulu dengan Ekstrak halaman PDF; makin sedikit halaman, makin kecil filenya. Alat itu berjalan di browser Anda.
  • Ingin memperkecil foto, bukan PDF? Kompres gambar bekerja di perangkat Anda, tanpa mengunggah.
