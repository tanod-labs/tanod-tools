Dari baris CSV ke JSON

CSV adalah format data yang paling umum: setiap spreadsheet dan database bisa mengekspornya. JSON adalah format yang diharapkan sebagian besar API web, skrip, dan file konfigurasi. Konverter CSV ke JSON ini membaca CSV dengan parser yang mengikuti standar CSV, sehingga koma di dalam alamat bertanda kutip atau jeda baris di dalam komentar bertanda kutip tetap berada di selnya, bukan memecah baris.

Dengan baris header, setiap baris menjadi objek yang kuncinya adalah nama kolom, sesuai urutan kolom. Tanpa header, setiap baris menjadi array. Nilai dipertahankan sebagai teks kecuali Anda meminta angka dan true/false dikonversi, karena file CSV tidak membawa tipe data dan tebakan otomatis bisa diam-diam mengubah kode pos seperti 02134 menjadi angka 2134.

Baris di bawah opsi menunjukkan berapa baris dan kolom yang dibaca dan pemisah mana yang dipakai. Jika beberapa baris memiliki kolom lebih banyak atau lebih sedikit dari header, sebuah catatan menyebutkan baris mana saja, yang biasanya menunjuk ke pemisah yang nyasar atau tanda kutip yang tidak ditutup di sumbernya.

Tips

  • Ingin sebaliknya? Gunakan JSON ke CSV.
  • Untuk memeriksa atau memformat ulang hasilnya, tempel ke Format dan validasi JSON.
  • Bersihkan baris yang berulang terlebih dahulu dengan Hapus baris duplikat.
