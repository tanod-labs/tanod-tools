Apa yang berubah antara RouterOS v6 dan v7

Sebagian besar konfigurasi RouterOS terbaca sama di kedua versi: interface, alamat, aturan firewall, DHCP, PPP, dan queue tetap memakai menu dan properti yang sama. Perubahan terbesar ada di routing. v7 mengganti routing engine, dan bersamanya cara routing mark, routing filter, OSPF, dan BGP dikonfigurasi. Routing mark kini menjadi tabel routing sungguhan yang harus dibuat di /routing table dengan fib sebelum route, rule, atau mangle bisa memakainya, dan route menulis routing-table= sebagai ganti routing-mark=.

Routing filter berubah dari satu aturan per baris match-dan-action menjadi skrip kecil: /routing filter rule add chain=ospf-in rule="if (dst in 10.0.0.0/8 && dst-len in 8-24) { accept }". Network OSPF menjadi interface template yang mencocokkan interface berdasarkan network, nama, atau keduanya, dengan pengaturan per interface di template. Peer BGP menjadi connection dengan local.role yang eksplisit, dan network yang diiklankan kini berasal dari address list yang disebut di output.network.

Cara kerja pembantu ini

  • Alat ini hanya menulis ulang yang berubah secara mekanis, menampilkan setiap baris asli di atas penggantinya, dan membiarkan sisanya tidak tersentuh.
  • Jika sebuah baris tidak bisa dikonversi dengan yakin, baris itu dijadikan komentar dan dijelaskan, tidak pernah ditebak; daftar di samping input mengumpulkan semuanya beserta nomor barisnya.
  • Bandingkan hasilnya dengan export dari router yang sudah di-upgrade memakai RouterOS export diff, dan periksa firewall dengan firewall auditor.
