    Ringkasan fattura elettronica
    

    Di Italia, faktur dipertukarkan sebagai file XML melalui Sistema di Interscambio (SDI) milik Agenzia delle Entrate. Faktur ke badan publik memakai format FatturaPA sejak 2014 dan 2015, dan pelaku usaha wajib memakainya untuk hampir semua faktur dalam negeri sejak 2019. XML-nya, bukan salinan PDF, yang merupakan fakturnya, sehingga yang sampai kepada Anda sering berupa file yang tidak bisa dibaca. Halaman ini mengubahnya kembali menjadi faktur.
    

    File .p7m bertanda tangan
    

    Banyak faktur datang sebagai nama.xml.p7m. .p7m adalah amplop bertanda tangan dalam format CMS (PKCS#7): faktur XML disimpan di dalamnya bersama tanda tangan dan sertifikat penandatangan. Penyedia layanan Italia menulis amplop ini dengan cara yang sedikit berbeda (panjang tetap atau terbuka, isi dipecah menjadi beberapa bagian, bahkan berupa teks base64), dan sebuah file bisa ditandatangani dua kali. Halaman ini membaca amplop tersebut dengan parser kecil yang dibuat khusus untuk situs ini, mengeluarkan XML-nya, dan menyatakan dengan jelas bahwa tanda tangannya tidak diperiksa.
    

    Apa yang ditampilkan penampil
    

    Anda melihat cedente/prestatore (penjual) dan cessionario/committente (pembeli) beserta nomor PPN dan kode pajaknya, jenis, nomor, dan tanggal dokumen, alasan faktur (Causale), setiap baris dengan kuantitas, satuan, harga, diskon, dan tarif PPN, ringkasan PPN dengan kode pembebasan dan acuan hukumnya, iuran jaminan sosial, pajak yang dipotong, bea meterai, baris pembayaran dengan IBAN dan tanggal jatuh tempo, serta file terlampir. Halaman ini tidak memvalidasi faktur dan tidak berkomunikasi dengan SDI.
