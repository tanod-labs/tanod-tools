Output

Kegunaan hash

Generator hash ini menghitung hash kriptografis, yang mengubah input apa pun, dari satu huruf hingga file besar, menjadi sidik jari pendek dengan panjang tetap. Input yang sama selalu menghasilkan sidik jari yang sama, dan mengubah satu bit saja menghasilkan sidik jari yang sama sekali berbeda. Karena itu hash berguna untuk mengecek apakah file sampai tanpa perubahan, untuk menemukan file duplikat, dan sebagai komponen dasar tanda tangan digital serta version control.

Untuk mengecek file unduhan, cari checksum yang dicantumkan penerbitnya di sebelah file itu (sering kali SHA-256), letakkan file di sini dan tempel checksum-nya ke kolom Bandingkan. Jika cocok, file tersebut sama persis byte demi byte dengan yang di-hash oleh penerbit. Kecocokan itu hanya membuktikan bahwa file-nya memang yang dimaksud penerbit jika Anda memercayai halaman tempat checksum itu berasal.

Hash SHA-1 dan SHA-2 (SHA-256, SHA-384, SHA-512) dihitung oleh fungsi Web Crypto di browser Anda. Browser tidak menyediakan MD5, jadi halaman ini menyertakan kode MD5 sendiri, yang membaca file per potongan dan menampilkan progres untuk file besar. MD5 dan SHA-1 disediakan hanya demi kompatibilitas dengan checksum lama.

Tips

  • Butuh isi file sebagai teks, bukan sidik jarinya? Gunakan Encode dan decode Base64.
  • Untuk membuat rahasia acak yang kuat, bukan meng-hash-nya, gunakan Generator password.
  • Membandingkan dua teks baris demi baris lebih mudah dengan Bandingkan teks daripada dengan dua hash.
