    Menggabungkan PDF tanpa mengunggahnya

    Untuk menggabungkan PDF, Anda tidak memerlukan server. Setiap halaman dalam PDF adalah deskripsi mandiri berisi teks, gambar, dan perintah gambar, sehingga menggabungkan file berarti menyalin objek halaman itu ke dokumen baru dan menulis indeks yang baru. Browser Anda bisa melakukannya langsung dengan file yang ada di perangkat Anda.

    Halaman disalin, bukan dirender ulang, sehingga file gabungan memiliki kualitas yang sama dengan aslinya: teks tetap bisa dipilih dan dicari, dan gambar tidak dikompres ulang. Dokumen baru mendapat satu daftar halaman sesuai urutan yang Anda atur di sini.

    Tips

    • Hanya perlu beberapa halaman dari sebuah file? Proses dulu dengan Ekstrak halaman PDF, atau hapus halaman setelah digabungkan dengan Hapus halaman PDF.
    • Ingin menggabungkan foto atau hasil scan? Ubah dulu menjadi PDF dengan JPG ke PDF, lalu gabungkan.
