Mengubah JSON menjadi spreadsheet

API dan hasil ekspor sering memberi Anda JSON, sementara orang yang membutuhkan datanya menginginkan spreadsheet. CSV menjembatani keduanya: setiap objek dalam array menjadi baris dan setiap kunci menjadi kolom. Karena objek dalam data nyata jarang memiliki kunci yang persis sama, konverter JSON ke CSV ini mengumpulkan setiap kunci yang ditemukannya, sesuai urutan pertama kali ditemukan, dan mengosongkan sel jika sebuah objek tidak punya nilai untuk kolom itu.

Spreadsheet itu datar, jadi data bersarang harus dimasukkan ke kolom dengan cara tertentu. Perataan mengubah user.name dan user.email menjadi kolom terpisah, cocok untuk sebagian besar laporan. Menyimpan objek bersarang sebagai teks JSON membuat jumlah kolom tetap sedikit dan memungkinkan Anda menyusun ulang struktur aslinya nanti.

CSV yang dihasilkan mengikuti aturan umum (RFC 4180): nilai hanya diberi tanda kutip jika perlu dan tanda kutip di dalam nilai ditulis dua kali. Angka mempertahankan digit persis dari JSON Anda, tidak dibulatkan seperti angka JavaScript.

Tips

  • Ingin sebaliknya? Gunakan CSV ke JSON.
  • Jika JSON tidak bisa dikonversi, temukan masalahnya dengan Format dan validasi JSON.
  • Bandingkan dua hasil ekspor baris demi baris dengan Bandingkan teks.
