Dari YAML ke JSON


YAML dan JSON menggambarkan jenis data yang sama: mapping, daftar, dan nilai sederhana. YAML ditulis oleh manusia, dengan indentasi alih-alih kurung kurawal, komentar, dan pintasan seperti anchor; JSON adalah yang diharapkan sebagian besar program dan API. Konversi YAML ke JSON umum dilakukan saat manifest Kubernetes, file Compose, atau deskripsi OpenAPI harus diberikan ke sesuatu yang hanya membaca JSON.


Beberapa fitur YAML tidak punya padanan di JSON, jadi konverter menguraikannya. Anchor (&base) menandai blok yang bisa dipakai ulang oleh alias (*base), dan merge key (<<) menyalin entri sebuah mapping ke mapping lain; di JSON masing-masing menjadi salinan lengkap. Komentar dibuang, karena JSON tidak bisa menyimpannya. File dengan beberapa dokumen yang dipisahkan --- menjadi array JSON.


Aturan tipe mengikuti YAML 1.2: true dan false adalah boolean, null dan ~ adalah null, angka adalah angka, dan semua yang lain, termasuk yes dan 2024-05-01, adalah teks. Error sintaks disertai baris dan kolom, dan penyebab yang paling sering adalah tab yang dipakai untuk indentasi, kunci yang berulang dalam mapping yang sama, dan nilai yang tidak diindentasi di bawah kuncinya.


Tips


    
  
  • Perlu arah sebaliknya? Konversi JSON ke YAML memberi tanda kutip pada nilai seperti "yes" agar tetap utuh setelah dikonversi.
