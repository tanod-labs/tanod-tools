Static lease

      DHCP di RouterOS, bagian demi bagian

      RouterOS menyimpan DHCP server di tiga tempat, dan bagian yang hilang adalah alasan umum klien tidak mendapat alamat. Pool hanyalah kumpulan bernama berisi rentang alamat. Server mendengarkan pada satu interface dan meminjamkan alamat dari pool-nya. Entri network dicocokkan berdasarkan subnet dan memuat opsi yang dikirim bersama setiap lease: gateway, server DNS, nama domain, dan server NTP. Interface juga memerlukan alamat router sendiri di subnet itu, atau server tidak punya jaringan untuk dilayani.

      Halaman ini memeriksa bagian-bagian itu satu sama lain sebelum menulis apa pun: gateway dan pool harus berada di dalam subnet, pool harus menghindari alamat network, broadcast, dan gateway, dan static lease harus unik serta berada di dalam subnet. Static lease ditulis ke /ip dhcp-server lease dengan nama server, sehingga tiap perangkat selalu mendapat alamat yang sama.

      Tips

      • Merencanakan pengalamatan? Kalkulator subnet menampilkan rentang host dan ukuran prefix mana pun.
      • Satu DHCP server per VLAN: buat interface VLAN lebih dulu dengan generator VLAN, lalu jalankan alat ini sekali per VLAN.
      • Jika router menjawab DNS, pastikan firewall men-drop DNS dari internet.
