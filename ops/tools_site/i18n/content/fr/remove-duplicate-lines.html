Supprimer les doublons et trier des lignes

Les listes accumulent les répétitions : adresses e-mail collées depuis plusieurs sources, mots-clés, lignes de journal, noms de fichiers. Cet outil supprime les lignes en double : il lit le texte ligne par ligne, mémorise chaque ligne déjà vue et retire les copies suivantes (ou les précédentes, si vous choisissez de garder la dernière occurrence). Les lignes restantes gardent leur ordre d'origine, sauf si vous choisissez un tri.

Le compte rendu au-dessus des boutons indique combien de lignes sont entrées, combien sont sorties et combien ont été supprimées comme doublons, pour que vous puissiez vérifier le résultat. Les lignes vides retirées par l'option sont comptées à part.

Conseils

  • Pour nettoyer d'abord les lignes, utilisez Rechercher et remplacer, puis revenez ici.
  • Voyez ce qui a changé entre deux versions d'une liste avec Comparer deux textes.
  • Vous voulez seulement remettre la liste en ordre, avec plus d'options de tri ? Utilisez Trier par ordre alphabétique.
  • Comptez ce qui reste avec le Compteur de mots.
