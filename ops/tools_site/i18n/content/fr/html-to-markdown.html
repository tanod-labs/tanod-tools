Transformer des pages web en Markdown

Sortir du contenu d'une page web, d'un ancien CMS ou d'un éditeur de texte enrichi pour le mettre dans un README, un site statique ou une application de notes demande en général de convertir du HTML en Markdown. Le convertisseur parcourt la structure HTML et écrit chaque élément sous sa forme Markdown : les titres deviennent des lignes en #, les listes des tirets, les liens [texte](url), et <pre><code> devient un bloc de code.

Le Markdown ne décrit que la structure : la mise en forme visuelle est donc laissée de côté. Les styles en ligne, classes, couleurs et conteneurs de mise en page disparaissent, tandis que les mots, l'emphase, les liens, les images et les listes restent. Les tableaux sont écrits en tableaux GitHub Flavored Markdown quand ils sont assez simples pour ce format.

Chaque projet a ses habitudes en Markdown : c'est pourquoi les styles de titres, de puces de liste, de blocs de code et d'italique sont modifiables. La plupart des moteurs de rendu acceptent tous ces styles.

Conseils

  • Vérifiez le rendu du Markdown avec Markdown en HTML, qui a un aperçu.
  • Corrigez les espaces ou formulations restantes avec Rechercher et remplacer.
  • Comptez les mots du résultat avec le Compteur de mots.
