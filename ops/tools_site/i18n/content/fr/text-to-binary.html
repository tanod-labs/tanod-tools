Comment un texte devient des uns et des zéros

Les ordinateurs stockent le texte sous forme de nombres. Un encodage décide quel nombre reçoit chaque caractère ; pour convertir le texte en binaire, cet outil utilise l'UTF-8, l'encodage de presque toutes les pages web, tous les e-mails et les fichiers modernes. L'UTF-8 stocke les 128 premiers caractères (l'alphabet latin sans accent, les chiffres et la ponctuation courante) sur un octet chacun, avec les mêmes valeurs que l'ancien code ASCII. Les autres caractères prennent de deux à quatre octets : é s'écrit 11000011 10101001 et l'emoji 😀 occupe quatre octets.

Un octet compte huit bits : chaque octet s'affiche donc sous forme de huit chiffres binaires, avec les zéros de tête conservés pour que tous les groupes aient la même largeur. Le résultat est ainsi facile à relire : chaque groupe de huit est un octet.

Pour décoder, l'outil lit chaque groupe comme un octet, puis lit les octets comme du texte UTF-8. Si les octets ne forment pas de l'UTF-8 valide, il indique où commence le problème au lieu d'afficher des caractères illisibles.
