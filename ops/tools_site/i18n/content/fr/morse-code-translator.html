Le code morse en bref

Le code morse écrit chaque lettre sous forme d'une courte suite de signaux brefs et longs, les points et les traits. Les lettres fréquentes ont des codes courts : E est un seul point et T un seul trait, tandis que des lettres plus rares comme Q (--.-) demandent quatre signaux. Ce traducteur utilise l'alphabet morse international normalisé par l'UIT, celui qu'apprennent les radioamateurs, les pilotes et les marins.

Le rythme fait partie du code. Un trait dure trois fois plus longtemps qu'un point, la pause à l'intérieur d'une lettre dure un point, la pause entre les lettres trois points et la pause entre les mots sept. À l'écrit, une espace représente la pause entre les lettres et une barre oblique la pause entre les mots.

Le code morse ne distingue pas les majuscules : le texte décodé sort donc en capitales, comme les opérateurs le notent traditionnellement.

Conseils

  • Essayez une autre façon d'écrire du texte sous forme de signaux avec Texte en binaire.
  • Transformez les capitales décodées en phrases normales avec Convertir majuscules et minuscules (Majuscule en début de phrase).
