Comment fonctionne la comparaison

Pour comparer deux textes, un diff cherche la plus courte liste de modifications qui transforme le texte d'origine en texte modifié. Les passages identiques restent tels quels ; le reste est affiché comme supprimé de l'original et ajouté dans la nouvelle version. Cet outil utilise la bibliothèque open source jsdiff, qui s'exécute dans votre navigateur.

Quand un bloc de lignes est remplacé, l'ancienne et la nouvelle version s'affichent sur les mêmes rangées en vue côte à côte, pour que vous puissiez les lire en parallèle. Sur un téléphone, les deux côtés s'empilent. « Ouvrir un fichier .txt » remplit le dernier champ que vous avez utilisé.

Conseils

  • Comparez des listes après les avoir nettoyées avec Supprimer les lignes en double.
  • Appliquez d'abord la même modification partout avec Rechercher et remplacer.
  • Vous comparez deux exports de données ? Convertissez-les d'abord avec JSON en CSV pour que chaque enregistrement tienne sur une ligne.
  • Cliquez sur Inverser pour voir la comparaison dans l'autre sens.
