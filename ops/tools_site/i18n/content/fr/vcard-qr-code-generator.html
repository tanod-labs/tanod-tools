Ce que contient un QR code de contact


Un QR code vCard est une vCard écrite sous forme de texte et dessinée en QR code. La carte commence par BEGIN:VCARD et se termine par END:VCARD, et chaque ligne est une propriété : N contient le nom structuré, FN le nom tel qu'il doit s'afficher, TEL un numéro de téléphone avec un type comme CELL, et ainsi de suite. Scanner le code transmet au téléphone le même texte que contiendrait un fichier .vcf, et le téléphone propose d'enregistrer le contact.


La norme demande que les lignes se terminent par un retour chariot et un saut de ligne : le fichier et le code respectent cette règle. Les valeurs sont échappées : une barre oblique inverse, une virgule ou un point-virgule reçoit une barre oblique inverse devant, et un saut de ligne dans la note devient \n. Le nom et l'adresse sont des listes de parties séparées par des points-virgules : un point-virgule saisi dans une partie ne peut donc pas déborder sur la suivante.


Les QR codes grandissent par paliers appelés versions, de 1 (21 × 21 modules) à 40 (177 × 177). Chaque caractère supplémentaire peut faire passer un code à la version suivante. Une carte avec seulement un nom, un téléphone et un e-mail reste d'une version modeste et se scanne facilement même imprimée en petit. Ajouter une adresse postale et une longue note peut doubler la largeur. Si le code est dense, retirez les champs dont vous pouvez vous passer ou choisissez un niveau de correction d'erreur plus bas.
