      Lire les couleurs directement dans les pixels

      Retrouver la couleur d'une marque à partir d'un logo, trouver le bleu exact d'une capture d'écran ou construire une palette à partir d'une photo revient toujours à la même chose : lire les valeurs de rouge, de vert et de bleu enregistrées pour un pixel. Cette pipette de couleur pour image décode l'image dans votre navigateur et lit ces valeurs sur l'image en pleine résolution : le code que vous copiez est donc la couleur réellement présente dans le fichier.

      Un pixel isolé peut être trompeur sur une photo, où le bruit et la compression font varier les pixels voisins. Utilisez la loupe pour viser le milieu d'un aplat, ou prenez la palette, qui fait la moyenne de groupes entiers de pixels similaires pour obtenir quelques couleurs représentatives.

      Conseils
