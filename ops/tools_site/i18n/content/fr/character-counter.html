Les lignes X et SMS suivent les règles de décompte propres à ces systèmes ; les autres lignes comptent les caractères comme ci-dessus. Les limites sont indicatives : les plateformes les modifient, et certaines mesurent la largeur à l'écran plutôt que le nombre de caractères.

Compter les caractères comme le fait le système destinataire

Le mot « caractère » n'a pas le même sens pour tous les logiciels. Une personne voit un seul caractère dans « é » ou dans un emoji de drapeau, mais un ordinateur peut stocker l'un comme l'autre en deux morceaux ou plus. Ce compteur de caractères affiche le décompte que vous voyez (Caractères), le décompte de plus bas niveau en points de code Unicode, et le nombre d'octets qu'occupe le texte en UTF-8, l'encodage utilisé par la plupart des sites web et des bases de données. Quand un formulaire indique « 255 caractères maximum », il compte généralement l'une de ces unités, et la différence ne compte que pour les emoji, les accents stockés comme des signes séparés et les écritures non latines.

Le tableau des limites de longueur compare votre texte aux endroits où la longueur est souvent plafonnée. Chaque ligne indique ce qui est utilisé et ce qui reste ; une ligne qui dépasse sa limite indique combien de caractères supprimer. Les SMS sont comptés selon les règles GSM qu'utilisent les téléphones : un seul emoji peut donc faire passer tout le message à la limite Unicode, plus courte.

Tout est compté dans votre navigateur pendant la saisie. Le texte n'est ni envoyé ni conservé.
