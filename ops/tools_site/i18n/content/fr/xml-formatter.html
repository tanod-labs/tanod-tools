Indenter du XML sans le modifier


Le XML est exigeant sur la structure et souple sur la mise en page : entre deux balises, vous pouvez ne rien mettre, une espace ou cent lignes vides, le document a le même sens. C'est pourquoi les flux, les réponses SOAP et les configurations exportées arrivent souvent sur une seule longue ligne. Formater le XML en indentant chaque élément imbriqué rend la hiérarchie visible et permet une comparaison ligne par ligne.


Beaucoup de formateurs analysent le document puis le réécrivent, ce qui peut modifier discrètement des choses auxquelles vous ne leur avez pas demandé de toucher : transformer &#169; en caractère littéral, changer le style des guillemets ou réordonner les attributs. Cet outil lit le texte avec un découpeur lexical et réutilise chaque morceau exactement tel qu'il a été écrit, en ajoutant ou retirant uniquement des espaces entre les éléments. Il utilise ensuite l'analyseur XML du navigateur pour vérifier que le résultat est bien formé.


Les espaces sont le seul endroit où le XML n'est pas toujours souple. Dans un paragraphe comme <p>un <b>deux</b> trois</p>, les espaces autour des balises font partie du texte : les déplacer ou les supprimer changerait ce que voit le lecteur. Les éléments qui mêlent texte et balises, et les éléments marqués xml:space="preserve", ne sont donc jamais remis en forme.
