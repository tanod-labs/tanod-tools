    Convertir le format d'une image dans votre navigateur

    Un fichier image, c'est un conteneur et une méthode de compression. Convertir une image consiste à décoder les pixels de l'ancien format et à les encoder de nouveau dans le nouveau. Votre navigateur dispose déjà de décodeurs et d'encodeurs pour les formats courants : la conversion peut donc se faire entièrement sur votre appareil.

    Le PNG stocke chaque pixel exactement et gère la transparence, ce qui le rend plus lourd pour les photos. Le JPEG et le WebP sont avec perte : ils sacrifient un peu d'exactitude pour des fichiers beaucoup plus légers, selon le réglage de qualité. Convertir un JPEG en PNG ne restaure pas les détails déjà perdus par le JPEG ; cela stocke seulement les pixels actuels sans perte supplémentaire.

    Astuces

    • Après la conversion, allégez le fichier avec Compresser une image.
    • Vous voulez plutôt changer les dimensions en pixels ? Utilisez Redimensionner une image.
    • Vous partez d'un dessin vectoriel ? SVG en PNG le rend à n'importe quelle taille.
