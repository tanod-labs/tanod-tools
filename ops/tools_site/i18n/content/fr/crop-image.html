Déposez une image ici

PNG, JPEG, WebP, GIF, BMP ou AVIF. Ou glissez-la n'importe où sur cette page.

Faites glisser le cadre pour le déplacer et un angle pour le redimensionner. Quand le cadre a le focus, les flèches le déplacent et Maj avec les flèches le redimensionne.

Format

Recadrer sans perdre de résolution

Recadrer une image, c'est garder un rectangle des pixels d'origine et supprimer le reste. L'image affichée à l'écran est un aperçu réduit pour tenir dans la page ; le recadrage lui-même est effectué sur l'image en pleine résolution, d'après les valeurs X, Y, largeur et hauteur affichées dans les champs. Ces nombres sont exprimés en pixels de l'image, et non en pixels de l'écran.

Utilisez un format prédéfini quand le résultat doit entrer dans un cadre : 1:1 pour un avatar carré, 16:9 pour une miniature de vidéo, 4:3 ou 3:2 pour les formats photo courants, 9:16 pour une story verticale. Le cadre garde cette forme quand vous le redimensionnez, et saisir une largeur ou une hauteur met à jour l'autre valeur.

Conseils

  • Recadrez d'abord, puis réduisez le poids avec Redimensionner une image et Compresser une image.
  • Photo dans le mauvais sens ? Faire pivoter une image la remet d'aplomb.
  • Vous créez une icône à partir d'une partie d'image ? Recadrez en 1:1, puis utilisez le Générateur de favicon.
