Remettre les pages dans l'ordre

Les pages se retrouvent souvent dans le mauvais ordre : scans recto verso, documents assemblés à partir de plusieurs sources, page de signature qui devrait être à la fin. Pour réorganiser les pages d'un PDF, vous voyez ici chaque page en miniature et vous la déplacez à sa place.

Le nouveau PDF est créé en copiant les pages dans votre ordre. Rien n'est modifié sur les pages, et les liens, le texte et les images sont conservés intacts.

Astuces

  • Vous combinez plusieurs fichiers dans un ordre précis ? Fusionner des PDF vous permet d'abord d'ordonner les fichiers.
  • Après la réorganisation, utilisez Numéroter les pages d'un PDF pour que l'ordre soit visible sur papier.
