Ce que contient un QR code Wi-Fi


Un QR code Wi-Fi est un texte ordinaire dans une mise en forme fixe : WIFI:T:WPA;S:name;P:password;;. Les lettres avant chaque deux-points désignent le champ : T pour le type de sécurité, S pour le nom du réseau, P pour le mot de passe et H pour un réseau masqué. Les appareils photo des téléphones reconnaissent le préfixe WIFI: et proposent de se connecter : la personne qui scanne n'a jamais à saisir le mot de passe.


Comme les champs sont séparés par des points-virgules et des deux-points, ces caractères, ainsi que la barre oblique inverse, la virgule et le guillemet droit, doivent être échappés avec une barre oblique inverse lorsqu'ils figurent dans un nom ou un mot de passe. Une erreur à ce niveau est la raison habituelle pour laquelle un code fonctionne avec un mot de passe simple et échoue avec un mot de passe compliqué. L'affichage ci-dessus montre le texte final pour que vous voyiez ce qui a été échappé. Pour un réseau ouvert, le champ du mot de passe est entièrement omis.


La carte à imprimer place le code sur un fond blanc uni avec le nom du réseau en dessous, dans la même police Archivo que le reste de ce site. C'est un PNG fixe de 900 × 1100 pixels, qui s'imprime net à environ 8 × 10 cm à 280 points par pouce, et plus grand si vous acceptez un texte aux contours un peu moins nets.
