Comment s'écrit un tableau Markdown

Un tableau Markdown GitHub est du texte brut : une ligne d'en-tête, une ligne de tirets qui définit l'alignement, puis une ligne par ligne de données, les cellules étant séparées par des barres verticales. C'est le format que GitHub affiche dans les README, les tickets et les pull requests, et de nombreux autres outils, dont les sites de documentation et les applications de notes, le comprennent aussi.

La grille contient les cellules ; la première ligne est l'en-tête. Chaque colonne a un alignement. La gauche s'écrit :---, le centre :---:, la droite ---: et l'absence d'alignement se note par de simples tirets. Le texte des cellules est échappé si nécessaire : une barre verticale devient \| et un saut de ligne devient la balise HTML <br>. L'outil aligne ensuite les colonnes avec des espaces pour que le source ressemble à un tableau, en se fondant sur la largeur de chaque caractère plutôt que sur son nombre d'octets, afin que les lettres accentuées s'alignent aussi.

Coller depuis un tableur est le moyen le plus rapide de démarrer. Les tableurs placent les cellules copiées dans le presse-papiers sous forme de texte séparé par des tabulations, avec une ligne par ligne du tableau, et la grille le lit directement. Les fichiers CSV et TSV fonctionnent de la même façon via la zone de texte, avec prise en charge des champs entre guillemets et des sauts de ligne entre guillemets. Si vous collez un tableau Markdown existant, les cellules et les alignements sont relus dans la grille pour que vous puissiez les modifier.
