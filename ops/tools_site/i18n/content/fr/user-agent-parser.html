Client Hints de votre navigateur

Ce que dit un user agent, et ce qu'il cache

Un analyseur de user agent doit composer avec l'histoire de cette chaîne. Le user agent servait au départ à un serveur pour savoir quel navigateur l'interrogeait, afin d'envoyer une page qui y fonctionnait. Les navigateurs ont ensuite copié les noms des autres pour obtenir les bonnes pages, c'est pourquoi une chaîne Chrome mentionne aujourd'hui aussi Mozilla, AppleWebKit, KHTML, Gecko et Safari. Un analyseur contourne ce problème en testant des motifs dans un ordre soigneusement choisi et en retenant la correspondance la plus précise.

La chaîne est aussi raccourcie volontairement. La réduction du User-Agent de Chrome fige la version de Windows à NT 10.0, celle de macOS à 10_15_7, le modèle Android à K et le numéro de build à 0.0.0, pour que la chaîne ne soit plus une bonne empreinte. Les détails n'ont pas disparu : une page qui les demande via les Client Hints obtient la version de la plateforme, l'architecture, le modèle et la version complète du navigateur, et c'est le navigateur du visiteur qui décide de répondre ou non.

Utilisez la chaîne pour des décisions grossières et pour les journaux, pas pour accorder votre confiance. Les robots d'exploration et les outils en ligne de commande comme curl envoient leurs propres chaînes courtes, et tout peut être falsifié. Si vous traquez un bug de mise en page, la détection de fonctionnalités dans la page est plus fiable que la lecture du nom du navigateur.

Astuces

  • Un journal de serveur rempli de réponses 403 ou 429 pour un même client ? Consultez ces codes dans la référence des Codes de statut HTTP.
  • Les user agents présents dans des URL ou des chaînes de requête sont souvent encodés en pourcent ; décodez-les avec Encoder et décoder une URL.
  • Les en-têtes copiés d'une requête contiennent parfois des valeurs en Base64 ; lisez-les avec Encoder et décoder en Base64.
