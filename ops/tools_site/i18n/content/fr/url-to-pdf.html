Comment une page web devient un PDF ici

Pour convertir une page web en PDF, notre serveur lance une nouvelle copie isolée (sandbox) du navigateur Chromium, ouvre l'adresse que vous avez indiquée, attend que la page ait fini de se charger et l'imprime en PDF avec votre format de papier et votre orientation, exactement comme le ferait la boîte de dialogue Imprimer de votre navigateur. Ce navigateur ne peut accéder qu'à ce seul site, jamais aux réseaux privés, et il est détruit après chaque tâche.

Astuces

  • Les pages faciles à lire, comme les articles qui proposent une version imprimable, donnent les PDF les plus propres.
  • Vous voulez plusieurs pages dans un seul fichier ? Convertissez-les une par une, puis assemblez-les avec Fusionner des PDF (dans votre navigateur).
  • Besoin du texte plutôt que d'un PDF ? HTML en Markdown convertit le HTML collé sur votre appareil.
