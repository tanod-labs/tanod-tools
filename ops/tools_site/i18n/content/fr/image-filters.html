Ce que chaque filtre fait aux pixels

Ces filtres photo en ligne travaillent directement sur les pixels. Chaque pixel est formé de trois nombres de 0 à 255, pour le rouge, le vert et le bleu. La luminosité multiplie ces nombres : à 150 %, une valeur de 100 devient 150, et tout ce qui dépasse 255 est écrêté en blanc. Le contraste éloigne les nombres du gris moyen (128) ou les en rapproche, ce qui explique pourquoi un contraste à 0 % donne une image grise uniforme. La saturation et la rotation de teinte mélangent les trois canaux à l'aide de matrices de couleur fixes : c'est ainsi qu'une photo glisse vers le gris ou fait le tour de la roue chromatique.

Les niveaux de gris remplacent chaque pixel par sa luminance, une somme pondérée qui compte surtout le vert (environ 72 %), puis le rouge (21 %) et enfin le bleu (7 %), car l'œil est plus sensible au vert. Le sépia utilise une matrice qui donne la teinte brune et chaude des anciens tirages. Le négatif soustrait chaque valeur de 255. Le flou fait la moyenne de chaque pixel avec ses voisins, trois fois dans chaque direction, ce qui s'approche de très près d'un flou gaussien.

Les petits aperçus rendent les curseurs rapides, mais le fichier enregistré est traité en pleine résolution par morceaux : la page reste donc réactive et affiche la progression. Une fois l'image enregistrée, le fichier d'origine reste intact.

Conseils

  • Pour lire une couleur exacte dans le résultat, utilisez la Pipette de couleur pour image.
  • Appliquer les filtres avant d'ajouter une légende garde le texte net : procédez dans cet ordre avec Ajouter du texte à une image.
  • Une image floutée ou très contrastée se compresse très différemment : vérifiez ensuite son poids avec Compresser une image.
