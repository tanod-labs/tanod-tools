Comment le Markdown devient du HTML

Le Markdown permet d'écrire du texte mis en forme avec des caractères ordinaires : un # commence un titre, **deux astérisques** mettent en gras, une ligne qui commence par un tiret est un élément de liste. C'est le format des fichiers README, de nombreuses applications de notes et de la plupart des forums de développeurs. Les navigateurs, les modèles d'e-mail et les systèmes de gestion de contenu attendent du HTML : il faut donc tôt ou tard convertir le Markdown en HTML.

Ce convertisseur suit CommonMark avec les ajouts de GitHub Flavored Markdown : tableaux, listes de tâches et texte barré fonctionnent comme sur GitHub. Le HTML produit passe ensuite par un nettoyeur, qui retire tout ce qui pourrait exécuter du code à l'affichage du HTML, sans toucher à la mise en forme ordinaire.

L'onglet Aperçu montre le même HTML rendu dans la page. Les liens s'ouvrent dans un nouvel onglet, et les images hébergées ailleurs sont affichées comme des espaces réservés au lieu d'être chargées : rien de ce que vous écrivez n'est envoyé à un autre site pendant que vous travaillez.
