    Les factures électroniques du Vietnam
    

    Depuis le décret 123/2020/ND-CP et la circulaire 78/2021/TT-BTC, les entreprises du Vietnam émettent des hóa đơn điện tử, des factures électroniques, sous forme de fichiers XML dans un format fixé par l'administration fiscale. Une facture porte soit un code de l'administration fiscale (hóa đơn có mã, indiqué dans l'élément MCCQT), soit est émise sans code. Le XML est la facture ; la version lisible n'en est qu'une visualisation. Cette page produit cette visualisation dans votre navigateur à partir du XML que vous possédez.
    

    Ce que montre la visionneuse
    

    Vous voyez le nom et la version de la facture, le numéro de modèle (KHMSHDon), le symbole (KHHDon), le numéro (SHDon), la date (NLap), le code de l'administration fiscale (MCCQT) lorsqu'il y en a un, le vendeur (NBan) et l'acheteur (NMua) avec leurs identifiants fiscaux (MST), leurs adresses et leurs coordonnées, chaque ligne avec son unité, sa quantité, son prix, sa remise et son taux de TVA, la TVA par taux (THTTLTSuat), les totaux, le montant en toutes lettres et les coordonnées de paiement. Pour une facture rectificative ou de remplacement (TCHDon), la facture à laquelle elle se rapporte est affichée. Les montants sont affichés exactement comme dans le fichier.
    

    Elle ne vérifie pas les signatures numériques (DSCKS), ne valide pas la facture selon le schéma et les règles de l'administration fiscale et ne consulte pas la facture auprès d'elle. Les factures dans d'autres formats, comme les anciennes factures de la circulaire 32/2011, ne sont pas lues.
    

    Astuces
    

      
  
    • Télécharger le JSON vous donne la facture sous forme de données brutes, avec les noms de champs vietnamiens rattachés aux termes métier de la norme EN 16931.
      • 
  
    • D'autres formats s'ouvrent aussi ici : XRechnung, ZUGFeRD / Factur-X, FatturaPA, KSeF, Peppol et la hóa đơn điện tử vietnamienne. La page vous propose la visionneuse adaptée lorsque vous en ouvrez un.
      • 
  
    • Afficher le XML brut est utile lorsque vous avez besoin d'un élément que la facture lisible n'affiche pas.
