Les métadonnées d'un PDF, et pourquoi les modifier

Chaque PDF peut contenir quelques champs descriptifs : un titre, un auteur, un sujet, des mots-clés, le programme qui l'a créé et les dates de création et de dernière modification. Ces métadonnées se trouvent dans le dictionnaire d'informations du document, et beaucoup de programmes en écrivent aussi une seconde copie sous forme de paquet XMP, un bloc XML joint au fichier.

Ces champs apparaissent dans les propriétés du fichier, les résultats de recherche et les onglets du navigateur : un titre erroné ou un nom d'auteur oublié peut donc être gênant quand un document vous échappe. Cet outil les lit dans votre navigateur, vous permet de les corriger ou les efface. Le contenu des pages n'est jamais modifié.
