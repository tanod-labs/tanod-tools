Transformer du JSON en tableur

Les API et les exports fournissent souvent du JSON, alors que les personnes qui ont besoin des données veulent un tableur. Convertir le JSON en CSV fait le lien : chaque objet du tableau devient une ligne et chaque clé une colonne. Comme les objets de données réelles ont rarement tous les mêmes clés, l'outil rassemble toutes les clés qu'il rencontre, dans l'ordre où il les voit pour la première fois, et laisse une cellule vide quand un objet n'a pas de valeur pour cette colonne.

Un tableur est plat : les données imbriquées doivent donc être ramenées en colonnes d'une manière ou d'une autre. L'aplatissement transforme user.name et user.email en colonnes distinctes, ce qui convient à la plupart des rapports. Garder les objets imbriqués en texte JSON limite le nombre de colonnes et permet de reconstruire plus tard la structure d'origine.

Le CSV suit les règles habituelles (RFC 4180) : les valeurs ne sont mises entre guillemets que si nécessaire et les guillemets à l'intérieur d'une valeur sont doublés. Les nombres gardent les chiffres exacts de votre JSON au lieu d'être arrondis comme le seraient des nombres JavaScript.

Conseils

  • Si le JSON ne se convertit pas, trouvez le problème avec Formater et valider du JSON.
