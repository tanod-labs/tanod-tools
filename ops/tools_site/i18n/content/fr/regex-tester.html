Tester des motifs en toute sécurité


Ce testeur de regex construit un RegExp JavaScript à partir de votre motif et de vos drapeaux, et l'exécute dans un worker en arrière-plan, avec le même moteur que celui qu'utilisera votre code dans ce navigateur. Les correspondances reviennent avec leur position de début et chaque groupe de capture, et la page les dessine sur votre texte avec un surlignage alterné pour que les correspondances voisines restent distinctes. Une correspondance vide, comme celle que peuvent produire \b ou a*, apparaît sous forme de fine barre.


Exécuter le motif dans un worker est important, car une expression régulière peut prendre un temps exponentiel. Si un motif tourne encore au bout de 2 secondes, le worker est arrêté et vous recevez un message au lieu d'un onglet figé. La même protection s'applique à Rechercher et remplacer.


Les positions sont comptées en unités de code UTF-16, comme le font les chaînes JavaScript : un emoji ou un autre caractère hors du plan de base en occupe deux. La liste affiche les 1 000 premières correspondances ; le total indiqué au-dessus les inclut toutes.
