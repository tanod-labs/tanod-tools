Lire le diff d'une configuration RouterOS

Un export est la configuration du routeur écrite sous forme des commandes qui la recréeraient : une ligne de menu comme /ip firewall filter suivie des commandes add et set de ce menu. Seuls les paramètres qui diffèrent des valeurs par défaut apparaissent, ce qui garde les exports courts mais signifie qu'un paramètre revenu à sa valeur par défaut disparaît simplement de l'export le plus récent. Le diff traite chaque menu comme une section, compare ses commandes dans l'ordre et met en évidence les sections modifiées.

Certaines différences sont du bruit plutôt que des changements : l'en-tête avec la date d'export, l'identifiant du logiciel et le numéro de série est supprimé, les lignes coupées sont réunies, et les lignes de commentaire peuvent être ignorées. Ce qui reste est ce que le routeur ferait réellement de façon différente. L'ordre est conservé volontairement : les règles de firewall, NAT, mangle et de queues sont traitées de haut en bas, donc déplacer une règle est un vrai changement.

Conseils

  • Conservez un export daté après chaque fenêtre de changement et comparez-le au précédent pour voir exactement ce qui a été fait.
  • Vous vérifiez une mise à jour v6 vers v7 ? Comparez le script converti par l'aide à la migration avec un export pris après la mise à jour.
  • Pour du texte brut qui n'est pas un export, le comparateur de texte général compare aussi mot à mot.
