JSON नमूने से टाइप निकालना


TypeScript के टाइप डेटा का आकार बताते हैं, और JSON रिस्पॉन्स में आकार पहले से मौजूद होता है: हर की, उसके पीछे के मान का प्रकार, और ऑब्जेक्ट कैसे नेस्ट हैं। कन्वर्टर नमूने से गुज़रकर उस आकार को डिक्लेरेशन के रूप में लिख देता है, ताकि भरोसे के साथ API कॉल करने से पहले आपको चालीस फ़ील्ड हाथ से टाइप न करने पड़ें।


सबसे अहम कदम यह है कि ऐरे के साथ क्या किया जाए। ऑब्जेक्ट के ऐरे का हर आइटम पढ़ा जाता है और उनके आकार मिला दिए जाते हैं: जो की हर आइटम में है वह ज़रूरी रहती है, जो सिर्फ़ कुछ में है वह वैकल्पिक बन जाती है, और जिन मानों का प्रकार अलग है वे यूनियन बन जाते हैं। इसीलिए कई रिकॉर्ड वाला नमूना एक रिकॉर्ड वाले नमूने से कहीं बेहतर टाइप देता है। null मान को गायब की से अलग माना जाता है, क्योंकि फ़ील्ड पढ़ने वाले कोड के लिए दोनों के मतलब अलग हैं।


निकाले गए टाइप शुरुआती बिंदु हैं, अनुबंध नहीं। वे नहीं जान सकते कि कोई स्ट्रिंग हमेशा तीन मानों में से एक होती है, कि कोई संख्या असल में पूर्णांक ID है, या कि आपके सभी उदाहरणों में मौजूद फ़ील्ड प्रोडक्शन में गायब हो सकती है। नतीजा पढ़ें, जो नाम अटपटे आए हों उन्हें बदलें, और जो टाइप मायने रखते हैं उन्हें कसें।
