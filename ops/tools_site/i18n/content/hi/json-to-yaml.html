JSON को पढ़ने लायक YAML बनाना


YAML काफ़ी हद तक वही डेटा लिखने का ज़्यादा इंसान-अनुकूल तरीका है जो JSON रखता है। ब्रेसेस और कोट की जगह इंडेंटेशन और सादे शब्द ले लेते हैं, इसीलिए Kubernetes, Compose और CI सिस्टम का कॉन्फ़िगरेशन आम तौर पर इसी में लिखा जाता है। JSON से, जैसे API रिस्पॉन्स या जनरेट किए मैनिफ़ेस्ट से, शुरू करने पर कन्वर्ज़न यांत्रिक है, पर एक बारीकी का ध्यान रखना होता है: YAML किसी मान का प्रकार इस बात से तय करता है कि वह दिखता कैसा है।


YAML में सादा true बूलियन है, null null है और 1.0 संख्या है। जो JSON स्ट्रिंग इनमें से किसी जैसी दिखे, जैसे "null", "1.0" या "0x1F", उसे YAML में कोट करना ज़रूरी है, वरना पढ़ते समय उसका प्रकार बदल जाएगा। कन्वर्टर ठीक उन्हें कोट करता है, साथ ही खाली स्ट्रिंग और ऐसे टेक्स्ट को जो YAML में मतलब रखने वाले चिह्नों से शुरू होता है, और फिर आउटपुट को वापस पढ़कर जाँचता है।


बहु-लाइन टेक्स्ट लिटरल ब्लॉक बन जाता है, जिसे \n एस्केप वाली लंबी स्ट्रिंग से पढ़ना कहीं आसान है। खाली ऑब्जेक्ट और ऐरे {} और [] के रूप में लिखे जाते हैं। JSON में कमेंट नहीं होते, इसलिए YAML बिना किसी कमेंट के शुरू होती है; बाद में आप अपने कमेंट जोड़ सकते हैं।
