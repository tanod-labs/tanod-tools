Markdown टेबल कैसे लिखी जाती है

GitHub-फ़्लेवर्ड Markdown टेबल सादा टेक्स्ट होती है: एक हेडर पंक्ति, अलाइनमेंट तय करने वाली डैश की एक पंक्ति, और हर डेटा पंक्ति के लिए एक लाइन, जिसमें सेल पाइप कैरेक्टर से अलग किए जाते हैं। GitHub इसी फ़ॉर्मैट को README, इश्यू और पुल रिक्वेस्ट में दिखाता है, और डॉक्यूमेंटेशन साइट व नोट ऐप समेत कई दूसरे टूल भी इसे समझते हैं।

ग्रिड में सेल रहते हैं; पहली पंक्ति हेडर है। हर कॉलम का एक अलाइनमेंट होता है। बाएँ के लिए :---, बीच के लिए :---:, दाएँ के लिए ---: लिखा जाता है, और अलाइनमेंट न हो तो सादे डैश रहते हैं। ज़रूरत पड़ने पर सेल का टेक्स्ट एस्केप किया जाता है: पाइप \| बन जाता है और नई लाइन HTML टैग <br> बन जाती है। फिर टूल कॉलम को स्पेस से बराबर करता है ताकि सोर्स टेबल जैसा दिखे। इसके लिए वह बाइट की गिनती नहीं, हर अक्षर की चौड़ाई इस्तेमाल करता है, इसलिए मात्राओं और एक्सेंट वाले अक्षर भी सीध में रहते हैं।

स्प्रेडशीट से पेस्ट करना शुरू करने का सबसे तेज़ तरीका है। स्प्रेडशीट कॉपी किए सेल को क्लिपबोर्ड पर टैब से अलग टेक्स्ट के रूप में रखती हैं, हर पंक्ति के लिए एक लाइन, और ग्रिड उसे सीधे पढ़ लेता है। CSV और TSV फ़ाइलें भी पेस्ट बॉक्स के ज़रिए इसी तरह काम करती हैं, जिनमें कोटेशन में बंद फ़ील्ड और कोटेशन के अंदर की नई लाइनें भी सँभाली जाती हैं। अगर आप पहले से बनी Markdown टेबल पेस्ट करते हैं, तो सेल और अलाइनमेंट वापस ग्रिड में पढ़ लिए जाते हैं ताकि आप उन्हें बदल सकें।

सुझाव

  • स्प्रेडशीट की जगह JSON है? पहले उसे JSON से CSV से बदलें, फिर नतीजा यहाँ पेस्ट करें।
  • Markdown से HTML से देखें कि टेबल कैसी दिखेगी।
  • उल्टी दिशा में, यानी वेब पेज से वापस Markdown में जाने के लिए HTML से Markdown इस्तेमाल करें।
