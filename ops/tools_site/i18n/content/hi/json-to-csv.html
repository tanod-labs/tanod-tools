शुरू करने के लिए JSON पेस्ट करें।

JSON को स्प्रेडशीट में बदलना

API और एक्सपोर्ट अक्सर आपको JSON देते हैं, जबकि जिन लोगों को डेटा चाहिए वे स्प्रेडशीट चाहते हैं। CSV दोनों के बीच पुल बनाता है: ऐरे का हर ऑब्जेक्ट एक पंक्ति बनता है और हर की एक कॉलम। असली डेटा में ऑब्जेक्ट की सारी कीज़ शायद ही कभी एक जैसी होती हैं, इसलिए टूल हर वह की इकट्ठा करता है जो उसे दिखती है, उसी क्रम में जिसमें वह पहली बार दिखती है, और जिस ऑब्जेक्ट में उस कॉलम का मान नहीं है वहाँ सेल खाली छोड़ता है।

स्प्रेडशीट सपाट होती हैं, इसलिए नेस्टेड डेटा को किसी तरह कॉलमों में समेटना पड़ता है। समतल करने पर user.name और user.email अलग कॉलम बन जाते हैं, जो ज़्यादातर रिपोर्टों के लिए ठीक बैठता है। नेस्टेड ऑब्जेक्ट को JSON टेक्स्ट के रूप में रखने से कॉलमों की संख्या कम रहती है और आप बाद में मूल ढाँचा दोबारा बना सकते हैं।

CSV आम नियमों (RFC 4180) का पालन करता है: मान सिर्फ़ ज़रूरत पड़ने पर कोट होते हैं और मान के अंदर के कोट दोहराए जाते हैं। संख्याएँ आपके JSON के ठीक वही अंक रखती हैं, उस तरह राउंड नहीं होतीं जैसे JavaScript संख्याएँ होतीं।

सुझाव

  • उल्टी दिशा में जाना है? CSV से JSON इस्तेमाल करें।
  • अगर JSON कन्वर्ट नहीं हो रहा, तो JSON फ़ॉर्मैट और वैलिडेट करें से समस्या ढूँढें।
  • दो एक्सपोर्ट को लाइन-दर-लाइन टेक्स्ट की तुलना करें से मिलाएं।
