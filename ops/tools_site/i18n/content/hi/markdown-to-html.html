शुरू करने के लिए Markdown टाइप या पेस्ट करें।

Markdown HTML कैसे बनता है

Markdown सादे वर्णों से फ़ॉर्मैट किया टेक्स्ट लिखने का तरीका है: # हेडिंग शुरू करता है, **दो तारे** बोल्ड बनाते हैं, डैश से शुरू होने वाली लाइन सूची का आइटम होती है। README फ़ाइलें, कई नोट्स ऐप और ज़्यादातर डेवलपर फ़ोरम यही इस्तेमाल करते हैं। ब्राउज़र, ईमेल टेम्पलेट और कंटेंट सिस्टम को HTML चाहिए, इसलिए कभी न कभी Markdown का अनुवाद करना पड़ता है।

यह कन्वर्टर GitHub Flavored Markdown के जोड़ों के साथ CommonMark का पालन करता है, इसलिए टेबल, टास्क लिस्ट और स्ट्राइकथ्रू वैसे ही काम करते हैं जैसे GitHub पर। इसका बनाया HTML फिर एक सैनिटाइज़र से गुज़रता है, जो ऐसी हर चीज़ हटा देता है जो HTML दिखाए जाने पर कोड चला सके, और सामान्य फ़ॉर्मैटिंग को नहीं छेड़ता।

प्रीव्यू टैब वही HTML पेज में रेंडर करके दिखाता है। लिंक नए टैब में खुलते हैं, और कहीं और होस्ट की गई इमेज लोड होने के बजाय प्लेसहोल्डर के रूप में दिखती हैं, इसलिए आप जो लिखते हैं वह काम करते समय किसी दूसरी साइट को नहीं भेजा जाता।
