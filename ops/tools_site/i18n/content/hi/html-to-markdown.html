वेब पेज को Markdown में बदलना

किसी वेब पेज, पुराने CMS या रिच-टेक्स्ट एडिटर से सामग्री निकालकर README, स्टैटिक साइट या नोट्स ऐप में ले जाने के लिए आम तौर पर HTML को Markdown में बदलना पड़ता है। कन्वर्टर HTML के ढाँचे को देखता चलता है और हर एलिमेंट को उसके Markdown रूप में लिखता है: हेडिंग # वाली लाइनें बन जाती हैं, सूचियाँ डैश बन जाती हैं, लिंक [text](url) बन जाते हैं, और <pre><code> कोड ब्लॉक बन जाता है।

Markdown सिर्फ़ ढाँचा बताता है, इसलिए स्टाइलिंग पीछे छूट जाती है। इनलाइन स्टाइल, क्लास, रंग और लेआउट के कंटेनर गायब हो जाते हैं, जबकि शब्द, ज़ोर, लिंक, इमेज और सूचियाँ बनी रहती हैं। टेबल जब उस फ़ॉर्मैट में समा सकने लायक सरल हों, तो GitHub Flavored Markdown टेबल के रूप में लिखी जाती हैं।

अलग-अलग प्रोजेक्ट की Markdown की अपनी आदतें होती हैं, इसीलिए हेडिंग, सूची के चिह्न, कोड ब्लॉक और इटैलिक की शैलियाँ बदली जा सकती हैं। ज़्यादातर रेंडरर इनमें से कोई भी मान लेते हैं।

सुझाव

  • Markdown से HTML में, जिसमें प्रीव्यू है, देखें कि Markdown कैसा रेंडर होता है।
  • बची हुई खाली जगह या शब्दों को खोजें और बदलें से ठीक करें।
  • नतीजे के शब्द शब्द गिनें से गिनें।
