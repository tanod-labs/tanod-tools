Как Markdown превращается в HTML

Markdown — это способ записи форматированного текста обычными символами: # начинает заголовок, **две звёздочки** дают полужирный, строка с дефисом в начале — элемент списка. Так пишут файлы README, многие приложения для заметок и большинство форумов разработчиков. Браузерам, шаблонам писем и системам управления контентом нужен HTML, поэтому в какой-то момент Markdown приходится переводить.

Этот конвертер следует CommonMark с дополнениями GitHub Flavored Markdown, поэтому таблицы, списки задач и зачёркивание работают так же, как на GitHub. Полученный HTML затем проходит через санитайзер, который удаляет всё, что могло бы выполнить код при показе HTML, и не трогает обычное форматирование.

Вкладка предпросмотра показывает тот же HTML, отрисованный на странице. Ссылки открываются в новой вкладке, а изображения, размещённые на других сайтах, показываются заглушками и не загружаются, поэтому ничто из написанного вами не отправляется на другой сайт, пока вы работаете.

Советы

  • Есть HTML, а нужен Markdown? Используйте «HTML в Markdown».
  • Проверить длину публикации можно в инструменте «Подсчёт слов».
  • Сравните два черновика в инструменте «Сравнить тексты».
