Параметры

    Per Connection Queue на практике

    PCQ — это тип очереди: он задаётся в разделе /queue type с kind=pcq, а затем его используют simple queue или queue tree. Параметр pcq-classifier определяет, что считать одним потоком: dst-address для загрузки, чтобы загрузка каждого клиента была отдельным потоком, и src-address для отдачи. RouterOS создаёт подпотоки на лету и удаляет их, когда они затихают, так что при появлении и уходе клиентов ничего поддерживать не нужно.

    Результат определяют две настройки. pcq-rate ограничивает каждый поток; если оставить 0, потоки просто делят поровну то, что позволяет max-limit очереди. Значение max-limit очереди с PCQ должно быть немного ниже реальной пропускной способности канала: PCQ может честно делить полосу только тогда, когда пакеты ждут в очереди на маршрутизаторе, а не в модеме выше по цепочке.

    Simple queue или queue tree?

    Метод simple queue не требует маркировки: одна очередь с подсетью локальной сети в качестве target и queue=upload-type/download-type. Метод queue tree использует mangle, чтобы пометить соединения из LAN в WAN, и две очереди с parent=global; он не ограничивает трафик между локальными сетями и служит отправной точкой для классов приоритета. В любом случае настройки burst для каждого клиента относятся к simple queue; сравните их с помощью инструментов Генератор Simple Queue для MikroTik и Калькулятор Burst для MikroTik.
