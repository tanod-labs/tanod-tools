    Объединение PDF без загрузки на сервер

    Для объединения PDF сервер не нужен. Каждая страница в PDF — это самодостаточное описание текста, изображений и команд рисования, поэтому объединение файлов означает копирование этих объектов страниц в новый документ и запись нового оглавления. Ваш браузер может сделать это сам с файлами на вашем устройстве.

    Страницы копируются, а не отрисовываются заново, поэтому объединённый файл имеет то же качество, что и исходные: текст остаётся доступным для выделения и поиска, а изображения не пережимаются. Новый документ получает один список страниц в заданном вами порядке.

    Советы

    • Нужны только некоторые страницы файла? Сначала пропустите его через «Извлечь страницы из PDF» или удалите страницы после объединения с помощью «Удалить страницы из PDF».
    • Объединяете фото или сканы? Превратите их в PDF в инструменте «JPG в PDF», а затем объедините.
