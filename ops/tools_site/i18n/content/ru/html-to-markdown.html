Как превратить веб-страницу в Markdown

Чтобы перенести содержимое веб-страницы, старой CMS или визуального редактора в README, статический сайт или приложение для заметок, обычно нужно преобразовать HTML в Markdown. Конвертер обходит структуру HTML и записывает каждый элемент в форме Markdown: заголовки становятся строками с #, списки — строками с дефисами, ссылки — записью [текст](url), а <pre><code> — блоком кода.

Markdown описывает только структуру, поэтому оформление теряется. Встроенные стили, классы, цвета и контейнеры вёрстки исчезают, а слова, выделение, ссылки, изображения и списки остаются. Если таблица достаточно проста, она записывается как таблица в формате GitHub Flavored Markdown.

В разных проектах приняты разные привычки записи Markdown, поэтому стили заголовков, маркеры списков, блоки кода и курсив можно менять. Большинство средств отображения понимают любой из вариантов.

Советы

  • Посмотреть, как отображается Markdown, можно в инструменте «Markdown в HTML» с предпросмотром.
  • Убрать лишние пробелы и поправить формулировки поможет «Поиск и замена».
  • Посчитайте слова в результате с помощью «Подсчёт слов».
