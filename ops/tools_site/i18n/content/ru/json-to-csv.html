Как превратить JSON в таблицу

API и экспорты часто отдают JSON, а тем, кому нужны данные, нужна таблица. CSV соединяет их: каждый объект массива становится строкой, а каждый ключ — столбцом. Поскольку в реальных данных у объектов редко бывают одинаковые наборы ключей, инструмент собирает все встреченные ключи в порядке первого появления и оставляет ячейку пустой там, где у объекта нет значения для этого столбца.

Таблицы плоские, поэтому вложенные данные приходится как-то уложить в столбцы. Разворачивание превращает user.name и user.email в отдельные столбцы, что подходит для большинства отчётов. Сохранение вложенных объектов как текста JSON уменьшает число столбцов и позволяет позже восстановить исходную структуру.

CSV следует обычным правилам (RFC 4180): значения берутся в кавычки только при необходимости, а кавычки внутри значения удваиваются. Числа сохраняют точные цифры из вашего JSON и не округляются так, как это делали бы числа JavaScript.

Советы

  • Нужно обратное преобразование? Используйте «CSV в JSON».
  • Если JSON не преобразуется, найдите проблему в инструменте «Форматирование и проверка JSON».
  • Сравните два экспорта построчно в инструменте «Сравнить тексты».
