Для чего нужен хеш

Криптографическая хеш-функция превращает любые данные, от одной буквы до большого файла, в короткий отпечаток фиксированной длины. Одинаковые данные всегда дают одинаковый отпечаток, а изменение даже одного бита даёт совершенно другой. Поэтому хеши полезны для проверки того, что файл дошёл без изменений, для поиска дубликатов, а также как составная часть подписей и систем контроля версий.

Чтобы проверить скачанный файл, найдите контрольную сумму, которую издатель указал рядом с ним (чаще всего SHA-256), перетащите файл сюда и вставьте сумму в поле «Сравнить». Если значения совпали, файл байт в байт совпадает с тем, что хешировал издатель. Совпадение доказывает, что это именно тот файл, лишь если вы доверяете странице, с которой взята контрольная сумма.

Хеши SHA-1 и SHA-2 (SHA-256, SHA-384, SHA-512) вычисляются функциями Web Crypto вашего браузера. Браузеры не поддерживают MD5, поэтому на странице есть собственный код MD5: он читает файлы частями и показывает ход выполнения для больших файлов. MD5 и SHA-1 оставлены только для совместимости со старыми контрольными суммами.

Советы

  • Нужно содержимое файла в виде текста, а не отпечаток? Воспользуйтесь инструментом «Кодирование и декодирование Base64».
  • Чтобы создать надёжный случайный секрет, а не хешировать готовый, используйте «Генератор паролей».
  • Два текста удобнее сравнивать построчно в инструменте «Сравнить тексты», чем по двум хешам.
