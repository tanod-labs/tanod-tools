Как читать различия в конфигурации RouterOS

Экспорт — это конфигурация роутера, записанная в виде команд, которые её воссоздают: строка меню, например /ip firewall filter, а за ней команды add и set для этого меню. В экспорт попадают только настройки, отличающиеся от значений по умолчанию. Из-за этого экспорты получаются короткими, но параметр, возвращённый к значению по умолчанию, просто исчезает из нового экспорта. Сравнение считает каждое меню разделом, сопоставляет его команды по порядку и выделяет изменившиеся разделы.

Часть различий — это шум, а не изменения: заголовок с датой экспорта, идентификатором ПО и серийным номером отбрасывается, перенесённые строки склеиваются, а строки-комментарии можно игнорировать. Остаётся то, что роутер действительно будет делать иначе. Порядок сохраняется намеренно: правила firewall, NAT, mangle и очередей обрабатываются сверху вниз, поэтому перемещение правила — это настоящее изменение.

Советы

  • Сохраняйте экспорт с датой после каждого окна изменений и сравнивайте его с предыдущим, чтобы точно видеть, что было сделано.
  • Проверяете обновление с v6 на v7? Сравните сценарий, преобразованный «Помощником по переходу с RouterOS v6 на v7», с экспортом, снятым после обновления.
  • Для обычного текста, который не является экспортом, подойдёт общий инструмент «Сравнить тексты»: он тоже сравнивает по словам.
