Client Hints вашего браузера

Что user agent сообщает и что скрывает

User agent появился как способ для сервера видеть, какой браузер его запрашивает, чтобы отправить страницу, которая в нём работает. Затем браузеры стали копировать названия друг друга, чтобы получать хорошие страницы, поэтому сегодня строка Chrome упоминает Mozilla, AppleWebKit, KHTML, Gecko и Safari. Разбор обходит это, проверяя шаблоны в тщательно выбранном порядке и выбирая самое точное совпадение.

Строку к тому же намеренно сокращают. Сокращение User-Agent в Chrome фиксирует версию Windows на NT 10.0, версию macOS на 10_15_7, модель Android на K и номер сборки на 0.0.0, чтобы строка перестала быть хорошим отпечатком. Подробности никуда не делись: страница, запросившая их через Client Hints, получает версию платформы, архитектуру, модель и полную версию браузера, а браузер посетителя решает, отвечать ли.

Используйте строку для грубых решений и журналов, а не для доверия. Поисковые роботы и программы командной строки вроде curl отправляют свои короткие строки, а подделать можно что угодно. Если вы ищете ошибку вёрстки, определение возможностей на странице надёжнее, чем чтение названия браузера.

Советы

  • В журнале сервера много ответов 403 или 429 для одного клиента? Найдите коды в справочнике «Коды состояния HTTP».
  • User agent в URL или строках запроса часто закодированы процентным кодированием; декодируйте их в «Кодирование и декодирование URL».
  • Заголовки, скопированные из запроса, иногда содержат значения Base64; прочитайте их в «Кодирование и декодирование Base64».
