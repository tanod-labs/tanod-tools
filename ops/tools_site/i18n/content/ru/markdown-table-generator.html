Как записывается таблица Markdown

Таблица Markdown в стиле GitHub это обычный текст: строка заголовка, строка из дефисов, задающая выравнивание, и по одной строке на каждую строку данных, а ячейки разделены вертикальными чертами. Этот формат GitHub отображает в README, issue и pull request, и его понимают многие другие инструменты, в том числе сайты документации и приложения для заметок.

Сетка хранит ячейки; первая строка это заголовок. У каждого столбца есть выравнивание. По левому краю записывается :---, по центру :---:, по правому краю ---:, а без выравнивания остаются простые дефисы. Текст ячеек при необходимости экранируется: вертикальная черта превращается в \|, а перенос строки в HTML-тег <br>. Затем инструмент выравнивает столбцы пробелами, чтобы исходный текст выглядел как таблица. Он учитывает ширину каждого символа, а не число байтов, поэтому буквы с диакритикой тоже выстраиваются ровно.

Вставка из электронной таблицы самый быстрый способ начать. Электронные таблицы помещают скопированные ячейки в буфер обмена как текст с табуляциями, по одной строке на каждую строку таблицы, и сетка читает его напрямую. Файлы CSV и TSV работают так же через поле вставки, а поля в кавычках и переносы строк внутри кавычек обрабатываются. Если вставить готовую таблицу Markdown, ячейки и выравнивание считываются обратно в сетку, и их можно менять.

Советы

  • Есть JSON вместо электронной таблицы? Сначала преобразуйте его через JSON в CSV, а результат вставьте сюда.
  • Посмотрите, как будет выглядеть таблица, с помощью Markdown в HTML.
  • Чтобы пойти в обратную сторону, от веб-страницы к Markdown, используйте HTML в Markdown.
