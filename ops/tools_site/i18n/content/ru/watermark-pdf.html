Водяной знак для PDF в браузере

Водяной знак — это текст, нарисованный на каждой странице. Ваш браузер открывает PDF с помощью pdf-lib, определяет видимую область каждой страницы и рисует там текст выбранным вами цветом, с выбранной прозрачностью и под выбранным углом. Результат — новый файл; оригинал остаётся как был.

Текст набирается шрифтом Helvetica, одним из тех, что уже есть в каждой программе просмотра PDF; это сохраняет небольшой размер результата, но ограничивает символы западноевропейским латинским набором. Мозаичное расположение повторяет текст в шахматном порядке, чтобы его нельзя было обрезать с одного угла.

Советы

  • Оставляйте прозрачность невысокой, около 20–35 процентов, чтобы страница оставалась читаемой.
  • Нужна ещё и нумерация страниц? Добавьте её с помощью «Пронумеровать страницы PDF».
  • Нужно передать «плоскую» копию? Превратите страницы в картинки с помощью «PDF в JPG».
