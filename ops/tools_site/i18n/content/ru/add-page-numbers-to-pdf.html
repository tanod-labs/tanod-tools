Нумерация страниц без загрузки PDF

Номера страниц — это небольшие фрагменты текста, нарисованные поверх каждой страницы. Браузер справляется с этим сам: он открывает PDF с помощью pdf-lib, добавляет строку текста шрифтом Helvetica на каждую выбранную страницу и записывает новый файл. Исходное содержимое страниц не затрагивается.

У каждой страницы могут быть свой размер, рамка обрезки и поворот, поэтому положение вычисляется для каждой страницы отдельно. Отступы отсчитываются от края видимой области, а на странице, хранящейся в повёрнутом виде, номер поворачивается вместе с ней и читается прямо там, где вы ожидаете.

Советы

  • Склеиваете несколько файлов? Сначала используйте «Объединить PDF», а затем пронумеруйте результат, чтобы нумерация шла сквозная.
  • Нужна отметка поперёк страницы, а не номер? Попробуйте «Водяной знак для PDF».
  • Страницы идут не в том порядке? Исправьте это инструментом «Изменить порядок страниц в PDF» до нумерации.
