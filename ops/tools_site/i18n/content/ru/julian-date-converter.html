Формулы

Календарная дата переводится в юлианскую дату по алгоритму из книги Жана Мееса Astronomical Algorithms (2-е изд., 1998), глава 7, а страница использует эквивалентное соотношение со временем Unix JD = секунды Unix / 86 400 + 2 440 587,5, верное для пролептического григорианского календаря вашего браузера. Модифицированная юлианская дата равна MJD = JD − 2 400 000,5 (IAU, 1973). Эпоха J2000.0 — это JD 2 451 545,0.

Время GPS — непрерывная шкала времени, начавшаяся 1980-01-06 00:00:00 UTC (спецификация интерфейса IS-GPS-200). Неделя GPS равна floor(секунды с этой эпохи / 604 800), секунды недели — остаток, а передаваемая 10-битная неделя — это неделя по модулю 1024. Время GPS равно UTC плюс число високосных секунд, вставленных с 1980 года: 18 с 2017-01-01, по таблице из 18 вставок, публикуемой IERS (Bulletin C). Инструмент применяет число, действовавшее в данный момент.

IERS объявляет високосные секунды лишь за несколько месяцев, поэтому время GPS для будущих дат предполагает отсутствие новых високосных секунд. Не для навигации.
