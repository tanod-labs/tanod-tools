Jak zapisuje się tabelę Markdown

Tabela Markdown w stylu GitHuba to zwykły tekst: wiersz nagłówka, wiersz kresek ustalający wyrównanie i po jednej linii na każdy wiersz danych, z komórkami oddzielonymi kreskami pionowymi. Ten format GitHub wyświetla w plikach README, zgłoszeniach i pull requestach, a rozumie go też wiele innych narzędzi, w tym serwisy z dokumentacją i aplikacje do notatek.

Siatka przechowuje komórki; pierwszy wiersz to nagłówek. Każda kolumna ma wyrównanie. Do lewej zapisuje się :---, do środka :---:, do prawej ---:, a brak wyrównania to zwykłe kreski. Tekst komórek jest w razie potrzeby poprzedzany znakiem ucieczki: kreska pionowa zamienia się w \|, a podział wiersza w znacznik HTML <br>. Następnie narzędzie wyrównuje kolumny spacjami, aby źródło wyglądało jak tabela. Bierze przy tym pod uwagę szerokość każdego znaku, a nie liczbę bajtów, dzięki czemu polskie litery też się równo ustawiają.

Wklejenie z arkusza kalkulacyjnego to najszybszy sposób na start. Arkusze umieszczają skopiowane komórki w schowku jako tekst rozdzielany tabulatorami, po jednej linii na wiersz, a siatka czyta go wprost. Pliki CSV i TSV działają tak samo przez pole wklejania, z obsługą pól w cudzysłowie i podziałów wiersza w cudzysłowie. Jeśli wkleisz istniejącą tabelę Markdown, komórki i wyrównania zostaną wczytane z powrotem do siatki, żebyś mógł je zmienić.

Wskazówki

  • Masz JSON zamiast arkusza? Najpierw przekonwertuj go narzędziem JSON na CSV, a wynik wklej tutaj.
  • Zobacz, jak tabela będzie wyglądać, w narzędziu Markdown na HTML.
  • W przeciwną stronę, od strony internetowej z powrotem do Markdown, użyj HTML na Markdown.
