Zamiana JSON na arkusz kalkulacyjny

Interfejsy API i eksporty często dają JSON, a osoby potrzebujące danych chcą arkusza kalkulacyjnego. CSV łączy te dwa światy: każdy obiekt w tablicy staje się wierszem, a każdy klucz kolumną. Ponieważ obiekty w prawdziwych danych rzadko mają te same klucze, narzędzie zbiera wszystkie napotkane klucze w kolejności ich pierwszego wystąpienia i zostawia pustą komórkę tam, gdzie obiekt nie ma wartości dla danej kolumny.

Arkusze są płaskie, więc zagnieżdżone dane trzeba jakoś upchnąć w kolumnach. Spłaszczanie zamienia user.name i user.email w osobne kolumny, co pasuje do większości raportów. Zachowanie zagnieżdżonych obiektów jako tekstu JSON ogranicza liczbę kolumn i pozwala później odtworzyć pierwotną strukturę.

CSV podąża za zwykłymi regułami (RFC 4180): wartości są ujmowane w cudzysłów tylko w razie potrzeby, a cudzysłowy wewnątrz wartości są podwajane. Liczby zachowują dokładne cyfry z JSON zamiast być zaokrąglane, jak liczby JavaScriptu.

Wskazówki

  • Potrzebujesz odwrotnej konwersji? Użyj narzędzia CSV na JSON.
  • Jeśli JSON nie chce się skonwertować, znajdź problem w narzędziu Formatuj i waliduj JSON.
  • Porównaj dwa eksporty wiersz po wierszu w narzędziu Porównaj teksty.
