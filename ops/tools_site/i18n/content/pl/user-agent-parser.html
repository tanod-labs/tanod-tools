Client Hints z twojej przeglądarki

Co mówi user agent i co ukrywa

User agent powstał jako sposób, aby serwer widział, która przeglądarka o coś prosi, i mógł wysłać stronę, która tam działa. Przeglądarki zaczęły potem kopiować swoje nazwy nawzajem, aby dostawać lepsze strony, dlatego dzisiejszy ciąg Chrome mówi też Mozilla, AppleWebKit, KHTML, Gecko i Safari. Analizator radzi sobie z tym, sprawdzając wzorce w starannie dobranej kolejności i wybierając najbardziej szczegółowe dopasowanie.

Ciąg jest też celowo skracany. Redukcja User-Agent w Chrome ustala wersję Windows na NT 10.0, wersję macOS na 10_15_7, model Androida na K, a numer kompilacji na 0.0.0, aby ciąg przestał być dobrym odciskiem palca. Szczegóły nie zniknęły: strona, która poprosi o nie przez Client Hints, dostaje wersję platformy, architekturę, model i pełną wersję przeglądarki, a przeglądarka odwiedzającego decyduje, czy odpowiedzieć.

Używaj ciągu do zgrubnych decyzji i logów, a nie do budowania zaufania. Roboty indeksujące i narzędzia wiersza poleceń, takie jak curl, wysyłają własne krótkie ciągi, a wszystko można podrobić. Jeśli szukasz błędu w układzie strony, wykrywanie funkcji na stronie jest bardziej niezawodne niż odczytywanie nazwy przeglądarki.

Wskazówki

  • W logu serwera pełno odpowiedzi 403 lub 429 dla jednego klienta? Sprawdź kody w narzędziu Kody statusu HTTP.
  • User agenty w adresach URL lub ciągach zapytań są często zakodowane procentowo; odkoduj je w narzędziu Koduj i dekoduj URL.
  • Nagłówki skopiowane z żądania czasem zawierają wartości Base64; odczytaj je w narzędziu Koduj i dekoduj Base64.
