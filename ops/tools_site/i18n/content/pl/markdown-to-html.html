Jak Markdown staje się HTML

Markdown to sposób zapisu sformatowanego tekstu zwykłymi znakami: # zaczyna nagłówek, **dwie gwiazdki** dają pogrubienie, a wiersz zaczynający się myślnikiem to element listy. Używają go pliki README, wiele aplikacji do notatek i większość for dla programistów. Przeglądarki, szablony e-maili i systemy zarządzania treścią chcą HTML, więc w pewnym momencie Markdown trzeba przetłumaczyć.

Ten konwerter podąża za CommonMark z dodatkami GitHub Flavored Markdown, więc tabele, listy zadań i przekreślenia działają tak jak na GitHubie. Wygenerowany HTML przechodzi następnie przez sanitizer, który usuwa wszystko, co mogłoby uruchomić kod po wyświetleniu HTML, zostawiając zwykłe formatowanie bez zmian.

Karta podglądu pokazuje ten sam HTML wyrenderowany na stronie. Linki otwierają się w nowej karcie, a obrazy hostowane gdzie indziej są pokazywane jako symbole zastępcze zamiast być pobierane, więc nic, co piszesz, nie jest wysyłane do innej witryny podczas pracy.
