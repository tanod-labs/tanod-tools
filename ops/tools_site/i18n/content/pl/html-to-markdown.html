Zamiana stron internetowych na Markdown

Przeniesienie treści ze strony internetowej, starego CMS-a lub edytora tekstu sformatowanego do pliku README, generatora stron statycznych czy aplikacji do notatek zwykle oznacza konwersję HTML na Markdown. Konwerter przechodzi po strukturze HTML i zapisuje każdy element w odpowiedniej postaci Markdown: nagłówki stają się wierszami z #, listy myślnikami, linki zapisem [tekst](url), a <pre><code> blokiem kodu.

Markdown opisuje tylko strukturę, więc style zostają za nami. Style wbudowane, klasy, kolory i kontenery układu znikają, a słowa, wyróżnienia, linki, obrazy i listy pozostają. Tabele są zapisywane jako tabele GitHub Flavored Markdown, jeśli są wystarczająco proste, by zmieścić się w tym formacie.

Różne projekty preferują różne zwyczaje zapisu Markdownu, dlatego styl nagłówków, znacznik listy, blok kodu i kursywę można zmienić. Większość rendererów akceptuje każdy z nich.
