Ausgabe

Bilder als Text einbetten

HTML, CSS, JSON, Markdown und E-Mail-Texte bestehen aus Text, Bilder dagegen sind binär. Base64 schlägt die Brücke, indem es die Bytes des Bildes mit 64 sicheren Zeichen schreibt. Wenn Sie ein Bild in Base64 umwandeln, kann das ganze Bild in einer Stylesheet-Regel, einem img-Tag oder einer Konfigurationsdatei stehen, ohne separaten Download.

Dieses Tool liest die Datei in Ihrem Browser, prüft ihren tatsächlichen Typ anhand der ersten Bytes und baut das gewählte Snippet um den kodierten Text. Das Bild selbst wird nicht verändert: Dekodiert man das Base64, erhält man exakt die Originaldatei zurück.

Tipps

  • Verkleinern Sie das Bild vorher mit Bild komprimieren oder Bildgröße ändern; jedes eingesparte Byte spart in Base64 ein Drittel mehr.
  • Für einfache Icons ist eine SVG-Datei oft kleiner als jedes PNG, selbst als Base64.
  • Um Base64 wieder in eine Datei zu verwandeln oder eine beliebige andere Datei zu kodieren, nutzen Sie Base64 kodieren und dekodieren.
