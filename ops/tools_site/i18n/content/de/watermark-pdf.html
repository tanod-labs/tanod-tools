Ein PDF im Browser mit Wasserzeichen versehen

Ein Wasserzeichen ist Text, der auf jede Seite gezeichnet wird. Ihr Browser öffnet das PDF mit pdf-lib, ermittelt den sichtbaren Bereich jeder Seite und zeichnet den Text dort in der gewählten Farbe, Deckkraft und im gewählten Winkel. Das Ergebnis ist eine neue Datei; Ihr Original bleibt, wie es war.

Der Text nutzt Helvetica, eine der Schriften, die jeder PDF-Viewer bereits mitbringt. Das hält die Ausgabe klein, beschränkt die Zeichen aber auf den westeuropäischen lateinischen Zeichensatz. Die gekachelte Platzierung wiederholt den Text in einem versetzten Muster, sodass er sich nicht von einer Ecke aus wegschneiden lässt.

Tipps

  • Halten Sie die Deckkraft niedrig, etwa 20 bis 35 Prozent, damit die Seite lesbar bleibt.
  • Sie möchten auch Seitenzahlen? Fügen Sie sie mit Seitenzahlen in PDF einfügen hinzu.
  • Sie möchten eine nicht bearbeitbare Kopie teilen? Wandeln Sie die Seiten mit PDF in JPG in Bilder um.
