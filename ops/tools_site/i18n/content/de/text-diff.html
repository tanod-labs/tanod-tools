So funktioniert der Vergleich

Wenn Sie zwei Texte vergleichen, sucht ein Diff die kürzeste Liste von Änderungen, die das Original in den geänderten Text verwandelt. Übereinstimmende Abschnitte bleiben unangetastet; der Rest wird als aus dem Original entfernt und in der neuen Fassung hinzugefügt angezeigt. Dieses Tool nutzt die Open-Source-Bibliothek jsdiff, die in Ihrem Browser läuft.

Wird ein Block von Zeilen ersetzt, stehen alte und neue Fassung in der Ansicht nebeneinander auf denselben Zeilen, sodass Sie sie quer lesen können. Auf dem Smartphone werden die beiden Seiten untereinander angezeigt. „.txt-Datei öffnen“ füllt das Feld, das Sie zuletzt benutzt haben.

Tipps

  • Vergleichen Sie Listen, nachdem Sie sie mit Doppelte Zeilen entfernen bereinigt haben.
  • Nehmen Sie dieselbe Änderung vorher überall mit Suchen und Ersetzen vor.
  • Sie vergleichen zwei Datenexporte? Wandeln Sie sie vorher mit JSON in CSV um, damit jeder Datensatz in einer Zeile steht.
  • Klicken Sie auf Tauschen, um den Vergleich in umgekehrter Richtung zu sehen.
