Wofür Base64 da ist


Mit Base64 kodieren Sie eine beliebige Folge von Bytes in 64 sichere Textzeichen: A–Z, a–z, 0–9, Plus und Schrägstrich. Je 3 Bytes werden zu 4 Zeichen, die letzte Gruppe wird mit = aufgefüllt. So lassen sich Binärdaten gefahrlos in E-Mails, JSON, HTML, URLs und anderen Umgebungen unterbringen, die nur mit Text umgehen können. Base64 ist eine Kodierung, keine Verschlüsselung: Jeder kann es wieder dekodieren.


Text wird zunächst in Bytes umgewandelt, und dabei kommt es auf die Zeichenkodierung an. Dieses Tool verwendet UTF-8, den Standard im Web, sodass Umlaute, nicht lateinische Schriften und Symbole den Hin- und Rückweg überstehen. Beim Dekodieren wird geprüft, ob das Ergebnis gültiges UTF-8 ist, und Sie erfahren es, wenn nicht; meist bedeutet das, dass die Daten eine Datei und kein Text waren.


Im Modus Datei wird die Datei in Ihrem Browser gelesen und in kleinen Stücken kodiert, damit die Seite reaktionsfähig bleibt. In der Gegenrichtung dekodiert das Tool eingefügtes Base64 zu Bytes und stellt sie Ihnen als Download bereit. Anhand der ersten Bytes schlägt es für gängige Formate wie PNG, JPEG, GIF, PDF und ZIP eine Dateiendung vor.
