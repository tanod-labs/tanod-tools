Dies ist eine Online-Stimme. Der Text, den Sie damit vorlesen lassen, wird an den Sprachdienst des Browserherstellers gesendet. Wählen Sie eine Stimme ohne die Markierung (online), damit der Text auf diesem Gerät bleibt.

Audio lässt sich mit diesem Tool nicht speichern: Der Browser gibt die Sprache direkt über Ihre Lautsprecher aus und reicht sie nicht an Webseiten weiter.

Was passiert, wenn eine Webseite spricht

Wenn Sie im Browser Text vorlesen lassen, ist das eine Übergabe. Die Seite gibt Ihren Text, einen Stimmennamen, ein Tempo und eine Tonhöhe an den Browser, und der Browser bittet das Betriebssystem, in manchen Fällen auch die Server des Browserherstellers, daraus Ton zu machen. Deshalb hören zwei Menschen auf derselben Seite unterschiedliche Stimmen, und deshalb gibt es hier nichts herunterzuladen: Die Seite selbst erhält nie Audio.

Stimmen auf dem Gerät sind die, die Ihr System mitbringt, etwa mit Windows, macOS, iOS oder Android installierte, und sie funktionieren offline. Netzwerkstimmen klingen meist natürlicher, weshalb Browser sie anbieten, doch der Text muss dafür an einen Server gehen, um gesprochen zu werden. Dieser Unterschied ist bei vertraulichem Material wichtig; achten Sie also auf die Markierung (online), bevor Sie etwas Sensibles einfügen.

Zuhören ist ein guter Trick beim Korrekturlesen. Müde Augen gleiten über ein doppeltes Wort oder einen fehlenden Punkt hinweg, eine Stimme aber liest genau, was dasteht, und stolpert dort, wo der Satz stolpert. Verringern Sie das Tempo etwas und folgen Sie dem hervorgehobenen Wort.

Tipps

  • Prüfen Sie vorher mit Wörter zählen, wie lange das Vorlesen einer Passage dauert; dort gibt es eine Schätzung der Sprechzeit.
  • Entfernen Sie überzählige Zeilenumbrüche aus kopiertem Text mit Zeilenumbrüche entfernen, damit Sätze nicht bruchstückhaft vorgelesen werden.
  • Stellen Sie vor dem Anhören mit Groß- und Kleinschreibung umwandeln sicher, dass die richtigen Zeichen und Großbuchstaben stehen.
