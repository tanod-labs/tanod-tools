JSON in eine Tabelle verwandeln

APIs und Exporte liefern oft JSON, während die Menschen, die die Daten brauchen, eine Tabelle wollen. CSV schlägt die Brücke: Wenn Sie JSON in CSV umwandeln, wird jedes Objekt im Array zu einer Zeile und jeder Schlüssel zu einer Spalte. Weil Objekte in echten Daten selten alle dieselben Schlüssel haben, sammelt das Tool jeden Schlüssel in der Reihenfolge, in der es ihn zuerst sieht, und lässt eine Zelle leer, wo ein Objekt für diese Spalte keinen Wert hat.

Tabellen sind flach, also müssen verschachtelte Daten irgendwie in Spalten gepresst werden. Das Abflachen macht aus user.name und user.email getrennte Spalten, was für die meisten Auswertungen passt. Verschachtelte Objekte als JSON-Text zu behalten, hält die Spaltenzahl klein und lässt Sie die ursprüngliche Struktur später wiederherstellen.

Das CSV folgt den üblichen Regeln (RFC 4180): Werte stehen nur bei Bedarf in Anführungszeichen, und Anführungszeichen innerhalb eines Wertes werden verdoppelt. Zahlen behalten die exakten Ziffern aus Ihrem JSON, statt so gerundet zu werden, wie es bei JavaScript-Zahlen geschähe.

Tipps

  • Sie brauchen den umgekehrten Weg? Nutzen Sie CSV in JSON.
  • Wenn sich das JSON nicht umwandeln lässt, finden Sie das Problem mit JSON formatieren und validieren.
  • Vergleichen Sie zwei Exporte Zeile für Zeile mit Texte vergleichen.
