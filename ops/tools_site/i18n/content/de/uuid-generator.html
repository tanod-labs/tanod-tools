Was eine UUID ist, und v4 im Vergleich zu v7


Eine UUID ist eine 128-Bit-Kennung, geschrieben als 32 Hexadezimalziffern in fünf Gruppen. Weil der Wertebereich so groß ist, können Systeme IDs unabhängig voneinander erzeugen, ohne zentralen Zähler, und trotzdem davon ausgehen, dass sie eindeutig sind. Mit diesem UUID-Generator erzeugen Sie solche Kennungen direkt im Browser.


Bei einer UUID der Version 4 sind 122 der 128 Bits zufällig; die übrigen enthalten die Version (4) und die Variante. Eine UUID der Version 7 beginnt mit der Erstellungszeit in Unix-Millisekunden, gefolgt von einem Zähler und Zufallsbits. Weil die Zeit vorne steht, sortieren sich neuere IDs hinter ältere, was für Datenbankindizes günstiger ist als vollständig zufällige Schlüssel. Der Preis ist, dass sich die Erstellungszeit aus der ID ablesen lässt.


Dieses Tool verwendet den sicheren Zufallsgenerator des Browsers. Innerhalb einer Millisekunde steigen Werte der Version 7 über einen 12-Bit-Zähler an, sodass ein Stapel streng geordnet ist.
