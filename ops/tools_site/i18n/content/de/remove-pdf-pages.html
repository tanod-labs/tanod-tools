Seiten löschen, ohne das PDF neu zu erzeugen

Leere Scannerseiten, ein veralteter Anhang, ein Deckblatt, das niemand braucht: Um sie zu entfernen, genügt eine neue Seitenliste, die sie überspringt. Die Seiten, die Sie behalten, werden unverändert kopiert, also wird nichts neu gerendert und nichts verliert an Qualität.

Zum Löschen markierte Seiten erscheinen im Raster blass und durchgestrichen, sodass Sie das Ergebnis vor dem Speichern prüfen können.

Tipps

  • Sie wollen von vielen Seiten nur wenige behalten? PDF-Seiten extrahieren erledigt dieselbe Aufgabe von der anderen Seite.
  • Seiten in falscher Reihenfolge oder quer? Korrigieren Sie das mit PDF-Seiten sortieren und PDF drehen.
