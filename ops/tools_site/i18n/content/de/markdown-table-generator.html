So wird eine Markdown-Tabelle geschrieben

Eine GitHub-Markdown-Tabelle ist reiner Text: eine Kopfzeile, eine Zeile aus Strichen, die die Ausrichtung festlegt, und eine Zeile pro Datenzeile, wobei die Zellen durch senkrechte Striche getrennt sind. GitHub stellt dieses Format in READMEs, Issues und Pull Requests dar, und viele weitere Werkzeuge, darunter Dokumentationsseiten und Notiz-Apps, verstehen es ebenfalls.

Das Raster enthält die Zellen; die erste Zeile ist die Kopfzeile. Jede Spalte hat eine Ausrichtung. Links wird :--- geschrieben, zentriert :---:, rechts ---: und ohne Ausrichtung einfache Striche. Zelltext wird bei Bedarf maskiert: Ein senkrechter Strich wird zu \|, und ein Zeilenumbruch wird zum HTML-Tag <br>. Anschließend richtet das Tool die Spalten mit Leerzeichen aus, damit der Quelltext wie eine Tabelle aussieht. Es verwendet dabei die Breite jedes Zeichens statt der Byte-Anzahl, sodass auch Umlaute und andere Sonderzeichen sauber ausgerichtet sind.

Das Einfügen aus einer Tabellenkalkulation ist der schnellste Einstieg. Tabellenkalkulationen legen kopierte Zellen als tabulatorgetrennten Text mit einer Zeile pro Tabellenzeile in die Zwischenablage, und das Raster liest ihn direkt. CSV- und TSV-Dateien funktionieren über das Einfügefeld genauso, einschließlich Feldern in Anführungszeichen und Zeilenumbrüchen darin. Wenn Sie eine vorhandene Markdown-Tabelle einfügen, werden Zellen und Ausrichtungen zurück ins Raster gelesen, sodass Sie sie ändern können.

Tipps

  • Sie haben JSON statt einer Tabellenkalkulation? Wandeln Sie es zuerst mit JSON in CSV um und fügen Sie das Ergebnis hier ein.
  • Sehen Sie mit Markdown in HTML, wie die Tabelle aussehen wird.
  • Für den umgekehrten Weg, von einer Webseite zurück zu Markdown, nutzen Sie HTML in Markdown.
