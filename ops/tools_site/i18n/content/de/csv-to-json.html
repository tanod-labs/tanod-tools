Von CSV-Zeilen zu JSON

CSV ist der kleinste gemeinsame Nenner für Daten: Jede Tabellenkalkulation und jede Datenbank kann es exportieren. JSON erwarten dagegen die meisten Web-APIs, Skripte und Konfigurationsdateien. Um CSV in JSON umzuwandeln, liest dieses Tool das CSV mit einem Parser, der dem CSV-Standard folgt. Ein Komma in einer Adresse in Anführungszeichen oder ein Zeilenumbruch in einem Kommentar in Anführungszeichen bleibt also in seiner Zelle, statt die Zeile zu teilen.

Mit Kopfzeile wird jede Zeile zu einem Objekt, dessen Schlüssel die Spaltennamen in Spaltenreihenfolge sind. Ohne Kopfzeile wird jede Zeile zu einem Array. Werte bleiben Text, sofern Sie nicht die Umwandlung von Zahlen und true/false anfordern, denn eine CSV-Datei enthält keine Typen, und eine automatische Vermutung kann eine Postleitzahl wie 01067 stillschweigend in die Zahl 1067 verwandeln.

Die Zeile unter den Optionen zeigt, wie viele Zeilen und Spalten gelesen wurden und welches Trennzeichen verwendet wurde. Haben einige Zeilen mehr oder weniger Felder als die Kopfzeile, nennt ein Hinweis die betroffenen Zeilen. Das deutet meist auf ein verirrtes Trennzeichen oder ein nicht geschlossenes Anführungszeichen in der Quelle hin.

Tipps

  • Sie brauchen den umgekehrten Weg? Nutzen Sie JSON in CSV.
  • Um das Ergebnis zu prüfen oder neu zu formatieren, fügen Sie es in JSON formatieren und validieren ein.
  • Entfernen Sie wiederholte Zeilen vorher mit Doppelte Zeilen entfernen.
