Seitenzahlen einfügen, ohne das PDF hochzuladen

Seitenzahlen sind nur kleine Textstücke, die über jede Seite gezeichnet werden. Ihr Browser kann das direkt: Er öffnet das PDF mit pdf-lib, fügt jeder gewählten Seite eine Zeile Text in Helvetica hinzu und schreibt eine neue Datei. Der ursprüngliche Seiteninhalt bleibt unangetastet.

Jede Seite kann ihre eigene Größe, CropBox und Drehung haben, deshalb wird die Position für jede Seite einzeln berechnet. Die Ränder werden ab der Kante des sichtbaren Bereichs gemessen, und auf einer quer gespeicherten Seite wird die Zahl mitgedreht, sodass sie dort aufrecht steht, wo Sie sie erwarten.

Tipps

  • Sie möchten zuerst mehrere Dateien zusammenführen? Nutzen Sie PDF zusammenfügen und nummerieren Sie dann das Ergebnis, damit die Zahlen durchlaufen.
  • Sie brauchen eher eine Markierung quer über die Seite als eine Zahl? Probieren Sie PDF-Wasserzeichen.
  • Seiten in falscher Reihenfolge? Korrigieren Sie das vor dem Nummerieren mit PDF-Seiten sortieren.
