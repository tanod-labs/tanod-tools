JSON formatieren und prüfen


JSON ist ein kleines, strenges Textformat für Daten: Objekte in geschweiften Klammern, Arrays in eckigen Klammern und Werte, die Zeichenketten, Zahlen, true, false oder null sind. Maschinen ist Leerraum egal, Menschen nicht. Wer JSON formatieren will, braucht deshalb einen Formatter, der Einrückungen und Zeilenumbrüche einfügt, damit verschachtelte Daten lesbar werden; ein Minifier entfernt sie wieder, um Platz zu sparen.


Dieses Tool liest Ihren Text mit einem eigenen Parser und kann deshalb genau auf das Zeichen zeigen, an dem etwas schiefgeht. Die häufigsten Fehler sind ein Komma nach dem letzten Element, einfache statt doppelter Anführungszeichen, ein Schlüssel ohne Anführungszeichen, ein Kommentar oder eine fehlende Klammer am Ende. Der Fehler zeigt Zeile und Spalte, eine Kopie dieser Zeile und ein Caret unter der Position.


Das Formatieren ändert nur Leerraum. Zahlen und Escape-Sequenzen in Zeichenketten bleiben wie geschrieben, sodass eine lange ID wie 12345678901234567890 nicht gerundet wird, wie es beim Einlesen der Daten als JavaScript-Zahlen geschähe.
