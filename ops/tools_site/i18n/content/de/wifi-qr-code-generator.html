Was ein WLAN-QR-Code enthält


Ein WLAN-QR-Code ist gewöhnlicher Text in einem festen Format: WIFI:T:WPA;S:name;P:password;;. Die Buchstaben vor jedem Doppelpunkt bezeichnen das Feld: T für die Verschlüsselung, S für den Netzwerknamen, P für das Passwort und H für ein verstecktes Netzwerk. Smartphone-Kameras erkennen das Präfix WIFI: und bieten an, sich zu verbinden, sodass die Person, die scannt, das Passwort nie eintippen muss. So können Sie Ihr WLAN teilen, ohne das Passwort zu diktieren.


Weil die Felder an Semikolons und Doppelpunkten getrennt werden, müssen diese Zeichen sowie Backslash, Komma und doppeltes Anführungszeichen mit einem Backslash maskiert werden, wenn sie in einem Namen oder Passwort vorkommen. Ein Fehler dabei ist der übliche Grund, warum ein Code mit einem einfachen Passwort funktioniert und mit einem komplizierten nicht. Die Anzeige oben zeigt den fertigen Text, damit Sie sehen, was maskiert wurde. Bei einem offenen Netzwerk entfällt das Passwortfeld ganz.


Die druckbare Karte setzt den Code auf einen schlichten weißen Hintergrund mit dem Netzwerknamen darunter, in derselben Schrift Archivo wie der Rest dieser Website. Sie ist ein PNG mit festen 900 mal 1100 Pixeln, das bei 280 dpi scharf in etwa 8 mal 10 cm gedruckt wird, und größer, wenn Sie etwas weichere Textkanten in Kauf nehmen.
