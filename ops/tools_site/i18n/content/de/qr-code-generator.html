Wie ein QR-Code Ihren Text speichert

Wenn Sie einen QR-Code erstellen, entsteht ein quadratisches Raster aus dunklen und hellen Quadraten, den sogenannten Modulen. Ihr Text wird in Bytes umgewandelt (dieses Tool verwendet UTF-8, Umlaute, Akzente und Emoji bleiben also erhalten), in Blöcke aufgeteilt und mit zusätzlichen Fehlerkorrekturdaten ergänzt, die mit Reed-Solomon-Codes berechnet werden. Diese Zusatzdaten sorgen dafür, dass ein Scanner auch einen verschmierten, zerkratzten oder teilweise verdeckten Code lesen kann.

Die Rastergröße wird automatisch gewählt: Mehr Text oder eine höhere Fehlerkorrekturstufe bedeutet ein größeres Raster mit kleineren Quadraten. Sie drucken klein? Halten Sie den Text kurz und lassen Sie die Ruhezone stehen, denn Scanner nutzen diesen leeren Rand, um den Code zu finden.

WLAN-Codes verwenden ein standardisiertes Textformat, das Smartphones erkennen und zum Verbinden anbieten. E-Mail- und Telefoncodes verwenden mailto:- und tel:-Links. Alles wird auf dieser Seite erzeugt, und nichts wird irgendwohin gesendet.

Tipps

  • Scannen Sie einen gedruckten Code immer mit einem echten Smartphone, bevor Sie ihn verteilen.
  • Sie wählen Markenfarben? Prüfen Sie den Kontrast mit dem Farbkonverter und Kontrastprüfer; dunkle Module auf hellem Hintergrund lassen sich am besten scannen.
  • Sie brauchen ein zufälliges Passwort für das WLAN? Nutzen Sie den Passwort-Generator.
  • Sie bauen einen Datenblock zum Kodieren? Siehe Base64 kodieren und dekodieren.
