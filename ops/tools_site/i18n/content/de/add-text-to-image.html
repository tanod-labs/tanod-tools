Text auf ein Foto schreiben, der lesbar bleibt

Text auf einem Bild muss sich vom Hintergrund abheben, und Fotos bieten selten eine ruhige Fläche. Drei Werkzeuge helfen dabei. Eine dunkle Kontur hält weiße Buchstaben auch über hellen Bereichen lesbar. Ein weicher Schatten hebt den Text leicht ab, ohne harte Kante. Eine halbtransparente Box hinter den Zeilen sorgt für den gleichmäßigsten Kontrast, verdeckt dafür aber einen Teil des Bildes.

Weil die Größe in Prozent der Bildbreite angegeben wird, entspricht das Layout in der Vorschau dem Layout in der Datei, egal wie groß das Original ist. Innenabstand, Konturstärke und Schatten skalieren ebenfalls mit dem Text, sodass in voller Größe nichts wuchtiger wirkt als auf dem Bildschirm.

Setzen Sie Bildunterschriften ins untere Drittel, wo man sie erwartet, halten Sie die Zeilen kurz und lassen Sie Abstand zum Rand; das Raster mit neun Positionen hält automatisch einen kleinen Randabstand ein. Zentrierter Text passt zu Titeln, linksbündiger Text zu mehrzeiligen Bildunterschriften.

Tipps

  • Ist das Bild zu unruhig für Text, passen Sie zuerst Helligkeit oder Kontrast mit Bildfilter an.
  • Rahmen Sie das fertige Bild mit Bild mit Rahmen versehen ein.
  • Sie brauchen den Text stattdessen auf einem PDF? PDF-Wasserzeichen stempelt Text auf jede Seite.
