Farbstopps

    Vorlagen

    Einen CSS-Farbverlauf verstehen

    Ein CSS-Farbverlauf (Gradient) ist ein Bild, das der Browser selbst zeichnet; er skaliert daher auf jede Größe und kostet keinen Download. Ein linearer Verlauf mischt Farben entlang einer Linie, die durch einen Winkel festgelegt ist. Ein radialer Verlauf mischt von einem Mittelpunkt aus nach außen, als Kreis oder Ellipse. Ein konischer Verlauf lässt die Farben wie einen Uhrzeiger um einen Mittelpunkt kreisen und ist damit die naheliegende Wahl für Tortendiagramme und Farbkreise.

    Jeder Farbstopp ist eine Farbe plus eine Position auf der Verlaufslinie, angegeben in Prozent. Zwischen zwei Farbstopps mischt der Browser weich. Teilen sich zwei Farbstopps eine Position, hat der Übergang keine Breite, und es entsteht eine scharfe Kante. Liegt ein Farbstopp vor dem vorherigen, behandeln Browser ihn so, als läge er an der Position des vorherigen; deshalb können Sie die Farbstopps in diesem Tool umordnen und sortieren.

    Die Regel wird als background: geschrieben und funktioniert daher bei jedem Element. Verläufe werden auf den Hintergrund gezeichnet; Text darauf braucht also dieselbe Sorgfalt beim Kontrast wie Text auf einer Volltonfarbe: Prüfen Sie den hellsten und den dunkelsten Teil des Verlaufs getrennt.
