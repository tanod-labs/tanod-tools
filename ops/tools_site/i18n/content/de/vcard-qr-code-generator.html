Was in einem Kontakt-QR-Code steckt


Ein vCard-QR-Code ist eine vCard, als Text ausgeschrieben und als QR-Code gezeichnet: eine digitale Visitenkarte zum Scannen. Die Karte beginnt mit BEGIN:VCARD und endet mit END:VCARD, und jede Zeile ist eine Eigenschaft: N enthält den strukturierten Namen, FN den Namen, wie er angezeigt werden soll, TEL eine Telefonnummer mit einem Typ wie CELL, und so weiter. Beim Scannen erhält das Smartphone denselben Text, den eine .vcf-Datei enthalten würde, und bietet an, den Kontakt zu speichern.


Der Standard verlangt, dass Zeilen mit Wagenrücklauf und Zeilenvorschub enden, daher verwenden Datei und Code diese. Werte werden maskiert: Vor einen Backslash, ein Komma oder ein Semikolon kommt ein Backslash, und ein Zeilenumbruch in der Notiz wird zu \n. Name und Adresse sind Listen von Teilen, getrennt durch Semikolons, sodass ein in einen Teil eingegebenes Semikolon nicht in den nächsten überlaufen kann.


QR-Codes wachsen in Stufen, die Versionen heißen, von 1 (21 mal 21 Module) bis 40 (177 mal 177). Jedes zusätzliche Zeichen kann einen Code in die nächste Version schieben. Eine Karte mit nur Name, Telefon und E-Mail ergibt eine bescheidene Version und lässt sich auch klein gedruckt leicht scannen. Eine Straßenadresse und eine lange Notiz können die Breite verdoppeln. Ist der Code dicht, lassen Sie verzichtbare Felder weg oder wählen Sie eine niedrigere Fehlerkorrekturstufe.
