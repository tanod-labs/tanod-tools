Wie eine Unterschrift auf eine PDF-Seite kommt

Eine PDF-Seite ist ein festes Layout; eine Seite zu unterschreiben heißt daher, ihr etwas hinzuzufügen, nicht, in sie hineinzuschreiben. Dieses Tool verwandelt Ihre Unterschrift, auf Wunsch samt Datumszeile, in ein kleines Bild mit transparentem Hintergrund und zeichnet dieses Bild auf die gewählte Seite. Ihr Browser zeigt Ihnen die Seite mit pdf.js an und schreibt die neue Kopie mit pdf-lib, sodass die Seite, die Sie sehen, genau die ist, die unterschrieben wird.

Position und Größe werden als Bruchteile der Seite gespeichert, nicht als feste Maße. Deshalb passen dieselben Reglerwerte zu Seiten unterschiedlicher Größe, wenn Sie alle Seiten unterschreiben, und deshalb erhält auch eine seitlich gedreht gespeicherte Seite eine aufrecht stehende Unterschrift. Ihre Originaldatei wird nie verändert; Sie laden eine separate, unterschriebene Kopie herunter.

Sie erhalten das Bild einer Unterschrift; so unterschreiben die meisten Menschen Formulare, Briefe und Verträge ja auch: von Hand und anschließend eingescannt. Es ist keine kryptografische digitale Signatur. Eine solche nutzt ein auf Sie ausgestelltes Zertifikat, schützt die Datei nach dem Unterschreiben vor Änderungen und erfordert einen eigens dafür gebauten Dienst. Welche Art ein Dokument braucht, hängt vom Dokument ab und davon, wer die Unterschrift verlangt.

Tipps

  • Zeichnen Sie langsam und nutzen Sie das ganze Feld: Die Unterschrift wird auf die gezeichneten Striche zugeschnitten, daher wird sie bei gleicher Größe auf der Seite umso schärfer, je größer Sie sie zeichnen.
  • Sichern Sie die unterschriebene Kopie mit einem Passwort über PDF mit Passwort schützen oder stempeln Sie jede Seite mit PDF-Wasserzeichen.
  • Müssen Sie zuerst eine unterschriebene Seite an ein anderes Dokument anhängen? PDF zusammenfügen verbindet Dateien in der Reihenfolge, die Sie festlegen.
