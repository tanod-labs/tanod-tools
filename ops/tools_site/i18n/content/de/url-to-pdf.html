So wird hier aus einer Webseite ein PDF

Unser Server startet eine frische, abgeschottete Instanz des Chromium-Browsers, öffnet die angegebene Adresse, wartet, bis die Seite fertig geladen ist, und druckt sie mit Ihrem Papierformat und Ihrer Ausrichtung als PDF, genau wie es der Druckdialog Ihres Browsers tun würde. Der Browser kann nur diese eine Website erreichen, nie private Netzwerke, und wird nach jedem Auftrag verworfen.

Tipps

  • Leserfreundliche Seiten, etwa Artikel mit Druckansicht, ergeben die saubersten PDFs.
  • Sie möchten mehrere Seiten in einer Datei? Wandeln Sie jede einzeln um und fügen Sie sie dann mit PDF zusammenfügen zusammen (in Ihrem Browser).
  • Sie brauchen den Text statt eines PDFs? HTML in Markdown wandelt eingefügtes HTML auf Ihrem Gerät um.
