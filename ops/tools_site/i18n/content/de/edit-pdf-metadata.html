Was PDF-Metadaten sind und warum Sie sie ändern sollten

Jedes PDF kann einige beschreibende Felder enthalten: einen Titel, einen Autor, einen Betreff, Stichwörter, das Programm, mit dem es erstellt wurde, und die Daten der Erstellung und der letzten Änderung. Sie stehen im Dokumentinformations-Wörterbuch, und viele Programme schreiben zusätzlich eine zweite Kopie als XMP-Paket, einen an die Datei angehängten XML-Block.

Diese Felder erscheinen in den Dateieigenschaften, in Suchergebnissen und in Browser-Tabs. Ein falscher Titel oder ein vergessener Autorenname kann daher unangenehm sein, wenn ein Dokument Ihre Hände verlässt. Dieses Tool liest sie in Ihrem Browser, lässt Sie sie korrigieren oder leert sie. Der Seiteninhalt wird nie verändert.

Tipps

  • Sie möchten stattdessen Metadaten aus Fotos entfernen? Nutzen Sie EXIF-Daten entfernen.
  • Sie kombinieren Dateien? PDF zusammenfügen erstellt ein neues Dokument, setzen Sie den Titel also anschließend hier.
