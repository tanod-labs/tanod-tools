Wie aus Text Einsen und Nullen werden

Computer speichern Text als Zahlen. Eine Kodierung legt fest, welche Zahl jedes Zeichen bekommt; dieses Tool verwendet UTF-8, das fast jede Webseite, E-Mail und moderne Datei nutzt. Wenn Sie Text in Binärcode umwandeln, speichert UTF-8 die ersten 128 Zeichen (das englische Alphabet, Ziffern und gängige Satzzeichen) in je einem Byte, mit denselben Werten wie der ältere ASCII-Code. Andere Zeichen belegen zwei bis vier Bytes: é ist 11000011 10101001, und das Emoji 😀 besteht aus vier Bytes.

Ein Byte hat acht Bit, daher wird jedes Byte als acht Binärziffern angezeigt, mit führenden Nullen, damit jede Gruppe gleich breit ist. So lässt sich die Ausgabe leicht zurücklesen: Jede Achtergruppe ist ein Byte.

Zum Dekodieren liest das Tool jede Gruppe als Byte und dann die Bytes als UTF-8-Text. Bilden die Bytes kein gültiges UTF-8, zeigt es an, wo das Problem beginnt, statt verstümmelte Zeichen auszugeben.

Tipps

  • Für eine kürzere, standardisierte Art, Bytes als Text zu transportieren, nutzen Sie Base64 kodieren und dekodieren.
  • Sie wollen eine einzelne Zahl zwischen Binär, Dezimal und Hex umrechnen? Nutzen Sie den Zahlensystem-Umrechner.
  • Lieber Punkte und Striche? Probieren Sie den Morsecode-Übersetzer.
