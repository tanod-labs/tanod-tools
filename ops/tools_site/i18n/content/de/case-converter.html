Groß- und Kleinschreibung umwandeln, ohne neu zu tippen

Wählen Sie eine Schreibweise, und der Text im Feld wird direkt umgeschrieben. So können Sie Umwandlungen hintereinander ausführen: einen in Großbuchstaben „geschrienen“ Absatz erst kleinschreiben und dann in „Satzanfang groß“ umwandeln. Rückgängig hält die letzten zwanzig Versionen im Speicher, solange die Seite geöffnet ist.

Die Programmier-Schreibweisen (camelCase, PascalCase, snake_case, kebab-case, CONSTANT_CASE) behandeln jede Zeile als eigenen Namen, sodass aus einer Liste von Wortgruppen eine Liste von Bezeichnern wird. Großbuchstaben innerhalb von Wörtern gelten als Wortgrenzen; so können Sie einen Namen von einer Schreibweise in eine andere übertragen.

Tipps

  • Zählen Sie Ihren Text mit Wörter zählen.
  • Ersetzen Sie viele Wörter auf einmal mit Suchen und Ersetzen.
  • Sehen Sie mit Texte vergleichen, was die Umwandlung geändert hat.
  • Sie machen aus einem Titel eine Webadresse? Der Slug-Generator wandelt auch Akzente um und entfernt Satzzeichen.
