Webseiten in Markdown verwandeln

Wer Inhalte aus einer Webseite, einem alten CMS oder einem Rich-Text-Editor in eine README, eine statische Website oder eine Notiz-App übernehmen will, muss meist HTML in Markdown umwandeln. Der Konverter geht die HTML-Struktur durch und schreibt jedes Element in seiner Markdown-Form: Überschriften werden zu #-Zeilen, Listen zu Strichen, Links zu [text](url), und <pre><code> wird zu einem Codeblock.

Markdown beschreibt nur Struktur, deshalb bleibt die Gestaltung zurück. Inline-Styles, Klassen, Farben und Layout-Container verschwinden, während Wörter, Hervorhebungen, Links, Bilder und Listen bleiben. Tabellen werden als Tabellen in GitHub Flavored Markdown geschrieben, wenn sie einfach genug für dieses Format sind.

Verschiedene Projekte bevorzugen verschiedene Markdown-Gewohnheiten, deshalb lassen sich die Stile für Überschriften, Listenzeichen, Codeblöcke und Kursivschrift ändern. Die meisten Renderer akzeptieren jede Variante.

Tipps

  • Prüfen Sie, wie das Markdown gerendert wird, mit Markdown in HTML, das eine Vorschau hat.
  • Bereinigen Sie übrige Abstände oder Formulierungen mit Suchen und Ersetzen.
  • Zählen Sie die Wörter im Ergebnis mit Wörter zählen.
