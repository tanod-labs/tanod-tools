Vom Bild zum Text

Für einen Computer ist das Foto einer Seite nur eine Ansammlung farbiger Punkte. OCR, die optische Zeichenerkennung, findet in diesen Punkten die Formen von Buchstaben und wandelt sie zurück in Text, den Sie durchsuchen, bearbeiten und einfügen können. So wird aus einem Bild Text: Dieses Tool sendet eine vorbereitete Kopie Ihres Bildes an unseren Server, wo die Engine Tesseract sie liest, und zeigt Ihnen die Wörter innerhalb von Sekunden an.

Tipps für bessere Ergebnisse

  • Halten Sie das Smartphone gerade über die Seite, bei gutem Licht, und füllen Sie den Bildausschnitt mit dem Text.
  • Schneiden Sie alles, was kein Text ist, mit Bild zuschneiden weg und drehen Sie seitliche Fotos mit Bild drehen. Beide laufen in Ihrem Browser.
  • Sie haben ein ganzes gescanntes Dokument? PDF-OCR macht das PDF selbst durchsuchbar.
