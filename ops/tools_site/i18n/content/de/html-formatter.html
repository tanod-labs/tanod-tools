HTML sicher einrücken


Browser fassen den meisten Leerraum in HTML zusammen, sodass eine Seite in einer Zeile oder über tausend Zeilen verteilt geschrieben sein kann und gleich dargestellt wird. Vorlagen, CMS-Ausgaben und minifizierte Bundles erzeugen oft Markup, das niemand lesen kann. Wenn Sie HTML formatieren, stehen Blockelemente in eigenen Zeilen und Kindelemente werden unter ihren Eltern eingerückt; so fallen falsch geschlossene oder falsch platzierte Tags sofort auf.


An den Details scheitern Formatierer. Leere Elemente wie <br>, <img> und <input> haben nie ein schließendes Tag und dürfen die Einrückung daher nicht erhöhen. Leerraum in <pre> und <textarea> wird so angezeigt, wie er eingegeben wurde, und darf nicht angetastet werden. Und Inline-Elemente teilen sich die Zeile mit den Wörtern um sie herum, weil ein Zeilenumbruch dort ein sichtbares Leerzeichen erzeugen würde.


In die Seite eingebettete Skripte und Stylesheets sind eine eigene Sprache. Der Formatierer kann sie mit der Einrückung der Seite gestalten oder unverändert lassen, wenn Sie einen Diff klein halten möchten oder der Code bewusst minifiziert ist.
