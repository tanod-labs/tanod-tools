Wie aus Markdown HTML wird

Markdown ist eine Art, formatierten Text mit einfachen Zeichen zu schreiben: Ein # beginnt eine Überschrift, **zwei Sternchen** machen Text fett, eine Zeile mit einem Strich am Anfang ist ein Listeneintrag. So sind README-Dateien geschrieben, viele Notiz-Apps und die meisten Entwicklerforen. Browser, E-Mail-Vorlagen und Content-Systeme erwarten aber HTML, also muss das Markdown irgendwann in HTML umgewandelt werden.

Dieser Konverter folgt CommonMark mit den Erweiterungen von GitHub Flavored Markdown, sodass Tabellen, Aufgabenlisten und Durchstreichen so funktionieren wie auf GitHub. Das erzeugte HTML durchläuft anschließend einen Sanitizer, der alles entfernt, was beim Anzeigen des HTML Code ausführen könnte, und normale Formatierung unangetastet lässt.

Der Vorschau-Tab zeigt dasselbe HTML gerendert auf der Seite. Links öffnen sich in einem neuen Tab, und Bilder, die anderswo gehostet sind, werden als Platzhalter angezeigt statt abgerufen, sodass nichts, was Sie schreiben, während der Arbeit an eine andere Website gesendet wird.

Tipps

  • Sie haben HTML und möchten stattdessen Markdown? Nutzen Sie HTML in Markdown.
  • Prüfen Sie die Länge eines Beitrags mit Wörter zählen.
  • Vergleichen Sie zwei Entwürfe mit Texte vergleichen.
