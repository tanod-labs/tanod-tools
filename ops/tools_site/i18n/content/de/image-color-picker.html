      Farben direkt aus den Pixeln auslesen

      Eine Markenfarbe aus einem Logo übernehmen, das exakte Blau in einem Screenshot finden oder aus einem Foto eine Palette bauen: Es läuft immer darauf hinaus, die Rot-, Grün- und Blauwerte auszulesen, die für ein Pixel gespeichert sind. Dieses Tool dekodiert das Bild in Ihrem Browser und liest diese Werte aus dem Bild in voller Auflösung. Der Code, den Sie kopieren, ist also die Farbe, die tatsächlich in der Datei steht.

      Einzelne Pixel können bei Fotos täuschen, weil Bildrauschen und Komprimierung benachbarte Pixel variieren lassen. Zielen Sie mit der Lupe auf die Mitte einer gleichmäßigen Fläche oder nehmen Sie die Palette, die ganze Gruppen ähnlicher Pixel zu einer Handvoll repräsentativer Farben mittelt.

      Tipps

      • Wandeln Sie eine ausgewählte Farbe in CMYK um oder prüfen Sie ihren Kontrast zu Text mit dem Farbkonverter und Kontrastprüfer.
      • Sie möchten eine Farbe aus einem kleinen Teil eines großen Bildes auslesen? Schneiden Sie das Bild zuerst zu, damit der Bereich den Bildschirm füllt.
