PDF-Seiten im Browser in Bilder umwandeln

Eine PDF-Seite ist eine Liste von Zeichenanweisungen, kein Bild. Um ein Bild zu erhalten, muss die Seite in einer bestimmten Größe gezeichnet werden. Ihr Browser macht das mit pdf.js auf einem Canvas in der gewählten Auflösung, Seite für Seite, und speichert den Canvas dann als JPG- oder PNG-Datei.

Die Auflösung wird in Punkten pro Zoll (dpi) gemessen. Eine PDF-Seite ist in Punkten definiert, 72 pro Zoll, daher zeichnet 150 dpi jede Seite gut doppelt so breit wie ihre Nenngröße. Wählen Sie JPG für Fotos und kleinere Dateien oder PNG, wenn Sie scharfen Text und klare Kanten ohne Kompressionsartefakte möchten.

Tipps

  • Sie möchten in die andere Richtung umwandeln? JPG in PDF erstellt ein PDF aus Bildern.
  • Sie brauchen nur ein paar Seiten als PDF statt als Bilder? Nutzen Sie PDF-Seiten extrahieren.
  • Verkleinern oder komprimieren Sie die Bilder anschließend mit Bild komprimieren.
