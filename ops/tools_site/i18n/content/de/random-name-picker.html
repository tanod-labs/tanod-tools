Verlauf

    Fair auslosen, und warum das Rad nur Schau ist

    Wer Namen auslosen will, braucht eine faire Ziehung, bei der jeder Eintrag dieselbe Chance hat. Die übliche Falle: eine Animation drehen lassen, ablesen, wo sie stehen bleibt, und das zum Ergebnis erklären. Dann können die Physik eines gezeichneten Rads, ein langsamer Frame oder ein Rundungsfehler einzelne Segmente bevorzugen. Hier ist die Reihenfolge umgekehrt. Der Gewinnereintrag wird zuerst bestimmt, indem ein zufälliger Index per Verwerfungsmethode gezogen wird, die den ungleichmäßigen Rest verwirft, den ein einfaches Modulo hinterlassen würde, und das Rad wird dann so gedreht, dass es auf diesem Segment endet.

    Mehrere Gewinner werden auf dieselbe Weise ohne Zurücklegen gezogen. Die Seite führt ein teilweises Fisher-Yates-Mischen über die Positionen Ihrer Liste aus und nimmt die ersten, sodass eine Position in einer Ziehung nie zweimal gewählt werden kann. Für Teams wird vollständig gemischt und dann reihum Name für Name auf die Teams verteilt. Das garantiert, dass sich die Größen um höchstens eins unterscheiden, während zufällig bleibt, wer zusammen landet.

    Bei allem, wo etwas auf dem Spiel steht, etwa einem Gewinnspiel, lassen Sie die Liste während der Ziehung sichtbar und sagen Sie, wie gelost wurde. Den Verlauf laut vorzulesen oder hinterher zu veröffentlichen ist ein besserer Nachweis als ein Screenshot eines Glücksrads.

    Tipps

    • Bereinigen Sie eine eingefügte Liste zuerst: Doppelte Zeilen entfernen, wenn jede Person nur einen Eintrag haben soll.
    • Sie brauchen Zahlen statt Namen, etwa Los 1 bis 500? Nutzen Sie den Zufallszahlen-Generator.
    • Sie leiten eine Quizrunde oder einen Vortrag? Geben Sie jeder Runde ein Zeitlimit mit dem Countdown-Timer.
