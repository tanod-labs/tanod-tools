Hintergrund

Vektorgrafik in Pixel umwandeln

Eine SVG-Datei beschreibt Formen mit Koordinaten und lässt sich daher in jeder Größe ohne Schärfeverlust zeichnen. Viele Stellen verlangen trotzdem eine Pixelgrafik: App-Stores, Social-Media-Profile, Präsentationen, E-Mail-Signaturen und ältere Designprogramme. Wenn Sie SVG in PNG umwandeln, wird die Zeichnung auf eine Pixelgröße festgelegt. Wählen Sie also die größte Größe, die Sie brauchen werden: Ein PNG lässt sich später immer verkleinern, beim Vergrößern wird es unscharf.

Der SVG-Renderer Ihres Browsers zeichnet das Bild in der Ausgabegröße auf ein Canvas, und das Canvas wird mit voller Transparenz als PNG gespeichert. Die SVG-Datei wird strikt als Bild behandelt: Skripte darin werden nie ausgeführt, und nichts, worauf sie verlinkt, wird heruntergeladen.

Tipps

  • Für Bildschirme mit hoher Pixeldichte exportieren Sie in der 2- oder 3-fachen Anzeigegröße.
  • Sie erstellen ein Website-Icon? Der Favicon-Generator erzeugt alle Größen aus einem Bild.
  • Sie brauchen stattdessen JPG oder WebP? Wandeln Sie das PNG mit Bild konvertieren um.
