Come funziona la compressione dei PDF

La maggior parte del peso di un PDF grande sono le immagini: pagine scansionate, foto, screenshot. Il nostro server apre il file, trova ogni immagine di tipo fotografico e controlla quanto è nitida alla dimensione con cui è stampata sulla pagina. Tutto ciò che è più nitido del limite del livello viene ridotto, poi salvato di nuovo come JPEG. Un'immagine viene sostituita solo quando questo fa risparmiare almeno il 10 percento, e la struttura del file viene riscritta con ogni flusso compresso il più possibile.

Il risultato non è mai più grande dell'originale. Quando non si può risparmiare nulla, te lo diciamo e tieni il file che hai.

Suggerimenti

  • Per le email, prova prima Consigliato; passa a Forte solo se il file è ancora troppo grande.
  • Ti servono solo alcune pagine? Estraile prima con Estrai pagine da PDF; meno pagine significano un file più piccolo. Quello strumento funziona nel tuo browser.
  • Devi ridurre foto anziché un PDF? Comprimi immagine funziona sul tuo dispositivo, senza caricamenti.
