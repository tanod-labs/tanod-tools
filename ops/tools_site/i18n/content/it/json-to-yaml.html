Trasformare il JSON in YAML leggibile


YAML è in gran parte un modo più comodo per le persone di scrivere gli stessi dati del JSON. Parentesi graffe e virgolette lasciano il posto a rientri e parole semplici, ed è per questo che la configurazione di Kubernetes, Compose e dei sistemi CI è di solito scritta in YAML. Partendo da un JSON, come una risposta API o un manifest generato, la conversione è meccanica, ma un dettaglio richiede attenzione: YAML decide il tipo di un valore da come appare.


In YAML un semplice true è un booleano, null è null e 1.0 è un numero. Una stringa JSON che per caso somiglia a uno di questi, come "null", "1.0" o "0x1F", deve essere tra virgolette nello YAML o cambierà tipo alla lettura. Il convertitore mette tra virgolette proprio quelle, più le stringhe vuote e il testo che inizia con simboli che in YAML hanno un significato, e poi controlla l'output rileggendolo.


Il testo su più righe diventa un blocco letterale, molto più facile da leggere di una lunga stringa con escape \n. Oggetti e array vuoti vengono scritti come {} e []. Poiché JSON non ha commenti, lo YAML parte senza nessuno; puoi aggiungere i tuoi in seguito.
