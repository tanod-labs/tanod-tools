Dalle righe CSV al JSON

Il CSV è il minimo comune denominatore dei dati: ogni foglio di calcolo e database può esportarlo. Il JSON è ciò che si aspettano la maggior parte delle API web, degli script e dei file di configurazione. Questo strumento legge il CSV con un parser che segue lo standard CSV, quindi una virgola dentro un indirizzo tra virgolette o un a capo dentro un commento tra virgolette restano dentro la loro cella invece di spezzare la riga.

Con una riga di intestazione, ogni riga diventa un oggetto le cui chiavi sono i nomi delle colonne, nell'ordine delle colonne. Senza, ogni riga diventa un array. I valori restano testo a meno che tu non chieda di convertire numeri e true/false, perché un file CSV non ha tipi e un'ipotesi automatica può trasformare in silenzio un CAP come 02134 nel numero 2134.

La riga sotto le opzioni ti dice quante righe e colonne sono state lette e quale delimitatore è stato usato. Se alcune righe hanno più o meno campi dell'intestazione, una nota indica quali, il che di solito segnala un delimitatore fuori posto o una virgoletta non chiusa nella sorgente.
