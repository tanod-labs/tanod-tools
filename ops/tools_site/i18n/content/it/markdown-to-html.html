Come il Markdown diventa HTML

Markdown è un modo di scrivere testo formattato con caratteri semplici: un # inizia un titolo, **due asterischi** fanno il grassetto, una riga che inizia con un trattino è un elemento di elenco. È ciò che usano i file README, molte app di note e la maggior parte dei forum per sviluppatori. Browser, template di email e sistemi di gestione dei contenuti vogliono HTML, quindi a un certo punto il Markdown va tradotto.

Questo convertitore segue CommonMark con le aggiunte di GitHub Flavored Markdown, quindi tabelle, elenchi di attività e testo barrato funzionano come su GitHub. L'HTML prodotto passa poi per un sanitizzatore, che rimuove tutto ciò che potrebbe eseguire codice quando l'HTML viene mostrato, lasciando intatta la normale formattazione.

La scheda Anteprima mostra lo stesso HTML reso nella pagina. I link si aprono in una nuova scheda e le immagini ospitate altrove sono mostrate come segnaposto anziché scaricate, quindi nulla di ciò che scrivi viene inviato ad altri siti mentre lavori.
