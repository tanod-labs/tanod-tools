Come si scrive una tabella Markdown

Una tabella Markdown di GitHub è testo semplice: una riga di intestazione, una riga di trattini che imposta l'allineamento e una riga per ogni riga di dati, con le celle separate da barre verticali. È il formato che GitHub mostra in README, issue e pull request, e anche molti altri strumenti, tra cui siti di documentazione e app per appunti, lo capiscono.

La griglia contiene le celle; la prima riga è l'intestazione. Ogni colonna ha un allineamento. Sinistra si scrive :---, centro :---:, destra ---: e nessun allineamento è composto da semplici trattini. Il testo delle celle viene escapato dove serve: una barra verticale diventa \| e un a capo diventa il tag HTML <br>. Poi lo strumento allinea le colonne con degli spazi in modo che il sorgente sembri una tabella, usando la larghezza di ogni carattere e non il numero di byte, così anche le lettere accentate restano allineate.

Incollare da un foglio di calcolo è il modo più veloce per iniziare. I fogli di calcolo mettono le celle copiate negli appunti come testo separato da tabulazioni, con una riga per ogni riga della tabella, e la griglia lo legge direttamente. I file CSV e TSV funzionano allo stesso modo tramite la casella di incolla, con gestione dei campi tra virgolette e degli a capo tra virgolette. Se incolli una tabella Markdown esistente, celle e allineamenti vengono riletti nella griglia così puoi modificarli.
