Incorporare le immagini come testo

HTML, CSS, JSON, Markdown e corpi delle email sono testo, ma le immagini sono binarie. Base64 fa da ponte scrivendo i byte dell'immagine con 64 caratteri sicuri, così l'intera immagine può stare dentro una regola di un foglio di stile, un tag img o un file di configurazione senza un download separato.

Questo strumento legge il file nel browser, controlla il suo tipo reale dai primi byte e costruisce intorno al testo codificato il frammento che scegli. L'immagine in sé non cambia: decodificando il Base64 si ottiene di nuovo il file originale identico.

Suggerimenti

  • Riduci prima l'immagine con Comprimi immagine o Ridimensiona immagine: ogni byte risparmiato ne fa risparmiare un terzo in più in Base64.
  • Per le icone semplici, un SVG è spesso più piccolo di qualsiasi PNG, anche in Base64.
  • Per decodificare il Base64 in un file, o per codificare qualsiasi altro file, usa Codifica e decodifica Base64.
