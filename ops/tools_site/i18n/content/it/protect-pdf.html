Cosa fa la protezione con password

Un PDF protetto è cifrato: le sue pagine sono rimescolate con una chiave derivata dalla tua password, quindi un lettore non mostra nulla finché la password non viene digitata. Il nostro server cifra il file con AES-256 usando la libreria open source qpdf e ti rimanda la copia bloccata.

Consigli

  • Invia la password separatamente dal file, per esempio con un messaggio di testo invece che nella stessa email.
  • Vuoi anche un segno visibile di "Riservato"? Aggiungilo prima con Aggiungi filigrana al PDF; funziona nel tuo browser.
