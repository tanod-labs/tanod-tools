Client Hints del tuo browser

Cosa ti dice uno user agent, e cosa nasconde

Lo user agent è nato come modo per un server di vedere quale browser stava facendo la richiesta, per inviare una pagina che funzionasse lì. I browser poi si sono copiati i nomi a vicenda per ottenere le pagine migliori, ed è per questo che oggi una stringa Chrome dice anche Mozilla, AppleWebKit, KHTML, Gecko e Safari. Un parser aggira il problema verificando i pattern in un ordine accurato e scegliendo la corrispondenza più specifica.

La stringa viene anche accorciata di proposito. La User-Agent reduction di Chrome fissa la versione di Windows a NT 10.0, quella di macOS a 10_15_7, il modello Android a K e il numero di build a 0.0.0, in modo che la stringa non sia più una buona impronta digitale. I dettagli non sono scomparsi: una pagina che li richiede tramite i Client Hints ottiene versione della piattaforma, architettura, modello e versione completa del browser, e il browser del visitatore decide se rispondere.

Usa la stringa per decisioni di massima e per i log, non per la fiducia. I crawler e gli strumenti da riga di comando come curl inviano le loro stringhe brevi, e tutto può essere falsificato. Se stai inseguendo un bug di layout, il rilevamento delle funzionalità nella pagina è più affidabile della lettura del nome del browser.

Consigli

  • Un log del server pieno di risposte 403 o 429 a un solo client? Cerca i codici nei Codici di stato HTTP.
  • Gli user agent negli URL o nelle query string sono spesso in percent-encoding; decodificali con Codifica e decodifica URL.
  • Le intestazioni copiate da una richiesta a volte contengono valori Base64; leggili con Codifica e decodifica Base64.
