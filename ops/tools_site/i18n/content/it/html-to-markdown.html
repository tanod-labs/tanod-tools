Trasformare le pagine web in Markdown

Spostare contenuti da una pagina web, da un vecchio CMS o da un editor di testo ricco a un README, a un sito statico o a un'app di note significa di solito convertire HTML in Markdown. Il convertitore percorre la struttura dell'HTML e scrive ogni elemento nella sua forma Markdown: i titoli diventano righe con #, gli elenchi diventano trattini, i link diventano [testo](url) e <pre><code> diventa un blocco di codice.

Markdown descrive solo la struttura, quindi lo stile viene lasciato indietro. Stili inline, classi, colori e contenitori di layout scompaiono, mentre parole, enfasi, link, immagini ed elenchi restano. Le tabelle vengono scritte come tabelle GitHub Flavored Markdown quando sono abbastanza semplici per quel formato.

Progetti diversi preferiscono abitudini Markdown diverse, ed è per questo che si possono cambiare gli stili di titoli, simbolo degli elenchi, blocchi di codice e corsivo. La maggior parte dei renderer li accetta tutti.

Suggerimenti

  • Controlla come viene mostrato il Markdown con Da Markdown a HTML, che ha un'anteprima.
  • Sistema spazi o parole rimasti con Trova e sostituisci.
  • Conta le parole del risultato con Conta parole.
