Biến trang web thành Markdown

Chuyển nội dung từ một trang web, một CMS cũ hay một trình soạn thảo văn bản có định dạng sang README, trang web tĩnh hoặc ứng dụng ghi chú thường đồng nghĩa với việc chuyển HTML sang Markdown. Bộ chuyển đổi duyệt qua cấu trúc HTML và viết mỗi phần tử theo dạng Markdown của nó: tiêu đề thành các dòng #, danh sách thành dấu gạch ngang, liên kết thành [văn bản](url), và <pre><code> thành khối mã.

Markdown chỉ mô tả cấu trúc, nên phần trình bày bị bỏ lại. Style nội tuyến, class, màu sắc và các vùng chứa bố cục biến mất, trong khi chữ, phần nhấn mạnh, liên kết, ảnh và danh sách vẫn còn. Bảng được viết thành bảng GitHub Flavored Markdown khi đủ đơn giản để phù hợp với định dạng đó.

Mỗi dự án ưa chuộng một thói quen Markdown khác nhau, vì vậy kiểu tiêu đề, ký hiệu danh sách, khối mã và chữ nghiêng đều có thể thay đổi. Hầu hết trình hiển thị đều chấp nhận bất kỳ kiểu nào trong số đó.

Mẹo

  • Xem Markdown hiển thị ra sao bằng Markdown sang HTML, có phần xem trước.
  • Dọn khoảng trắng hoặc câu chữ còn sót bằng Tìm và thay thế.
  • Đếm số từ trong kết quả bằng Đếm từ.
