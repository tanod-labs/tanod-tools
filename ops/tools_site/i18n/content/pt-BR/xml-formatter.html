Como formatar XML sem alterá-lo


O XML é exigente com a estrutura e tranquilo com o layout: entre duas tags você pode não pôr nada, um espaço ou cem linhas em branco, e o documento significa a mesma coisa. É por isso que feeds, respostas SOAP e configurações exportadas muitas vezes chegam numa única linha longa. Formatar o XML, indentando cada elemento aninhado, deixa a hierarquia visível e torna possível uma comparação linha por linha.


Muitos formatadores leem o documento e o escrevem de novo, o que pode reescrever silenciosamente coisas que você não pediu para mexer: transformar &#169; num caractere literal, trocar o estilo das aspas ou reordenar atributos. Esta ferramenta lê o texto com um tokenizador e reaproveita cada pedaço exatamente como foi escrito, acrescentando ou removendo só os espaços em branco entre os elementos. Depois, usa o próprio parser XML do navegador para verificar se o resultado está bem formado.


O espaço em branco é o único lugar em que o XML nem sempre é tranquilo. Num parágrafo como <p>one <b>two</b> three</p>, os espaços em volta das tags fazem parte do texto, então movê-los ou removê-los mudaria o que o leitor vê. Por isso, elementos que misturam texto e tags, e elementos marcados com xml:space="preserve", nunca são reorganizados.
