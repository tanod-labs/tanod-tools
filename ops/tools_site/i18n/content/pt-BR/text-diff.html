Como funciona a comparação de textos

Um diff encontra a menor lista de edições que transforma o original no texto alterado. Os trechos iguais ficam como estão; o que sobra aparece como removido do original e adicionado na nova versão. Esta ferramenta para comparar textos usa a biblioteca de código aberto jsdiff, que roda no seu navegador.

Quando um bloco de linhas é substituído, a versão antiga e a nova aparecem nas mesmas linhas na visualização lado a lado, para você ler uma ao lado da outra. No celular, os dois lados ficam empilhados. “Abrir arquivo .txt” preenche a caixa que você usou por último.

Dicas

  • Compare listas depois de limpá-las com Remover linhas duplicadas.
  • Faça a mesma edição em todo lugar antes com Localizar e substituir.
  • Vai comparar duas exportações de dados? Converta-as antes com JSON para CSV para cada registro ficar numa linha.
  • Clique em Inverter para ver a comparação no sentido contrário.
