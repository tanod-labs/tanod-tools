Como tirar páginas de um PDF

Extrair páginas de um PDF copia as páginas escolhidas para um PDF novo e deixa todo o resto para trás. É o jeito mais rápido de mandar a alguém uma seção de um relatório longo, ficar só com as páginas assinadas de um contrato ou descartar a capa e os anexos antes de imprimir.

As miniaturas são desenhadas no seu dispositivo conforme você rola a página, então até documentos longos abrem rápido. Digitar intervalos é mais rápido para seleções grandes; clicar é mais fácil para algumas páginas espalhadas. As duas formas ficam sincronizadas.

Dicas

  • Para cortar um documento em várias partes de uma vez, use Dividir PDF.
  • Para manter a maioria das páginas e descartar algumas, Remover páginas de PDF é mais rápido.
