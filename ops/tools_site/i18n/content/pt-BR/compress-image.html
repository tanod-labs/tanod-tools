    Como funciona a compressão de imagem aqui

    Quase todo o tamanho de um arquivo de imagem são os dados dos pixels. Para comprimir a imagem, JPEG e WebP descartam os detalhes que o olho tem menos chance de notar; a configuração de qualidade decide quanto é descartado. O PNG é sem perdas, então o tamanho dele depende de quão previsíveis são os pixels. Reduzir um PNG a uma paleta de no máximo 256 cores deixa os dados muito mais fáceis de comprimir, ao custo da cor exata.

    Esta ferramenta decodifica cada imagem com o seu navegador, desenha-a em um canvas e a salva de novo, usando os codificadores JPEG e WebP do próprio navegador. Para PNGs com paleta, ela escolhe as cores com o quantizador de código aberto UPNG.js e grava o arquivo PNG por conta própria. Se o resultado não ficar menor que o arquivo enviado à ferramenta, você recebe o seu original de volta.
