Como um QR Code guarda o seu texto

Um QR Code é uma grade quadrada de quadradinhos escuros e claros chamados módulos. Para gerar o QR Code, o seu texto é transformado em bytes (esta ferramenta usa UTF-8, então acentos e emoji são preservados), dividido em blocos e completado com dados extras de correção de erros calculados com códigos Reed-Solomon. São esses dados extras que permitem que um leitor leia um código manchado, riscado ou parcialmente coberto.

O tamanho da grade é escolhido automaticamente: mais texto, ou um nível de correção de erros mais alto, significa uma grade maior com quadrados menores. Vai imprimir pequeno? Mantenha o texto curto e deixe a zona de silêncio no lugar, porque os leitores usam essa borda em branco para encontrar o código.

Os códigos de Wi-Fi usam um formato de texto padrão que os celulares reconhecem e oferecem para conectar. Os códigos de e-mail e telefone usam links mailto: e tel:. Tudo é gerado nesta página e nada é enviado para lugar nenhum.
