Como funciona o tempo epoch

Um timestamp Unix conta os segundos desde a época Unix (epoch), meia-noite UTC de 1º de janeiro de 1970. Como ele indica um momento e não a leitura de um relógio, o mesmo número representa o mesmo instante em São Paulo, Lisboa e Nova York. É na conversão para data que entram os fusos horários: o conversor de timestamp Unix usa o banco de dados de fusos do seu navegador, as mesmas regras do seu sistema operacional, para calcular o deslocamento local e o horário de verão naquele momento.

Muitos sistemas usam unidades menores. JavaScript e Java contam milissegundos; alguns bancos de dados e o time.time_ns() do Python usam microssegundos ou nanossegundos. Colar um valor desses como segundos dá uma data dezenas de milhares de anos distante, então a ferramenta deduz a unidade pelo tamanho do número e mostra qual escolheu. Valores em microssegundos e nanossegundos mantêm os dígitos extras na linha ISO 8601.

Ir de uma data para um timestamp exige um fuso horário, porque 09:00 acontece em um momento diferente em cada fuso. A data que você digita é lida como a leitura do relógio no fuso escolhido. Leituras que caem em um intervalo pulado ou repetido pelo horário de verão são sinalizadas, para você saber qual instante obteve.

Dicas

  • Agendamentos escritos como expressões cron podem ser conferidos com Explicar expressão cron, que lista as próximas execuções em qualquer fuso.
  • Valores de UUID versão 7 carregam um timestamp em milissegundos; o Gerador de UUID consegue lê-lo.
  • Organize uma resposta JSON cheia de timestamps com Formatar e validar JSON.
