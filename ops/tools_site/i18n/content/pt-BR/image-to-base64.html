Saída

Embutir imagens como texto

Converter uma imagem para Base64 resolve um problema simples: HTML, CSS, JSON, Markdown e corpos de e-mail são texto, mas imagens são binárias. O Base64 faz a ponte escrevendo os bytes da imagem com 64 caracteres seguros, para que a imagem inteira caiba dentro de uma regra de folha de estilo, de uma tag img ou de um arquivo de configuração, sem download separado.

Esta ferramenta lê o arquivo no seu navegador, confere o tipo real pelos primeiros bytes e monta o trecho que você escolher em volta do texto codificado. A imagem em si não muda: decodificar o Base64 devolve exatamente o arquivo original.

Dicas

  • Reduza a imagem antes com Comprimir imagem ou Redimensionar imagem; cada byte economizado vale um terço a mais de economia em Base64.
  • Para ícones simples, um SVG costuma ser menor que qualquer PNG, mesmo em Base64.
  • Para decodificar Base64 de volta em arquivo, ou codificar qualquer outro arquivo, use Codificar e decodificar Base64.
