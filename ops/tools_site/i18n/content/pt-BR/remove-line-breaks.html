Como transformar linhas quebradas em parágrafos de novo

Texto copiado de PDFs, e-mails antigos, janelas de terminal e alguns sites costuma ter uma quebra de linha no fim de cada linha visual. Colado num documento ou formulário, ele continua quebrado em linhas curtas que não se reorganizam. Esta ferramenta remove as quebras de linha e junta os pedaços com um espaço, para o texto voltar a ficar corrido.

Manter parágrafos é a escolha certa para a maioria dos textos: mantém as linhas em branco que separam os parágrafos e junta todo o resto. Remover todas coloca o texto inteiro numa única linha, o que serve para trechos curtos, itens de lista que você quer separar por vírgula ou valores que vão para uma única célula de planilha.

Às vezes o texto de PDF divide palavras entre linhas com um hífen. Ative Juntar palavras separadas por hífen para uni-las de novo e confira no resultado as palavras que têm hífen de verdade.

Dicas

  • Precisa trocar outros caracteres também, como espaços duplos depois do ponto ou aspas curvas? Continue com Localizar e substituir.
  • Conte o texto limpo com o Contador de palavras ou o Contador de caracteres.
  • Quer fazer o caminho contrário, de uma lista para linhas ordenadas? Use Colocar linhas em ordem alfabética.
