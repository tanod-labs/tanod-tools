Como transformar JSON em YAML legível


Converter JSON para YAML é, em grande parte, reescrever os mesmos dados de um jeito mais fácil de ler. Chaves e aspas dão lugar a recuo e palavras simples, e é por isso que as configurações de Kubernetes, Compose e sistemas de CI costumam ser escritas em YAML. Partindo de um JSON, como a resposta de uma API ou um manifesto gerado, a conversão é mecânica, mas um detalhe exige cuidado: o YAML decide o tipo de um valor pela aparência dele.


No YAML, um true sem aspas é booleano, null é nulo e 1.0 é número. Uma string do JSON que por acaso se pareça com um desses, como "null", "1.0" ou "0x1F", precisa ficar entre aspas no YAML, senão muda de tipo ao ser lida. O conversor coloca aspas exatamente nesses casos, além das strings vazias e dos textos que começam com símbolos que têm significado no YAML, e depois confere o resultado lendo-o de volta.


Texto de várias linhas vira um bloco literal, muito mais fácil de ler do que uma string longa cheia de escapes \n. Objetos e arrays vazios são escritos como {} e []. Como o JSON não tem comentários, o YAML começa sem nenhum; você pode adicionar os seus depois.
