Mudar maiúsculas e minúsculas sem redigitar

Para converter maiúsculas e minúsculas, escolha um estilo e o texto da caixa é reescrito ali mesmo, então dá para encadear conversões: passe para minúsculas um parágrafo todo em CAIXA ALTA e depois transforme em tipo frase. Desfazer guarda as últimas vinte versões na memória enquanto a página estiver aberta.

Os estilos de programação (camelCase, PascalCase, snake_case, kebab-case, CONSTANT_CASE) tratam cada linha como um nome separado, então uma lista de expressões vira uma lista de identificadores. Letras maiúsculas dentro das palavras são tratadas como limites entre palavras, o que permite passar um nome de um estilo para outro.

Dicas

  • Conte o que você tem com o Contador de palavras.
  • Substitua muitas palavras de uma vez com Localizar e substituir.
  • Veja o que a conversão mudou com Comparar textos.
  • Vai criar um endereço da web a partir de um título? O Gerador de slug também converte acentos e remove a pontuação.
