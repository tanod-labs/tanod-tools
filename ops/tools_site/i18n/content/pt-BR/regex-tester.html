Como testar padrões com segurança


Este testador de regex monta um RegExp JavaScript com o seu padrão e as suas flags e o executa em um worker em segundo plano, o mesmo motor que o seu código vai usar neste navegador. As correspondências voltam com a posição inicial e todos os grupos de captura, e a página as desenha sobre o seu texto com destaques alternados, para que correspondências vizinhas continuem distinguíveis. Uma correspondência vazia, como a que \b ou a* podem produzir, aparece como uma barra fina.


Executar o padrão em um worker é importante porque uma expressão regular pode levar tempo exponencial. Se um padrão ainda estiver rodando após 2 segundos, o worker é interrompido e você recebe uma mensagem em vez de uma aba travada. A mesma proteção vale para Localizar e substituir.


As posições são contadas em unidades de código UTF-16, que é como as strings do JavaScript contam: um emoji ou outro caractere fora do plano básico ocupa duas. A lista mostra as primeiras 1.000 correspondências; a contagem total acima dela inclui todas.
