    O que muda quando um JPG vira PNG

    Ao converter JPG para PNG, você congela a foto no estado atual. Cada vez que um JPG é aberto, editado e salvo de novo, o codificador JPEG descarta mais um pouco de detalhe, e os artefatos se acumulam: bordas borradas, céus quadriculados, halos em volta do texto. Converter uma vez para PNG preserva a imagem como ela está, e as edições seguintes não custam mais nada.

    A contrapartida é o tamanho. O JPG foi criado para fotografias e o PNG não, então espere um arquivo bem maior. Se um formulário de envio ou um site pede PNG, este é o jeito de atender; se aceita os dois, enviar o JPG original costuma ser melhor.

    Dicas

    • Para o caminho inverso, use PNG para JPG.
