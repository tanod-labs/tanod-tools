O que cada filtro faz com os pixels

Para entender os filtros de imagem, pense que cada pixel são três números de 0 a 255, para vermelho, verde e azul. O brilho multiplica esses números, então 150 por cento transforma um valor de 100 em 150, e tudo o que passa de 255 é cortado para branco. O contraste afasta os números do cinza médio (128) ou os aproxima dele, e é por isso que contraste de 0 por cento gera uma imagem cinza chapada. A saturação e a rotação de matiz misturam os três canais usando matrizes de cor fixas, e é assim que uma foto vai ficando cinza ou dá a volta no círculo cromático.

A escala de cinza substitui cada pixel pela sua luminância, uma soma ponderada que dá mais peso ao verde (cerca de 72 por cento), depois ao vermelho (21 por cento) e menos ao azul (7 por cento), porque o olho é mais sensível ao verde. O sépia usa uma matriz que dá o tom marrom quente de fotos antigas. Inverter subtrai cada valor de 255 para gerar um negativo. O desfoque calcula a média de cada pixel com os vizinhos, três vezes em cada direção, o que se aproxima muito de um desfoque gaussiano.

Prévias pequenas deixam os controles rápidos, mas o arquivo salvo é processado em resolução total, em partes, para que a página continue respondendo e mostre o progresso. Depois de salvar, o arquivo original continua intacto.

Dicas

  • Para ler uma cor exata do resultado, use o Seletor de cores de imagem.
  • Aplicar os filtros antes de colocar uma legenda mantém o texto nítido: faça nessa ordem com Adicionar texto em imagem.
  • Uma imagem desfocada e com muito contraste se comprime de forma bem diferente, então confira o tamanho depois em Comprimir imagem.
