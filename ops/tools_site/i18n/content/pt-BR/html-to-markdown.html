Como transformar páginas da web em Markdown

Levar conteúdo de uma página da web, de um CMS antigo ou de um editor de texto formatado para um README, um site estático ou um app de notas geralmente significa converter HTML para Markdown. O conversor percorre a estrutura do HTML e escreve cada elemento na sua forma Markdown: cabeçalhos viram linhas com #, listas viram hífens, links viram [texto](url) e <pre><code> vira um bloco de código.

O Markdown só descreve estrutura, então a estilização fica para trás. Estilos inline, classes, cores e contêineres de layout desaparecem, enquanto as palavras, a ênfase, os links, as imagens e as listas ficam. As tabelas são escritas como tabelas do GitHub Flavored Markdown quando são simples o bastante para caber nesse formato.

Projetos diferentes preferem hábitos de Markdown diferentes, por isso os estilos de cabeçalho, marcador de lista, bloco de código e itálico podem ser alterados. A maioria dos renderizadores aceita qualquer um deles.
