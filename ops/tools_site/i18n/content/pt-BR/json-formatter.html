Como formatar e validar JSON


JSON é um formato de texto pequeno e rígido para dados: objetos entre chaves, arrays entre colchetes e valores que são strings, números, true, false ou null. As máquinas não se importam com espaços em branco, mas as pessoas sim, então um formatador acrescenta indentação e quebras de linha para deixar os dados aninhados legíveis, e um minificador os remove para economizar espaço.


Esta ferramenta lê o seu texto com um parser próprio, então consegue apontar o caractere exato em que algo dá errado. Os erros mais comuns são uma vírgula sobrando depois do último item, aspas simples em vez de duplas, uma chave sem aspas, um comentário ou um colchete faltando no final. O erro mostra a linha e a coluna, uma cópia dessa linha e um ^ sob a posição.


Formatar só muda os espaços em branco. Números e escapes de string são mantidos como foram escritos, então um ID longo como 12345678901234567890 não é arredondado, como aconteceria se os dados fossem lidos como números do JavaScript.
