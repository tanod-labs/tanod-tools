Como remover duplicados e ordenar linhas

Listas acumulam repetições: e-mails colados de várias fontes, palavras-chave, linhas de log, nomes de arquivos. Esta ferramenta para remover linhas duplicadas lê o texto uma linha por vez, lembra de cada linha que já viu e descarta as cópias seguintes (ou as anteriores, se você escolher manter a última ocorrência). As linhas que sobram ficam na ordem original, a menos que você escolha uma ordenação.

O relatório acima dos botões mostra quantas linhas entraram, quantas saíram e quantas foram removidas como duplicadas, para você conferir se o resultado é o esperado. As linhas vazias removidas pela opção aparecem separadamente.

Dicas

  • Para limpar as linhas antes, use Localizar e substituir e depois volte aqui.
  • Veja o que mudou entre duas versões de uma lista com Comparar textos.
  • Só precisa da lista em ordem, com mais opções de ordenação? Use Colocar linhas em ordem alfabética.
  • Conte o que sobrou com o Contador de palavras.
