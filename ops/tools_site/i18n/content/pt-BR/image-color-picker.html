      Lendo as cores direto dos pixels

      Pegar a cor de uma imagem, seja para reproduzir a cor de uma marca a partir de um logotipo, encontrar o azul exato de um print ou montar uma paleta a partir de uma foto, se resume à mesma coisa: ler os valores de vermelho, verde e azul armazenados em um pixel. Esta ferramenta decodifica a imagem no seu navegador e lê esses valores da imagem em resolução total, então o código que você copia é a cor que realmente está no arquivo.

      Em fotos, um único pixel pode enganar, porque o ruído e a compressão fazem os vizinhos variarem. Use a lupa para mirar no meio de uma área lisa, ou pegue a paleta, que calcula a média de grupos inteiros de pixels parecidos e os reduz a algumas cores representativas.
