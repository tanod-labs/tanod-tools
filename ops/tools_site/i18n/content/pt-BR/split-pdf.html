    Três formas de dividir um PDF

    Intervalos de páginas serve para documentos com uma estrutura conhecida: capítulos, notas fiscais reunidas em uma única digitalização ou as páginas assinadas de um contrato. Escreva os intervalos que quiser e cada um vira um arquivo próprio.

    A cada N páginas corta em intervalos fixos. É ideal para digitalizações de formulários frente e verso (a cada 2 páginas) ou lotes de documentos iguais impressos em um único PDF.

    Cada página gera um PDF por página, o que é útil antes de reorganizar as páginas à mão ou de enviá-las para pessoas diferentes.

    Dicas

    • Quer as páginas escolhidas em um único arquivo em vez de vários? Use Extrair páginas de PDF.
    • Precisa das páginas como imagens? PDF para JPG transforma cada página em uma imagem.
