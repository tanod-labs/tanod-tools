Como colocar as páginas em ordem

Páginas acabam fora de ordem o tempo todo: digitalizações frente e verso, documentos montados a partir de várias fontes, uma página de assinatura que deveria ficar no fim. Para organizar as páginas do PDF, aqui você vê cada uma como miniatura e a move para o lugar certo.

O novo PDF é montado copiando as páginas na sua ordem. Nada nas páginas é alterado, e links, textos e imagens continuam intactos.

Dicas

  • Vai combinar vários arquivos em uma ordem específica? Juntar PDF permite ordenar os arquivos primeiro.
  • Depois de reordenar, use Numerar páginas de PDF para que a ordem fique visível no papel.
