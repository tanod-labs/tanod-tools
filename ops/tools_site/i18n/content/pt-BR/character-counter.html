Limites de tamanho

OndeLimiteUsadoSobra

As linhas do X e do SMS seguem as regras de contagem desses sistemas; as outras linhas contam caracteres como mostrado acima. Os limites são referências: as plataformas os mudam, e algumas medem a largura na tela em vez de caracteres.

Contar caracteres do jeito que o sistema de destino conta

Para contar caracteres corretamente, é preciso saber que "caractere" significa coisas diferentes para programas diferentes. Uma pessoa vê um caractere em "é" ou em um emoji de bandeira, mas um computador pode armazenar qualquer um deles em duas ou mais partes. Este contador de caracteres mostra a contagem que você vê (Caracteres), a contagem de nível mais baixo de code points Unicode e o número de bytes que o texto ocupa em UTF-8, a codificação que a maioria dos sites e bancos de dados usa. Quando um formulário diz "máximo de 255 caracteres", geralmente está contando uma dessas coisas, e a diferença só importa para emojis, acentos armazenados como marcas separadas e sistemas de escrita não latinos.

A tabela de limites de tamanho compara o seu texto com lugares onde o tamanho costuma ser limitado. Cada linha mostra o que foi usado e o que sobra; uma linha acima do limite mostra quantos caracteres cortar. Mensagens de texto são contadas com as regras GSM que os celulares usam, então um único emoji pode mudar a mensagem inteira para o limite Unicode, que é menor.

Tudo é contado no seu navegador enquanto você digita. O texto não é enviado nem armazenado.
