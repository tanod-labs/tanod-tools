Como o texto vira uns e zeros

Computadores guardam texto como números. Uma codificação decide qual número cada caractere recebe; este conversor de texto para binário usa UTF-8, que é o que quase toda página da web, e-mail e arquivo moderno usa. O UTF-8 guarda os primeiros 128 caracteres (o alfabeto inglês, os dígitos e a pontuação comum) em um byte cada, com os mesmos valores do antigo código ASCII. Outros caracteres ocupam de dois a quatro bytes: é é 11000011 10101001 e o emoji 😀 tem quatro bytes.

Um byte tem oito bits, então cada byte aparece como oito dígitos binários, com os zeros à esquerda mantidos para que todos os grupos tenham a mesma largura. Isso torna a saída fácil de ler de volta: cada grupo de oito é um byte.

Para decodificar, a ferramenta lê cada grupo como um byte e depois lê os bytes como texto UTF-8. Se os bytes não formarem UTF-8 válido, ela diz onde o problema começa em vez de mostrar caracteres embaralhados.
