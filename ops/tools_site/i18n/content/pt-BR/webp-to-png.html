    Por que converter imagens WebP

    Converter WebP para PNG resolve o problema mais comum desse formato: abrir a imagem fora do navegador. O WebP é um formato da web: tem um modo com perdas para fotos e um modo sem perdas para gráficos, ambos com transparência, e deixa as páginas mais rápidas. Fora do navegador, o suporte é irregular. Um WebP salvo de uma loja virtual ou de uma notícia pode não abrir em um editor mais antigo, não ser aceito como anexo em um formulário ou não imprimir a partir de um programa de computador.

    Esta página decodifica o WebP com o decodificador do próprio navegador, que já entende os dois modos e a transparência, e grava os pixels como PNG. Nada é enviado, então também serve para imagens que você prefere não mandar para um servidor de conversão.
