Como uma tabela Markdown é escrita

Uma tabela Markdown do GitHub é texto simples: uma linha de cabeçalho, uma linha de hífens que define o alinhamento e uma linha para cada linha de dados, com as células separadas por barras verticais. É o formato que o GitHub exibe em READMEs, issues e pull requests, e muitas outras ferramentas, como sites de documentação e apps de notas, também o entendem.

A grade guarda as células; a primeira linha é o cabeçalho. Cada coluna tem um alinhamento. Esquerda se escreve :---, centro :---:, direita ---: e sem alinhamento são só hífens. O texto das células é escapado quando necessário: a barra vertical vira \| e a quebra de linha vira a tag HTML <br>. Depois a ferramenta alinha as colunas com espaços para que o código pareça uma tabela, usando a largura de cada caractere e não o tamanho em bytes, de modo que letras acentuadas também fiquem alinhadas.

Colar de uma planilha é a forma mais rápida de começar. As planilhas colocam as células copiadas na área de transferência como texto separado por tabulações, com uma linha por linha da tabela, e a grade lê isso diretamente. Arquivos CSV e TSV funcionam do mesmo jeito pela caixa de colagem, com campos entre aspas e quebras de linha entre aspas tratados. Se você colar uma tabela Markdown existente, as células e os alinhamentos são lidos de volta para a grade, e você pode alterá-los.
