Como transformar JSON numa planilha

APIs e exportações costumam entregar JSON, enquanto as pessoas que precisam dos dados querem uma planilha. O CSV faz a ponte entre os dois: ao converter JSON para CSV, cada objeto do array vira uma linha e cada chave vira uma coluna. Como os objetos de dados reais raramente têm todos as mesmas chaves, a ferramenta reúne todas as chaves que encontra, na ordem em que as vê pela primeira vez, e deixa a célula vazia quando um objeto não tem valor para aquela coluna.

Planilhas são planas, então os dados aninhados precisam ser encaixados em colunas de algum jeito. Achatar transforma user.name e user.email em colunas separadas, o que serve para a maioria dos relatórios. Manter objetos aninhados como texto JSON reduz o número de colunas e permite reconstruir a estrutura original depois.

O CSV segue as regras usuais (RFC 4180): os valores só ficam entre aspas quando necessário e as aspas dentro de um valor são duplicadas. Os números mantêm exatamente os dígitos do seu JSON, em vez de serem arredondados como os números do JavaScript seriam.

Dicas

  • Quer fazer o contrário? Use CSV para JSON.
  • Se o JSON não converter, encontre o problema com Formatar e validar JSON.
  • Compare duas exportações linha por linha com Comparar textos.
