De YAML para JSON


YAML e JSON descrevem o mesmo tipo de dado: mapeamentos, listas e valores simples. O YAML é escrito por pessoas, com indentação em vez de chaves, comentários e atalhos como âncoras; o JSON é o que a maioria dos programas e APIs espera. Converter YAML para JSON é comum quando um manifesto do Kubernetes, um arquivo do Compose ou uma descrição OpenAPI precisa ser passado para algo que só lê JSON.


Alguns recursos do YAML não têm equivalente em JSON, então o conversor os resolve. Uma âncora (&base) marca um bloco que um alias (*base) pode reutilizar, e uma chave de merge (<<) copia as entradas de um mapeamento para outro; no JSON, cada um deles vira uma cópia completa. Os comentários são descartados, porque o JSON não os aceita. Um arquivo com vários documentos separados por --- vira um array JSON.


As regras de tipo seguem o YAML 1.2: true e false são booleanos, null e ~ são nulos, números são números, e todo o resto, inclusive yes e 2024-05-01, é texto. Os erros de sintaxe trazem linha e coluna, e as causas mais frequentes são uma tabulação usada na indentação, uma chave repetida no mesmo mapeamento e um valor que não está indentado sob a sua chave.
