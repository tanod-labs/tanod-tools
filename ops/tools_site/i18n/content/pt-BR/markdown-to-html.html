Como o Markdown vira HTML

Markdown é um jeito de escrever texto formatado com caracteres simples: um # começa um cabeçalho, **dois asteriscos** deixam em negrito, uma linha que começa com hífen é um item de lista. É o que usam os arquivos README, muitos apps de notas e a maioria dos fóruns de desenvolvedores. Navegadores, templates de e-mail e sistemas de conteúdo querem HTML, então em algum momento é preciso converter Markdown para HTML.

Este conversor segue o CommonMark com os acréscimos do GitHub Flavored Markdown, então tabelas, listas de tarefas e texto tachado funcionam como no GitHub. O HTML gerado passa depois por um sanitizador, que remove tudo o que poderia executar código quando o HTML é exibido, sem mexer na formatação comum.

A aba Prévia mostra o mesmo HTML renderizado na página. Os links abrem numa nova aba, e imagens hospedadas em outros lugares aparecem como espaços reservados em vez de serem baixadas, então nada do que você escreve é enviado para outro site enquanto você trabalha.
