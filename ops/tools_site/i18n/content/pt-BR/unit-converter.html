Como as conversões funcionam

Este conversor de medidas usa uma unidade base para cada categoria: metros para comprimento, quilogramas para peso, litros para volume, metros quadrados para área e metros por segundo para velocidade. O valor é multiplicado pelo tamanho da sua unidade na unidade base e depois dividido pelo tamanho da unidade de destino. Como cada fator é uma definição exata (1 polegada = 0,0254 m exatamente, 1 libra = 0,45359237 kg exatamente), o resultado é tão preciso quanto os números que você digita.

A temperatura funciona de outro jeito, porque as escalas têm pontos zero diferentes. Celsius e Kelvin têm o mesmo tamanho de grau, mas o Kelvin começa no zero absoluto, então K = °C + 273,15. O grau Fahrenheit tem 5/9 do tamanho do grau Celsius e a escala é deslocada, então °F = °C × 9/5 + 32. Rankine é a escala com graus do tamanho do Fahrenheit que começa no zero absoluto.

Algumas unidades têm o mesmo nome, mas não o mesmo tamanho. Galões, pints e onças fluidas americanos e britânicos são diferentes, assim como as toneladas americana, britânica e métrica, por isso aparecem separadas e identificadas.
