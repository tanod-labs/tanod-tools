Como uma página da web vira PDF aqui

Para salvar a página da web como PDF, nosso servidor inicia uma cópia nova e isolada do navegador Chromium, abre o endereço que você informou, espera a página terminar de carregar e a imprime em PDF com o tamanho de papel e a orientação escolhidos, do mesmo jeito que a janela Imprimir do seu navegador faria. O navegador só consegue acessar aquele site, nunca redes privadas, e é descartado depois de cada tarefa.

Dicas

  • Páginas fáceis de ler, como artigos com versão para impressão, geram os PDFs mais limpos.
  • Quer várias páginas em um só arquivo? Converta cada uma e depois junte-as com Juntar PDF (no seu navegador).
  • Precisa do texto em vez de um PDF? HTML para Markdown converte o HTML colado no seu dispositivo.
