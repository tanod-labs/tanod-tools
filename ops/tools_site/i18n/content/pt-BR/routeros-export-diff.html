Lendo um diff de configuração do RouterOS

Um export é a configuração do roteador escrita como os comandos que a recriariam: uma linha de menu como /ip firewall filter seguida dos comandos add e set daquele menu. Só aparecem os ajustes que diferem dos padrões, o que mantém os exports curtos, mas significa que um ajuste que voltou ao padrão simplesmente desaparece do export mais novo. O diff trata cada menu como uma seção, compara os seus comandos em ordem e destaca as seções que mudaram.

Algumas diferenças são ruído e não mudanças: o cabeçalho com a data do export, o ID do software e o número de série é descartado, as linhas quebradas são unidas e as linhas de comentário podem ser ignoradas. O que sobra é o que o roteador faria de fato de modo diferente. A ordem é mantida de propósito: as regras de firewall, NAT, mangle e queue são processadas de cima para baixo, então mover uma regra é uma mudança real.

Dicas

  • Guarde um export datado depois de cada janela de mudança e compare-o com o anterior para ver exatamente o que foi feito.
  • Conferindo uma atualização da v6 para a v7? Compare o script convertido do assistente de migração com um export feito depois da atualização.
  • Para texto simples que não é um export, o diff de texto geral também compara palavra por palavra.
