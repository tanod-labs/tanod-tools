De linhas CSV para JSON

O CSV é o mínimo denominador comum dos dados: toda planilha e todo banco de dados conseguem exportá-lo. O JSON é o que a maioria das APIs web, scripts e arquivos de configuração espera. Para converter CSV para JSON, esta ferramenta lê o CSV com um parser que segue o padrão CSV, então uma vírgula dentro de um endereço entre aspas ou uma quebra de linha dentro de um comentário entre aspas fica dentro da sua célula, em vez de dividir a linha.

Com uma linha de cabeçalho, cada linha vira um objeto cujas chaves são os nomes das colunas, na ordem das colunas. Sem cabeçalho, cada linha vira um array. Os valores ficam como texto, a menos que você peça para converter números e true/false, porque um arquivo CSV não carrega tipos e um palpite automático pode transformar silenciosamente um código postal como 02134 no número 2134.

A linha abaixo das opções informa quantas linhas e colunas foram lidas e qual delimitador foi usado. Se algumas linhas tiverem mais ou menos campos que o cabeçalho, uma nota diz quais linhas, o que geralmente aponta para um delimitador perdido ou uma aspa não fechada na origem.
