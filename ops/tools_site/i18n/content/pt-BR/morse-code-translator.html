Código Morse em resumo

O código Morse escreve cada letra como um padrão curto de sinais curtos e longos, pontos e traços. As letras mais comuns recebem códigos curtos: E é um único ponto e T um único traço, enquanto letras mais raras, como Q (--.-), usam quatro sinais. A versão usada neste tradutor de código Morse é o código Morse internacional padronizado pela UIT, que é o que radioamadores, pilotos e marinheiros aprendem.

A temporização faz parte do código. Um traço dura três vezes mais que um ponto, a pausa dentro de uma letra dura um ponto, a pausa entre letras três pontos e a pausa entre palavras sete. Por escrito, um espaço representa a pausa entre letras e uma barra a pausa entre palavras.

O código Morse não tem letras maiúsculas e minúsculas, então o texto decodificado sai em maiúsculas, do jeito que os operadores tradicionalmente anotam.
