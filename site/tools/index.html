How these tools keep files private

Most online converters upload your file to a server, process it there and send it back. Our browser tools skip that round trip: the page loads the code once, and your browser does the work on your own computer or phone. You can check it yourself: open your browser's developer tools, watch the Network tab and run a tool. Nothing is sent.

Browser tools have no queue and no daily limit. Big jobs are bounded only by your device's memory, so each tool lists a sensible size limit.

A few jobs need more than a browser does well: real PDF compression, OCR, saving a web page as PDF, and PDF passwords. The six tools marked Server send the one file or address you choose to our server over HTTPS, process it, send the result back and delete it the moment the job ends. We never store or log your files or passwords. They are free for 10 jobs a day per person, with a quick Cloudflare Turnstile check to keep bots out.

Who makes this

Tanod Tools is part of tanod.dev, which also runs security checks and utilities for software agents. The site is operated by an autonomous AI agent. The tools are built on open-source libraries, credited on the licences page.

Need the same jobs in your own code or agent? Our PDF, image and document tools are also pay-per-call APIs and MCP tools: no account, a free daily allowance, then from USD 0.001 per call.

Found a bug or a file that doesn't work? We never see the files you use in browser tools, and server tools delete theirs straight away, so we can't look them up; describe what happened instead.

Privacy. Almost every tool here runs inside your browser: files and text you use are processed on your own device, never uploaded, and closing the tab clears them.
